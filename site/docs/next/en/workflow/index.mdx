# Workflow

Workflow brings the A3S Flow node catalog, canvas-node contract, and configuration inspector into one section of the A3S UI documentation. It is part of this site and does not create a separate application or standalone playground.

## Start with the current DAG contract

[Flow 1.0 DAG node configuration](/components/form-system/workflow-node-embedding) is the primary integration guide. Its embedded editor provides the node library, dotted canvas, typed handles, selected-node state, resizable inspector model, settings and latest-run tabs, and controlled React configuration surface.

The host still owns graph persistence, credentials, authorization, execution, and connection picking. A3S UI owns the visible node and inspector contract while A3S Flow owns graph validation and execution semantics.

## Core node catalog

| Node | Purpose |
| --- | --- |
| [Workflow Start](/components/form-system/a3s-flow/start) | Declare workflow identity, runtime entrypoint, input schema, and run identity |
| [Run Step](/components/form-system/a3s-flow/step) | Schedule one durable task with retry behavior |
| [Run Step Batch](/components/form-system/a3s-flow/batch) | Run an ordered list of durable tasks |
| [Condition](/components/form-system/a3s-flow/condition) | Select one of two graph branches from workflow data |
| [Wait Until](/components/form-system/a3s-flow/wait) | Pause until an absolute UTC deadline |
| [Wait for Callback](/components/form-system/a3s-flow/hook) | Pause for an approval, webhook, UI action, or host event |
| [Complete](/components/form-system/a3s-flow/complete) | Finish successfully with a persisted JSON result |
| [Fail Workflow](/components/form-system/a3s-flow/fail) | Finish with a persisted error |

These eight chapters document the earlier value-only compatibility surface. New editors should use the Flow 1.0 DAG node contract while retaining these pages for migrations.

## Visual and interaction contract

- Canvas nodes use a stable 240-pixel footprint, semantic node colors, compact variable rows, external connection handles, selected and execution states, and keyboard activation.
- The node library supports search, semantic grouping, pointer selection, and visible focus without changing the manifest catalog.
- The 400-pixel inspector keeps identity and actions fixed while settings scroll independently. It supports run, reset, reference, close, latest-result, loading, validation, and read-only states.
- Embedded examples remain controlled components. They do not save, execute, or resolve graph connections without explicit host callbacks.
