# Projects

Projects combines existing project management with template-based creation. A project is durable context for related tasks, files, instructions, and collaborators; it is not another task list.

## Composition

Use App Page, Input, Resource Grid, Resource Card, menus, Empty, and Dialog or a page-level creation form. Project templates create initial structure; existing project cards navigate to detail views.

## Responsive behavior

Search moves below the section heading when necessary. Grids collapse without forcing equal heights. Long project names and paths truncate within their own row, never the document.

## Accessibility

Use anchors for project navigation and buttons for template actions. Give search a label. Menus must not be nested inside a card link; place project actions in a sibling control or dedicated row. Project names, activity counts, update times, and templates in the preview are illustrative data.
