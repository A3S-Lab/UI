## Composition

Use App Page, Catalog, Tabs, Input, Select, buttons, Resource Grid, Resource Card, Status Badge, Skeleton, and Empty. Search, ownership, installation, pagination, and catalog data remain application state.

## Responsive behavior

Featured items scroll inside their own row. Header and toolbar controls stack below 768px. Resource Grid reduces columns without forcing equal card heights or creating document overflow.

## Accessibility

Use a real tab interface when tabs change resource type. Search and sort controls need labels. Selected, installed, unavailable, and loading state must use semantics and text, not color alone. Names, publishers, categories, counts, and availability in the preview are illustrative data.
