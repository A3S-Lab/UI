## Composition

Use one native `<form>` with Field, Native Select, radio controls, Item rows, and an Agent Composer Section. The outer Form remains the only submit boundary.

The application validates repository availability, creates a branch or worktree, resolves environment actions, and starts the thread. A3S UI owns none of those operations. The project path, status, and instruction shown in the preview are illustrative data.

## Responsive behavior

Keep environment choices before project details in DOM order. Collapse to one column on narrow screens and keep the primary action after the instruction. Long Windows, UNC, Unicode, and spaced paths must wrap or truncate inside the project control without causing document overflow.

## Accessibility

Group mutually exclusive environments in a Fieldset with a Legend. Disabled environments need visible reason text. If setup fails after submit, retain every selection and the first instruction, then focus an error summary associated with the failed field.
