## Composition

Use native Dialog behavior in production, then compose Workspace Header, Settings Layout, Setting List, Setting Row, native controls, Button Group, Switch, and Progress. Configuration persistence and validation remain application logic.

## Responsive behavior

The dialog stays within the visual viewport. Below 768px, settings navigation becomes a bounded horizontal section list or separate drawer before content becomes cramped. Rows stack below 640px without changing label-control order.

## Accessibility

Use a native `<dialog>` when possible, trap focus only while modal, and restore focus on close. Each setting needs a label, optional description, validation association, and direct recovery. Navigation links target uniquely headed sections. Storage values and selected defaults in the preview are illustrative data.
