## Composition

Use Task Start with one Agent Composer and optional starter actions. The outer form remains the only submit boundary. Workspace discovery, model availability, permission enforcement, attachment upload, and task creation stay in the application.

## Responsive behavior

Suggestions scroll within their own row. The composer stays nearly full width on phones, preserves 44px targets, and wraps or scrolls tools without hiding the submit action.

## Accessibility

Name the suggestion navigation and form. Anchored model, permission, and workspace menus restore focus to their trigger. If creation fails, preserve the instruction and every choice, then focus a direct error summary. Suggestions, workspace names, and permission labels in the preview are illustrative data.
