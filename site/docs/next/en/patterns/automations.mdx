## Composition

Use App Page, Item, Status Badge, Table, Resource Grid, Resource Card, Stepper, fields, and Agent Composer. Creation should become a page-level form when schedule, workspace, permission, delivery, and test-run choices require sustained attention.

## Responsive behavior

Scheduled rows move secondary actions below identity when necessary. Run history scrolls inside the table boundary. The page keeps the primary creation action visible without fixing it over content.

## Accessibility

State uses text plus semantics. Schedule controls need explicit timezone and locale. Run history rows navigate to named detail views. A failed test run retains all form data and focuses the direct recovery message. Names, schedules, durations, and statuses in the preview are illustrative data.
