## Composition

```text
App Shell
├── Activity Bar: projects and threads
└── Main workspace
    ├── Workspace Header: thread and environment identity
    ├── Split Pane
    │   ├── Agent Transcript + Agent Composer
    │   │   └── Execution Item / Approval Request
    │   └── Task Pane: context and thread metadata
    └── Status Bar
```

The pattern introduces no public root class or product state. Use the documented APIs of each component. Project selection, thread history, stream transport, Git state, approvals, and persistence stay in the host application. Names, paths, counts, and execution results in the preview are illustrative data.

## Responsive behavior

- Below 768 pixels, convert project navigation to the App Shell’s contained drawer.
- Collapse the inspector into Task Pane overlay behavior or a Drawer before the conversation becomes too narrow.
- Keep Agent Composer after the transcript in DOM order and anchored to the visible conversation region.
- Hide low-priority metadata before primary execution state or actions.

## Accessibility

Name project navigation, conversation, split separator, inspector, and status landmarks. The current project or thread uses `aria-current`. When a blocking approval arrives, move focus only if the application cannot continue without it; otherwise announce it and preserve the reader’s position. Do not use the transcript as one continuous live region.
