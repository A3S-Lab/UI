# Pane View

Pane View is a tool-pane stack with headers, expansion state, and resizable content heights. It suits outlines, symbols, filters, history, and property sections. Use [Split View](/harness/split-view) when every region must remain visible and does not need collapse.

React `usePaneview` returns `api`, `ready`, and a stable `onReady`; the Vue composable returns an `api` shallow ref and `onReady`. Expansion, resizing, and order remain on the native `PaneviewApi` and panel APIs.

## State and behavior

- A header names its pane; it must not show only an icon or internal ID.
- Expand high-frequency content by default. Low-frequency, expensive, or contextual regions may start collapsed.
- Observe `onDidExpansionChange` to persist a user preference, but do not collapse merely because asynchronous data is empty.
- A custom header retains expansion state, pointer and keyboard operation, focus treatment, and an accessible name.
- Drag reordering changes presentation only; data ownership and permission do not follow pane position.

## Accessibility

Associate each header with its content and expose expansion state to assistive technology. Collapsed content leaves the focus order; reopening a pane must not forcibly move focus. Header targets are at least 44px high for coarse pointers.
