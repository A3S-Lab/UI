# Harness

Harness groups the components needed to build Coding Agent workflows. It separates task input, conversation, execution, permission, review, evidence, and preview tools from general application layout so teams can choose components by user task instead of page appearance.

Harness currently contains 28 public components. Every guide keeps its stable `/components/*` route, so existing links and package imports remain compatible.

## Workspace layout

[Dock Workspace](/harness/dock-workspace) · [Grid View](/harness/grid-view) · [Split View](/harness/split-view) · [Pane View](/harness/pane-view)

These are optional layout integrations and do not change the 114-component semantic manifest. Dock Workspace owns tabs, DnD, floating and popout groups, Edge Groups, and layout recovery. Grid, Split, and Pane View cover a fixed two-dimensional grid, a one-axis split, and collapsible tool panes. Every layout guide includes vanilla, React, Vue, and matching hooks.

## Tooling
