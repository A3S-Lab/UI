# Color

A3S UI uses neutrals for structure and iris for focus and selection. Brand blue belongs to identity and information. Green, amber, and red report outcomes and never replace text, icons, or structure.

## Semantic tokens

| Role                    | Light     | Dark      | Use                            |
| ----------------------- | --------- | --------- | ------------------------------ |
| `--background`          | `#ffffff` | `#0d0d0f` | Application canvas             |
| `--foreground`          | `#111113` | `#f4f4f5` | Primary content                |
| `--card`                | `#ffffff` | `#151518` | Stable and raised surfaces     |
| `--muted`               | `#f7f7f8` | `#19191d` | Muted surface                  |
| `--accent`              | `#f4f4f5` | `#202024` | Hover surface                  |
| `--a3s-panel-strong`    | `#eeeeef` | `#26262b` | Active surface                 |
| `--muted-foreground`    | `#52525b` | `#b4b4bc` | Supporting text                |
| `--a3s-subtle`          | `#71717a` | `#888891` | Nonessential annotation        |
| `--border`              | `#dedee1` | `#333338` | Control and overlay boundaries |
| `--input`               | `#c9c9ce` | `#45454b` | Strong boundary                |
| `--primary`             | `#111113` | `#f4f4f5` | Default primary action         |
| `--ring` / `--a3s-blue` | `#5b57d9` | `#8378f0` | Focus, links, and selection    |
| `--a3s-brand-blue`      | `#249bf6` | `#38a8eb` | A3S identity and information   |

Success, warning, and danger resolve to `#16845b`, `#a86412`, and `#c93d45` in light mode, then `#57c795`, `#e7ad55`, and `#ef7a82` in dark mode. Do not use these colors to decorate ordinary cards, navigation, or toolbars.

```css
.selection-region {
  --ring: var(--a3s-blue);
}
```

## Parameters

Theme switching uses the `dark` class on `<html>`. Consumers may override semantic tokens at `:root`, within `.dark`, or inside a scoped product container, but must revalidate text contrast, visible focus, and state meaning together.
