# Color

A3S UI uses neutrals for structure and A3S OS blue for primary actions, focus, links, and selection. The deeper logo blue belongs to identity. Green, amber, and red report outcomes and never replace text, icons, or structure.

## Semantic tokens

| Role                    | Light     | Dark      | Use                            |
| ----------------------- | --------- | --------- | ------------------------------ |
| `--background`          | `#ffffff` | `#0d0d0f` | Application canvas             |
| `--foreground`          | `#111113` | `#f4f4f5` | Primary content                |
| `--card`                | `#ffffff` | `#151518` | Stable and raised surfaces     |
| `--muted`               | `#f7f7f8` | `#19191d` | Muted surface                  |
| `--accent`              | `#eef4ff` | `#17223b` | Selected or accented surface   |
| `--a3s-panel-strong`    | `#eeeeef` | `#26262b` | Active surface                 |
| `--muted-foreground`    | `#52525b` | `#b4b4bc` | Supporting text                |
| `--a3s-subtle`          | `#71717a` | `#888891` | Nonessential annotation        |
| `--border`              | `#dedee1` | `#333338` | Control and overlay boundaries |
| `--input`               | `#c9c9ce` | `#45454b` | Strong boundary                |
| `--primary`             | `#1456f0` | `#4380f9` | Default primary action         |
| `--ring` / `--a3s-blue` | `#1456f0` | `#4380f9` | Focus, links, and selection    |
| `--a3s-brand-blue`      | `#243a9a` | `#7aa2f7` | A3S identity and information   |

Success, warning, and danger resolve to `#16845b`, `#a86412`, and `#c93d45` in light mode, then `#57c795`, `#e7ad55`, and `#ef7a82` in dark mode. Do not use these colors to decorate ordinary cards, navigation, or toolbars.

```css
.selection-region {
  --ring: var(--a3s-blue);
}
```

## Parameters

Theme switching uses the `dark` class on `<html>`. Consumers may override semantic tokens at `:root`, within `.dark`, or inside a scoped product container, but must remap primary action, hover, focus, selection surface, and foreground together. Violet and other optional accents never replace the default A3S OS blue contract or semantic state colors.
