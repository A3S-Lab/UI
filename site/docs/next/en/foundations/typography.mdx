# Typography

A3S UI uses Geist Sans with established system and CJK fallbacks. Geist Mono is reserved for code, commands, paths, measurements, and tabular data.

## Families

| Token | Stack | Use |
| --- | --- | --- |
| `--font-sans` | Geist Sans, System UI, PingFang SC, Microsoft YaHei, Noto Sans CJK SC | Interface and documentation text |
| `--font-mono` | Geist Mono, SFMono-Regular, Consolas, Liberation Mono, Menlo | Code, commands, paths, measurements |

## Scale

| Role | Size / line height | Weight | Notes |
| --- | --- | --- | --- |
| Display | `28–40 / 32–46px` | `650` | Start and empty surfaces only |
| Page title | `24 / 30px` | `650` | One per view |
| Section title | `16 / 22px` | `650` | Settings and inspector regions |
| Control | `13 / 20px` | `500–600` | Dense application chrome |
| Body | `14 / 22px` | `400` | Default copy, limited to 65–75 characters per line |
| Caption | `12 / 16px` | `400–500` | Metadata and status |

## Parameters

Override `--font-sans` and `--font-mono` at the application root. Preserve the scale and line-height relationships unless the product has a measured density requirement. Avoid putting status, file names, or long labels in all caps.
