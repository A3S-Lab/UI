# Shape and elevation

Shape communicates hierarchy through a 6px control radius, 10px stable surface radius, and 14px elevated-surface radius. Shadows belong only to floating or overlapping surfaces.

## Radius

| Token | Default | Use |
| --- | ---: | --- |
| `--radius-sm` | base minus 4px | Badges and tiny controls |
| `--radius-md` | base minus 2px | Buttons, inputs, navigation items |
| `--radius-lg` | base radius | Toolbars and side navigation |
| `--radius-xl` | base plus 4px | Cards and panels |
| `--a3s-radius` | `14px` | Major and elevated surfaces |

## Elevation

| Token | Use |
| --- | --- |
| `--a3s-shadow-composer` | Docked or floating Task Composer |
| `--a3s-shadow-soft` | Menus, popovers, drawers, and compact overlays |
| `--a3s-shadow` | Modal dialogs and large floating panels |

Borders and tonal contrast are the default separators. Static cards, shells, catalogs, transcripts, and setting rows do not receive shadows. Use either a visible border or broad elevation for one edge, not both by default.
