# Message Status

Message Status reports a bounded delivery or generation state beside one message. It does not make the whole transcript a live region.

## Usage

```html
<output class="message-status" data-state="streaming" aria-live="polite">
  <span data-message-status-indicator aria-hidden="true"></span>
  <span data-message-status-label>Generating response</span>
</output>
```

### Parameters

| API | Values | Purpose |
| --- | --- | --- |
| `data-state` | `sending`, `streaming`, `sent`, `queued`, `stopped`, `error` | Bounded message state |
| `data-message-status-label` | Required | Textual status |
| `data-message-status-meta` or `<time>` | Optional | Time or compact metadata |

## States and variants

Use `queued` only when the message is retained for later submission. Error state includes a direct retry or recovery path when available.

## Accessibility

Add a polite live region only while status changes asynchronously. Do not announce every streamed token.
