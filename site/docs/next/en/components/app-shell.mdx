# App Shell

The App Shell establishes a persistent navigation region and a bounded product workspace. It is the top-level frame used by A3S Office, gateway operations, and agent consoles.

## Usage

```html
<div class="app-shell" data-navigation="expanded">
  <aside data-app-navigation>...</aside>
  <main data-app-main>
    <header class="workspace-header">...</header>
    <div data-app-content>...</div>
  </main>
</div>
```

### Parameters

| Parameter | Values | Default | Purpose |
| --- | --- | --- | --- |
| `data-navigation` | `expanded`, `collapsed`, `hidden` | `expanded` | Desktop navigation state |
| `data-mobile-navigation` | `open`, omitted | omitted | Mobile drawer visibility |
| `--app-shell-navigation-size` | CSS length | `15rem` | Expanded navigation width |
| `--app-shell-navigation-collapsed-size` | CSS length | `2.875rem` | Office-aligned icon-rail width |
| `--app-shell-navigation-max-size` | CSS length or percentage | `38%` | Maximum expanded-navigation share |
| `--app-shell-height` | CSS length or `auto` | `auto` | Optional bounded shell height |
| `--app-shell-min-height` | CSS length | `36rem` | Minimum shell height |

## States and variants

The shell has expanded, collapsed, hidden, and mobile-open states. Below 768px the navigation becomes a contained overlay: its closed state is removed from pointer and keyboard interaction, while `data-mobile-navigation="open"` reveals it above a local backdrop. State management belongs to the host application because it often persists user preference and coordinates routing. The preview uses a small documentation-only controller.

## Accessibility

Use landmark elements (`aside`, `nav`, `main`, `header`) and name each navigation region. The navigation toggle needs `aria-expanded` and a label that changes with state. When mobile navigation is modal, pair this layout with the [Drawer](/components/drawer) behavior for focus containment.
