# File Explorer

File Explorer combines workspace identity, file search, hierarchical navigation, file state, and contextual actions in one bounded tool. Filesystem reads, writes, authorization, and source control remain the trusted host's responsibility.

## Usage

File Explorer reuses Tree for focus, selection, disclosure, and typeahead. Context Menu supplies contextual commands.

```html
<section class="file-explorer" aria-labelledby="files-title">
  <header><div data-file-explorer-identity><h2 id="files-title">Project files</h2></div></header>
  <div data-file-explorer-toolbar><input class="input" type="search" data-file-explorer-search aria-label="Filter files" /></div>
  <div data-file-explorer-viewport>
    <div class="tree" role="tree" aria-label="Project file tree">...</div>
  </div>
  <footer><span data-file-explorer-summary>5 files</span></footer>
</section>
```

### Parameters

| API | Purpose |
| --- | --- |
| `data-file-explorer-identity` | Workspace or directory name and optional path |
| `data-file-explorer-toolbar` | Search, refresh, create, and collapse commands |
| `data-file-explorer-viewport` | The file tree's only scroll owner |
| `data-file-status` | `added`, `modified`, `deleted`, or `conflict`, with an accessible name |
| `data-file-dirty` | Unsaved marker; it does not replace text status or leave confirmation |
| `data-file-editor` | Inline input for rename or create state |
| `data-file-explorer-state` | Loading, empty, error, or permission feedback |

## States and variants

Read-only mode preserves selection, copy path, and open actions while removing write commands instead of disabling everything. Rename uses `data-file-editor` in the current row: Enter submits, Escape cancels, and the host validates duplicates, invalid characters, and permission.

Source status may appear as a short trailing file marker. Commit, stage, branch creation, and remote synchronization are separate workflows composed from Toolbar, Tree, Alert, and Dialog; they do not belong in File Explorer's base public contract.

## Accessibility

Follow Tree's roving tabindex and arrow-key contract. Filtering must not silently remove the focused node: announce the count, then retain focus in search. Show async loading or error state inside the affected branch. A trusted host performs every file write.
