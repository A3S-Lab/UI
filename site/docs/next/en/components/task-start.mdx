# Task Start

Task Start centers the first instruction, a restrained suggestion row, and Task Composer on a spacious canvas. Use it as the start surface before a task exists.

## Usage

```html
<section class="task-start">
  <header><h1>What should we work on?</h1></header>
  <nav data-task-suggestions aria-label="Task suggestions">...</nav>
  <form class="agent-composer" aria-label="Start a task">...</form>
</section>
```

### Parameters

| API | Purpose |
| --- | --- |
| `class="task-start"` | Centers the start surface |
| `data-task-suggestions` | Optional bounded starter actions |
| `--task-start-content-width` | Shared suggestion and composer measure; defaults to `47.5rem` |

## States and variants

The composer owns empty, populated, invalid, disabled, offline, queued, and loading states. Suggestions are optional and must perform real actions, such as populating the instruction.

## Accessibility

Name the suggestion navigation and composer. Keep suggestions before the composer in DOM order. On narrow screens the layout aligns to the start edge and retains 44px coarse-pointer targets.

## React

```tsx
import { TaskStart, useTaskStart } from "@a3s-lab/ui/react";

export function Example() {
  const control = useTaskStart();
  return (
    <TaskStart ref={control.ref}>
      <header>
        <h1>What should we work on?</h1>
      </header>
      <nav data-task-suggestions="" aria-label="Task suggestions">
        <button type="button">Review the release</button>
        <button type="button">Fix a failing test</button>
      </nav>
      <form className="agent-composer" aria-label="Start a task">
        <textarea
          aria-label="Task"
          placeholder="Describe the outcome"
        ></textarea>
        <button type="submit">Start</button>
      </form>
    </TaskStart>
  );
}
```

`useTaskStart` subscribes to manifest-declared DOM events and calls only public manifest methods. The adapter creates no second, framework-only state model.
