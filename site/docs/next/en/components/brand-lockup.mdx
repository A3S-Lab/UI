# Brand Lockup

Brand Lockup keeps a product mark, name, and optional description aligned across application headers, authentication surfaces, and product navigation.

## Usage

Import the complete A3S bundle or the split Brand Lockup entrypoint.

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/brand-lockup.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

Use an anchor when the lockup navigates home and a neutral container when it only identifies the current product.

```html
<a class="brand-lockup" href="/" aria-label="A3S OS home">
  <span data-brand-mark aria-hidden="true"><img src="/logo.png" alt="" /></span>
  <span data-brand-identity>
    <strong data-brand-name>A3S OS</strong>
    <small data-brand-description>Agent Factory</small>
  </span>
</a>
```

### Parameters

| API                      | Values    | Purpose                              |
| ------------------------ | --------- | ------------------------------------ |
| `class="brand-lockup"`   | Required  | Root identity group                  |
| `data-brand-mark`        | Required  | Fixed mark, monogram, or logo region |
| `data-brand-identity`    | Optional  | Groups a name and description        |
| `data-brand-name`        | Required  | Visible product or organization name |
| `data-brand-description` | Optional  | Compact product context              |
| `data-size`              | `sm`      | Denser header treatment              |
| `data-tone`              | `mono`    | Monochrome treatment of official art |
| `--brand-lockup-accent`  | CSS color | Mark accent override                 |

## States and variants

The name may sit directly beside the mark when no description is needed. Use `data-size="sm"` in dense workspace headers and `data-tone="mono"` only where color is unavailable. Every presentation uses the official A3S OS asset; do not redraw, crop, or fabricate a three-dimensional mark. Override `--brand-lockup-accent` only with an approved brand token; keep operational state colors out of product identity.

## Accessibility

Keep the visible product name in text. Mark decorative monograms and logos with `aria-hidden="true"`; if the whole lockup is a link, give the link a destination-specific accessible name. Do not repeat the product name in both the mark and the accessibility tree.

## React

```tsx
import { BrandLockup } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <BrandLockup href="/" aria-label="A3S OS home">
      <span data-brand-mark aria-hidden="true"><img src="/logo.png" alt="" /></span>
      <span data-brand-identity><strong data-brand-name>A3S OS</strong><small data-brand-description>Agent Factory</small></span>
    </BrandLockup>
  );
}
```

The adapter replaces only the documented semantic root and adds no wrapper; its children keep the HTML contract shown above.
