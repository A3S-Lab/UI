# File Manager

File Manager presents workspace locations, folder navigation, multi-selection, search, grid or list views, Quick Look, and recoverable file actions in one bounded surface. The trusted host still owns filesystem I/O, permissions, persistence, downloads, and trash recovery.

## Product decisions

File Manager is not a code tree. Use [File Explorer](/components/file-explorer) for repository hierarchy, dirty states, and editor-focused rename flows. Use File Manager when users need familiar workspace navigation, multi-selection, sorting, import, preview, and lifecycle actions across many file types.

- Selection is local UI state; the host authorizes every mutation through a cancelable `before-*` event.
- Delete means a host-defined recoverable trash operation unless the product explicitly presents permanent deletion.
- Loading and failure states retain the current location and user search. A failed refresh does not erase a usable listing.
- Quick Look previews only trusted or sanitized content. Large, binary, or remote files use a host previewer or download action.

`useFileManager` exposes the canonical DOM controller through `ref`/`componentRef`, `ready`, event subscriptions, and `call()`. It does not mirror the file list into a second framework-only store.

## Controller contract

| Area | Contract |
| --- | --- |
| Root | `.file-manager`, preferably a `<section>` |
| Items | `data-file-item`, stable `data-file-value`, `role="option"`, and `aria-selected` |
| Methods | `select`, `clearSelection`, `getSelection`, `setFilter`, `clearFilter`, `setView`, `getView`, `openPreview`, `closePreview`, `runAction`, `setReadonly`, `setState`, `refresh`, `getState` |
| Authorization | `a3s:file-manager-before-action`, `a3s:file-manager-before-filter-change`, `a3s:file-manager-before-selection-change` |
| Observation | `a3s:file-manager-action`, `a3s:file-manager-filter-change`, `a3s:file-manager-selection-change`, `a3s:file-manager-view-change`, `a3s:file-manager-preview-change`, `a3s:file-manager-state-change` |
| States | `ready`, `loading`, `empty`, `partial`, `error`, `offline`, `permission-denied`, `readonly` |

## Accessibility and ownership

The viewport is a multi-select listbox. Arrow keys move selection, Ctrl/Cmd + A selects visible items, Enter requests open, Space requests Quick Look, Delete requests a recoverable delete, and Escape closes preview before clearing selection. Search results update the operable set without moving page scroll. The host owns path resolution, symlink policy, conflict handling, upload limits, permissions, file content, persistence, and recovery.
