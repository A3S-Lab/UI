# Component catalog

A3S UI provides 111 public component contracts. Eighty-six general components are organized by interface responsibility, while 25 components for building Coding Agent workflows live in [Harness](/harness/). Every guide includes a live preview, minimal HTML, React and Vue usage, applicable hooks or composables, states, and accessibility guidance.

## API model

A3S UI keeps parameters close to the browser platform:

| API surface           | Purpose                                      | Example                                                                 |
| --------------------- | -------------------------------------------- | ----------------------------------------------------------------------- |
| Root class            | Selects the component                        | `class="resource-card"`                                                 |
| Native attributes     | Behavior and accessibility                   | `disabled`, `checked`, `aria-current="page"`                            |
| `data-*` attributes   | Finite visual or behavioral variants         | `data-size="sm"`, `data-orientation="vertical"`                         |
| CSS custom properties | Continuous layout values and theme decisions | `--split-position: 40%`                                                 |
| Vanilla JavaScript    | Behavior the browser does not provide        | Split-pane resizing, device preview, and composite keyboard interaction |

Native elements remain the source of truth. A disabled button uses `disabled`; it does not require a library-specific boolean.

## Support matrix

| Capability            | General components          | Layout and workspace     | Harness                               |
| --------------------- | --------------------------- | ------------------------ | ------------------------------------- |
| Semantic HTML         | Required                    | Required                 | Required                              |
| Light and dark themes | Yes                         | Yes                      | Yes                                   |
| RTL logical layout    | Yes                         | Yes                      | Yes                                   |
| Responsive layout     | Component-specific          | Built in                 | Workflow-specific                     |
| Nunjucks and Jinja    | Existing templates          | HTML composition         | HTML composition                      |
| JavaScript dependency | Interactive composites only | Interactive layouts only | Execution, editing, and preview tools |

Choose the A3S style pack for new products. The inherited Vega, Nova, Maia, Lyra, Mira, Luma, Sera, and Rhea packs remain available for applications that require their established appearance.
