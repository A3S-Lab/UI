# Tree

## Usage

Tree is an A3S application component for file explorers, resource hierarchies, and nested configuration. It is intentionally distinct from Accordion: focus moves between visible nodes, selection is explicit, and branches expose a parent-child hierarchy to assistive technology.

<Steps>
  <Step title="Include CSS">

Import Tailwind and one complete A3S UI style bundle.

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

Or import only the base CSS, Tree component CSS, and one style pack.

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/tree.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

  </Step>
  <Step title="Include JavaScript">

Load the complete runtime bundle, or load the runtime before the Tree controller.

```html
<script src="/assets/js/runtime.min.js" defer></script>
<script src="/assets/js/tree.min.js" defer></script>
```

  </Step>
  <Step title="Add the tree HTML">

```html
<div class="tree" role="tree" aria-label="Project files">
  <div
    role="treeitem"
    aria-label="src"
    aria-expanded="true"
    aria-selected="false"
    data-value="src"
  >
    <div data-tree-row>
      <svg aria-hidden="true"><!-- folder icon --></svg>
      <span data-tree-label>src</span>
    </div>
    <div role="group">
      <div
        role="treeitem"
        aria-label="tree.js"
        aria-selected="true"
        data-value="src/tree.js"
      >
        <div data-tree-row>
          <svg aria-hidden="true"><!-- file icon --></svg>
          <span data-tree-label>tree.js</span>
        </div>
      </div>
    </div>
  </div>
</div>
```

  </Step>
</Steps>

<Callout title="A3S extension" icon="git-branch">
  Tree is not currently provided by the upstream systems A3S UI follows. A3S UI
  defines a small semantic HTML contract instead of porting a framework-specific
  component API.
</Callout>

### Parameters

| Markup               | Purpose                                                                                                |
| -------------------- | ------------------------------------------------------------------------------------------------------ |
| `.tree[role="tree"]` | Root composite widget. Give it an accessible name with `aria-label` or `aria-labelledby`.              |
| `[role="treeitem"]`  | One selectable node. Use `aria-selected`, optional `aria-expanded`, and optional `aria-disabled`.      |
| `[data-tree-row]`    | The visual row directly inside a tree item. Clicking an expandable row selects and toggles its branch. |
| `[role="group"]`     | Direct child group owned by an expandable tree item.                                                   |
| `[data-tree-label]`  | Primary visible label used for truncation and typeahead fallback.                                      |
| `[data-tree-meta]`   | Optional trailing metadata such as size or item count.                                                 |
| `data-value`         | Stable value returned in event details. The item `id` or label is used when omitted.                   |

The controller owns `tabindex`, synchronizes child-group visibility with `aria-expanded`, and keeps exactly one enabled visible node in the Tab order.

### JavaScript API

```js
const tree = document.querySelector("#project-tree");
const item = tree.querySelector('[data-value="src/components"]');

tree.expand(item, true);
tree.select(item, true);
tree.refresh();
```

| Method                               | Behavior                                                  |
| ------------------------------------ | --------------------------------------------------------- |
| `tree.select(item, focus = false)`   | Sets the single selected item and optionally moves focus. |
| `tree.expand(item, expanded = true)` | Opens or closes an item that directly owns a group.       |
| `tree.toggle(item)`                  | Toggles an expandable item.                               |
| `tree.refresh()`                     | Re-reads dynamically added, removed, or disabled nodes.   |

Selection emits a bubbling `change` event with `{ item, value }`. Expansion emits `a3s:tree-toggle` with `{ item, value, expanded }`.

## States and variants

### Disabled nodes

Set `aria-disabled="true"` on a tree item. Disabled nodes remain visible but are skipped by pointer interaction, arrow navigation, and typeahead.

Logical indentation, guide lines, and chevrons follow document direction. In RTL, `ArrowLeft` expands or enters a branch and `ArrowRight` collapses or returns to its parent.

## Accessibility

- Keep tree items as direct children of the root or a direct child `role="group"`.
- Give every item a concise accessible name. An explicit `aria-label` prevents descendant groups or trailing metadata from becoming part of a branch name.
- Do not place buttons, links, or form controls inside a tree row. The tree item itself owns focus and selection.
- Use Tree for hierarchical choices. Use Accordion for independent disclosure sections and Sidebar for page navigation.

| Key                        | Action                                                                         |
| -------------------------- | ------------------------------------------------------------------------------ |
| `ArrowDown` / `ArrowUp`    | Moves to the next or previous enabled visible node.                            |
| `Home` / `End`             | Moves to the first or last enabled visible node.                               |
| `ArrowRight` / `ArrowLeft` | Expands, enters, collapses, or returns to a parent; directions reverse in RTL. |
| `Enter` / `Space`          | Selects the focused node.                                                      |
| Printable characters       | Moves to the next visible node whose label starts with the typed text.         |

## React

```tsx
import { Tree, useTree } from "@a3s-lab/ui/react";

export function Example() {
  const control = useTree();
  return (
    <Tree ref={control.ref} aria-label="Project files">
      <div
        role="treeitem"
        aria-label="src"
        aria-expanded="true"
        aria-selected="false"
        data-value="src"
      >
        <div data-tree-row="">
          <svg aria-hidden="true" viewBox="0 0 16 16" width="16" height="16"><path d="M2 4h5l1 2h6v7H2z" fill="none" stroke="currentColor" /></svg>
          <span data-tree-label="">src</span>
        </div>
        <div role="group">
          <div
            role="treeitem"
            aria-label="tree.js"
            aria-selected="true"
            data-value="src/tree.js"
          >
            <div data-tree-row="">
              <svg aria-hidden="true" viewBox="0 0 16 16" width="16" height="16"><path d="M4 2h5l3 3v9H4z" fill="none" stroke="currentColor" /></svg>
              <span data-tree-label="">tree.js</span>
            </div>
          </div>
        </div>
      </div>
    </Tree>
  );
}
```

`useTree` subscribes to manifest-declared DOM events and calls only public manifest methods. The adapter creates no second, framework-only state model.
