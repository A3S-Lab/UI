# Execution Evidence

Execution Evidence records one verifiable result such as a test run, screenshot, report, trace, or accessibility snapshot.

## Usage

```html
<article class="execution-evidence" data-state="verified">
  <header>
    <h3>Component semantic coverage</h3>
    <span data-evidence-result>Verified</span>
  </header>
  <section>Observable result and provenance.</section>
  <footer>...</footer>
</article>
```

### Parameters

| API                    | Values                                                    | Purpose                       |
| ---------------------- | --------------------------------------------------------- | ----------------------------- |
| `data-state`           | `capturing`, `verified`, `unverified`, `expired`, `error` | Evidence lifecycle            |
| `data-evidence-result` | Required                                                  | Textual verification result   |
| `data-evidence-meta`   | Recommended                                               | Time, source, and environment |

## States and variants

Verified means the evidence supports the stated claim, not that the entire task is correct. Expired evidence stays visible with the condition that invalidated it.

## Accessibility

Evidence summaries use text and structured data. Screenshots need useful alternative text or an adjacent textual result.
