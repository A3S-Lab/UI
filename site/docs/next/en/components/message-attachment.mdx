# Message Attachment

Message Attachment presents a file, image, source range, or URL associated with one message. Upload and persistence remain application responsibilities.

## Usage

```html
<article class="message-attachment" data-state="complete">
  <figure aria-hidden="true">...</figure>
  <div data-attachment-identity><strong>release-notes.md</strong><span data-attachment-meta>Markdown · 12 KB</span></div>
  <button type="button" aria-label="Remove release-notes.md">...</button>
</article>
```

### Parameters

| API | Values | Purpose |
| --- | --- | --- |
| `data-state` | `ready`, `uploading`, `complete`, `missing`, `error` | Attachment lifecycle |
| `data-attachment-identity` | Required | Name and type or source range |
| `data-attachment-meta` | Optional | Size, upload progress, or path |

## States and variants

Preserve the item after upload failure so users can retry or remove it. A missing source range names the unavailable file and recovery.

## Accessibility

Removal and retry labels include the attachment name. Decorative file-kind icons stay hidden from assistive technology.
