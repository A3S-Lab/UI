# 3D Code Graph

3D Code Graph reveals entry points, modules, components, tests, and configuration relationships in a large codebase. It combines spatial exploration, search, neighbourhood highlighting, and property inspection while keeping an operable list fallback.

## Why a graph

A file tree answers where a file lives. A graph answers what a change may affect. The projection prioritizes entry points, high-degree nodes, and direct neighbours of the selection. Above 600 nodes or 4,000 edges it enters `partial`, preserves complete totals in status, and keeps search and list access available.

## Interaction and fallback

Drag to orbit, scroll or use plus and minus to zoom, use arrow keys to rotate, and press Home to reset. Selection sends a cancelable `a3s:code-graph-before-selection-change` followed by `a3s:code-graph-selection-change`. If Canvas is unavailable, the component switches to the button-based list. Accessibility never depends on Canvas hit targets.
