# Context Menu

Context Menu exposes commands tied to a file, canvas node, or data row. It supports right click, `Shift + F10`, the Menu key, arrow navigation, submenus, disabled items, and focus restoration.

## Usage

```html
<div class="context-menu">
  <div data-context-trigger tabindex="0">deployment.acl</div>
  <div data-context-content role="menu" aria-label="File actions" aria-hidden="true">
    <button type="button" role="menuitem" data-value="open">Open</button>
    <button type="button" role="menuitem" data-value="rename">Rename</button>
  </div>
</div>
```

Load `context-menu.js` after the shared runtime, or use the complete bundle.

### Parameters

| API | Purpose |
| --- | --- |
| `data-context-trigger` | Direct child that receives pointer and keyboard menu requests |
| `data-context-content[role="menu"]` | Direct-child root menu |
| `data-context-submenu` | Structural owner containing one `aria-haspopup="menu"` item and its submenu |
| `data-context-submenu-content` | Nested menu, also using `role="menu"` |
| `data-value` | Stable command value returned by selection events |
| `data-context-surface` | Makes the root fill its container for trees or canvases |

### JavaScript API

```js
const menu = document.querySelector(".context-menu");
menu.openAt(240, 160, selectedNode);
menu.close();
menu.refresh();
menu.addEventListener("a3s:context-menu-select", ({ detail }) => run(detail.value, detail.target));
```

Open, selection, and close emit `a3s:context-menu-open`, `a3s:context-menu-select`, and `a3s:context-menu-close`. The controller constrains menus to the visual viewport and closes on viewport scroll or resize.

## States and variants

Keep Context Menu commands short and directly related to the invocation target. Use Command for global navigation, Toolbar for persistent actions, and Alert Dialog for destructive confirmation. Do not open an empty menu when no contextual action applies.

## Accessibility

Focusable trigger surfaces need a name or description. Use `aria-disabled="true"` for disabled items; arrow navigation skips them. Escape closes the complete menu and restores focus. Logical direction keys swap automatically in RTL.
