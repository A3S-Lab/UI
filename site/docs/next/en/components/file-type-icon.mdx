# File Type Icon

File Type Icon gives local files a recognizable identity through a small sheet or folder shape, a semantic color, and an optional extension label. It is designed for file managers, recent-work lists, task context pickers, and editor tabs.

For workbenches that need to match A3S Office editor chrome, add `data-file-icon-style="office"`. The variant keeps the same type and size contract while placing a host-provided real icon-library glyph inside a compact rounded identity block.

## Usage

Load the component CSS after the base tokens. The host supplies the semantic type and draws the decorative sheet or folder with the documented `data-*` hooks.

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/file-type-icon.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

```html
<span class="file-type-icon" data-file-type="document" data-file-format="word" data-file-icon-size="list" aria-hidden="true">
  <svg data-file-sheet viewBox="0 0 48 56" aria-hidden="true">
    <path d="M9 2.75h19.5L40 14.25v35A4.75 4.75 0 0 1 35.25 54H9a4.75 4.75 0 0 1-4.75-4.75V7.5A4.75 4.75 0 0 1 9 2.75Z" data-file-page />
    <path d="M28.5 2.75v8.5a3 3 0 0 0 3 3H40" data-file-fold />
    <path d="M11 20.5h13M11 25.5h8" data-file-lines />
  </svg>
  <span data-file-extension>DOCX</span>
</span>
```

The Office glyph variant is host-owned (`data-file-office-glyph` may contain a Lucide or other consistent SVG glyph):

```html
<span class="file-type-icon" data-file-type="spreadsheet" data-file-format="excel" data-file-icon-style="office" data-file-icon-size="list" aria-hidden="true">
  <svg data-file-office-glyph viewBox="0 0 24 24" aria-hidden="true"><!-- host glyph --></svg>
</span>
```

### Parameters

| API | Values | Purpose |
| --- | --- | --- |
| `class="file-type-icon"` | Required | Root identity and geometry |
| `data-file-type` | `folder`, `code`, `document`, `spreadsheet`, `presentation`, `pdf`, `image`, `archive`, `media`, `file` | Semantic color family |
| `data-file-format` | `word`, `excel`, `powerpoint`, `markdown`, `pdf`, or a host-defined format | Optional Office-aligned color override |
| `data-file-icon-size` | `grid`, `list`, `navigation`, `preview` | Layout-specific size |
| `data-file-icon-style` | `office` | A3S Office rounded identity block and host glyph |
| `data-file-icon-state` | `selected`, `loading`, `disabled`, `error` | Optional visual state owned by the host |
| `data-file-extension` | Text content | Optional visible extension label |
| `data-file-folder` | SVG marker | Folder geometry root |
| `data-file-sheet` | SVG marker | File geometry root |
| `data-file-page`, `data-file-fold`, `data-file-lines` | SVG markers | Sheet sub-shapes |
| `data-file-favorite` | Marker wrapper | Optional favorite badge supplied by the host |
| `--file-color` | CSS color | Explicit semantic color override |

## States and variants

Use `folder` for directories and `file` when no stronger type is known. Use `grid` in file cards, `list` in tables and menus, `navigation` in compact sidebars, and `preview` beside a file title. Keep the extension text visible when users need to distinguish formats; the color is supplementary and must not be the only type signal.

The optional state hook is visual only. Keep the owning file row responsible
for explanatory text, permissions, retry actions, and announcements. A
`loading` icon adds a compact spinner, while `selected`, `disabled`, and
`error` provide non-color-only emphasis that can be combined with row copy.
Do not use the icon state as a substitute for `aria-busy`, `disabled`, or an
error message on the owning control.

The Office variant does not force the UI package to depend on an icon library. The host selects the glyph, but should keep one stroke system, `viewBox`, and type mapping across the product.

## Accessibility

The icon is decorative when the adjacent file name and type are already announced, so use `aria-hidden="true"`. If it conveys information without a text label, provide an accessible name on the owning file control and keep the extension visible. Do not rely on color alone. Use a real `<button>` or `<a>` for file actions; the icon root is not interactive.
