# Data Grid

Data Grid handles resource collections that need sorting, selection, bulk actions, and remote pagination. It builds on Table, Checkbox, Filter Bar, and Pagination without owning queries, authorization, or data fetching.

## Usage

Load the runtime and Data Grid controller, or use the complete JavaScript bundle.

```html
<script src="/assets/js/runtime.min.js" defer></script>
<script src="/assets/js/data-grid.min.js" defer></script>
```

```html
<section class="data-grid" data-responsive="stack" aria-labelledby="grid-title">
  <header>
    <div data-grid-identity><h2 id="grid-title">Environments</h2></div>
```

### Parameters

| API                                         | Purpose                                                                       |
| ------------------------------------------- | ----------------------------------------------------------------------------- |
| `data-grid-viewport`                        | The grid's only horizontal and vertical scroll owner                          |
| `data-grid-select` / `data-grid-select-all` | Row selection and select-all checkboxes                                       |
| `data-grid-sort="key"`                      | Updates header `aria-sort` and requests host sorting                          |
| `data-grid-row-action="command"`            | Stable row command emitted with the row and its `data-value`                  |
| `data-grid-state="state"`                   | Dedicated `loading`, `empty`, `error`, or `permission-denied` feedback region |
| `data-responsive="stack"`                   | Reflows each row into a labelled record below 640px; cells need `data-label`  |
| `--data-grid-max-height`                    | Optional maximum grid height                                                  |

### JavaScript API

```js
const grid = document.querySelector(".data-grid");
grid.setSelection(["production", "staging"]);
grid.toggleSelection("preview", true);
grid.setSort("name", "ascending");
grid.setState("loading", { message: "Refreshing environments…" });
console.log(grid.getState());
grid.addEventListener("a3s:data-grid-sort", ({ detail }) => loadPage(detail));
```

`getSelection()`, `setSelection()`, `toggleSelection()`, `selectAll()`, and `clearSelection()` keep checkboxes, selected rows, the header checkbox, and a nested Bulk Action Bar synchronized. `getSort()` and `setSort()` control one active sort. `getState()` returns view, selection, and sort snapshots; `setState()` switches feedback regions; `refresh({ preserveSelection, preserveSort })` rebinds replaced rows.

The cancelable `a3s:data-grid-before-selection-change`, `a3s:data-grid-before-sort`, and `a3s:data-grid-before-row-action` hooks run before visible state is committed. Completed events are `a3s:data-grid-selection-change`, `a3s:data-grid-sort`, `a3s:data-grid-row-action`, and `a3s:data-grid-state-change`. Details identify `previous`, `current`, `source`, and `originalEvent`; legacy `values`, `selectedCount`, `key`, and `direction` fields remain available. The controller never reorders rows, fetches data, or authorizes a command.

## States and variants

Client collections may replace rows directly. Server collections should preserve the active filter, sort, rows, and column widths during a background request. Use separate `data-grid-state="empty"`, `error`, and `permission-denied` regions so each state names the problem and recovery. Row actions are part of the grid contract rather than a separate public component.

The default narrow layout keeps horizontal scrolling. Use `data-responsive="stack"` only when a record still reads linearly. Keep scrolling for wide comparisons, editable cells, or many columns.

## Accessibility

Use real `<th>` elements and put `aria-sort` on the header rather than its button. Every checkbox needs a row-specific name. Do not move focus when bulk actions appear. Announce server result counts politely, and never discard the current selection during loading without explaining why.

## React

```tsx
import { DataGrid, useDataGrid } from "@a3s-lab/ui/react";

export function Example() {
  const control = useDataGrid();
  return (
    <DataGrid ref={control.ref} aria-label="Data Grid">Component content</DataGrid>
  );
}
```

`useDataGrid` subscribes to manifest-declared DOM events and calls only public manifest methods. The adapter creates no second, framework-only state model.
