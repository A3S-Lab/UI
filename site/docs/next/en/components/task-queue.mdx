# Task Queue

Task Queue presents work waiting behind or alongside the active task. Scheduling, concurrency, prioritization, and cancellation remain application logic.

## Usage

```html
<section class="task-queue" data-state="running" aria-labelledby="queue-title">
  <header><h2 id="queue-title">Task queue</h2><span data-queue-status>Running</span></header>
  <ol><li data-state="queued">...</li></ol>
</section>
```

### Parameters

| API | Values | Purpose |
| --- | --- | --- |
| `data-state` | `idle`, `running`, `paused`, `blocked`, `complete`, `error` | Aggregate queue state |
| Item `data-state` | `queued`, `running`, `blocked`, `complete`, `error` | Per-task state |
| `data-queue-actions` | Optional | Open, retry, cancel, or reprioritize |

## States and variants

Order must match execution order. Reordering requires an explicit handle and immediate confirmation; do not make the entire row draggable by default.

## Accessibility

Use an ordered list and textual states. Announce only meaningful queue changes, not timer updates.
