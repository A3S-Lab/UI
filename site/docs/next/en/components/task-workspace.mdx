# Task Workspace

Task Workspace keeps the title, chronological transcript, bottom composer, and optional artifact inspector in one bounded application region.

## Usage

```html
<section class="task-workspace">
  <header class="workspace-header">
    <button type="button" data-task-inspector-trigger>Open files</button>
  </header>
  <div data-task-body>
    <main data-task-main>
      <section class="agent-transcript">...</section>
      <form class="agent-composer">...</form>
    </main>
    <aside id="task-files" class="task-pane" data-task-inspector>...</aside>
  </div>
</section>
```

### Parameters

| API | Values | Purpose |
| --- | --- | --- |
| `data-task-body` | required | Owns main and inspector columns |
| `data-task-main` | required | Transcript and composer scroll contract |
| `data-task-inspector` | optional | Artifact, file, citation, or context inspector |
| `data-task-inspector-trigger` | optional | Opens or closes the responsive inspector and receives restored focus |
| `data-inspector` | `hidden`, `open`, omitted | Inspector visibility and responsive overlay state |

### JavaScript API

Import `@a3s-lab/ui/all`, or import `@a3s-lab/ui/runtime` before `@a3s-lab/ui/task-workspace`. The controller initializes each workspace once and exposes `openInspector()`, `closeInspector()`, `toggleInspector()`, and `refresh()` on the root. It dispatches `a3s:task-inspector-change` with `{ open, mode, source }` after a transition.

## States and variants

Below 900px the inspector leaves the grid and opens only when `data-inspector="open"`. Below 520px it becomes a bottom overlay. The controller marks a closed inspector `inert` and `aria-hidden="true"`, removes those attributes on open, closes on Escape or backdrop activation, and restores focus to the trigger. The transcript and composer keep their DOM order in every state. Use `data-inspector="hidden"` when the product intentionally removes the inspector at every width.

## Accessibility

Name the transcript, inspector, and controls. Return focus to the inspector trigger when it closes. Announce bounded execution status changes rather than making the whole transcript live.

## React

```tsx
import { TaskWorkspace, useTaskWorkspace } from "@a3s-lab/ui/react";

export function Example() {
  const control = useTaskWorkspace();
  return (
    <TaskWorkspace ref={control.ref}>
      <header className="workspace-header">
        <button type="button" data-task-inspector-trigger="">
          Open files
        </button>
      </header>
      <div data-task-body="">
        <main data-task-main="">
          <section className="agent-transcript">
            <article>
              <p>Review the component documentation.</p>
            </article>
          </section>
          <form className="agent-composer">
            <textarea
              aria-label="Message"
              placeholder="Describe the next task"
            ></textarea>
            <button type="submit">Send</button>
          </form>
        </main>
        <aside id="task-files" className="task-pane" data-task-inspector="">
          <h2>Files</h2>
          <a href="/src/index.ts">src/index.ts</a>
        </aside>
      </div>
    </TaskWorkspace>
  );
}
```

`useTaskWorkspace` subscribes to manifest-declared DOM events and calls only public manifest methods. The adapter creates no second, framework-only state model.
