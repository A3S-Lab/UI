## Usage

```html
<section class="catalog">
  <header>...</header>
  <div data-catalog-featured>...</div>
  <div data-catalog-toolbar>...</div>
  <div class="resource-grid" data-catalog-results>...</div>
</section>
```

### Parameters

| API | Purpose |
| --- | --- |
| `data-catalog-identity` | Title and description |
| `data-catalog-actions` | Search, sort, view, and ownership actions |
| `data-catalog-featured` | Optional horizontal featured collection |
| `data-catalog-toolbar` | Filters, result count, sort, and view controls |
| `data-catalog-results` | Resource Grid, list, table, or Empty state |

## States and variants

Keep the page skeleton stable while card content distinguishes assistants, skills, and connectors. Results must cover loading, empty, error, selected, installed, unavailable, and pagination states.

## Accessibility

Use a real search input and pressed state for toggle filters. Announce result counts after filtering without moving focus. Featured content may scroll horizontally, but the document must not overflow.
