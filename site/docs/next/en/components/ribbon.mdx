## Usage

Load the Tabs controller and combine `ribbon` with `tabs`.

```html
<div class="ribbon tabs" data-accent="blue">
  <div role="tablist" aria-label="Editor commands">...</div>
  <div role="tabpanel">
    <fieldset data-ribbon-group>
      <legend>Clipboard</legend>
      ...
    </fieldset>
  </div>
</div>
```

### Parameters

| Parameter                           | Values                              | Default     | Purpose                                |
| ----------------------------------- | ----------------------------------- | ----------- | -------------------------------------- |
| `data-accent`                       | `blue`, `green`, `orange`, `purple` | `blue`      | Product or document-kind accent        |
| `role="tablist"`                    | —                                   | Required    | Tab navigation container               |
| `aria-selected`                     | `true`, `false`                     | Required    | Active tab state                       |
| `aria-controls` / `aria-labelledby` | Element IDs                         | Required    | Associates tabs and panels             |
| `data-ribbon-group`                 | —                                   | Required    | Command group layout                   |
| `data-ribbon-controls`              | —                                   | Recommended | Aligns commands above the group legend |

## States and variants

Blue suits documents and general workspaces, green suits spreadsheets or healthy operations, orange suits presentations, and purple suits agent workflows. Disabled tabs and commands use native `disabled`.

### JavaScript API

Ribbon behavior comes from the [Tabs](/components/tabs) controller. `window.a3sUI.refresh(ribbon)` rescans dynamically added tabs. No Ribbon-specific JavaScript is required.

## Accessibility

Use the complete Tabs keyboard contract. Group commands with `<fieldset>` and a visible or screen-reader-only `<legend>`. If a ribbon becomes too dense, allow horizontal scrolling rather than shrinking labels below a readable size.
