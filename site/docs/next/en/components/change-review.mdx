# Change Review

Change Review summarizes a bounded set of proposed file changes and keeps review decisions adjacent to their scope.

## Usage

```html
<section class="change-review" data-state="reviewing" aria-labelledby="review-title">
  <header><h2 id="review-title">Review changes</h2><p data-review-summary>3 files</p></header>
  <ul data-review-files><li><code>src/app.css</code><span data-review-delta>+4 −1</span></li></ul>
  <footer>...</footer>
</section>
```

### Parameters

| API | Values | Purpose |
| --- | --- | --- |
| `data-state` | `pending`, `reviewing`, `accepted`, `rejected`, `conflict`, `error` | Review lifecycle |
| `data-review-files` | Required | Files within the decision scope |
| `data-review-summary` | Recommended | Aggregate count and delta |

## States and variants

A conflict preserves the proposed changes and explains the competing revision. File-level acceptance belongs in a richer inspector, not a hidden checkbox list.

## Accessibility

Decision buttons name their consequence. Counts and filenames remain text; additions and deletions do not depend on red and green alone.
