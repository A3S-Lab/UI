# 组合方案

当多个现有契约共同解决一个可重复任务时，组合才值得进入文档。仅仅因为其他组件库给同一段标记起了名字，并不足以新增公共根类。下面的方案会明确所有权、键盘行为和失败恢复。

## 纯图标操作与操作组

纯图标操作仍然是 Button。必须提供可访问名称，并使用图标尺寸；只有共享同一作用域的操作才能组成一组。导航触发器还需说明受控区域和展开状态。

```html
<div class="button-group" role="group" aria-label="视图控制">
  <button type="button" class="btn" data-size="icon" aria-label="刷新视图">
    <svg aria-hidden="true" viewBox="0 0 24 24">...</svg>
  </button>
  <button type="button" class="btn" data-size="icon" aria-label="打开导航" aria-controls="workspace-navigation" aria-expanded="false">
    <svg aria-hidden="true" viewBox="0 0 24 24">...</svg>
  </button>
</div>
```

不要新增会隐藏名称要求的“图标操作”组件。Tooltip 可以为使用指针的用户重复显示名称，但不能取代可访问名称。

## 原生下载操作

浏览器可以直接导航到文件时，下载就是链接。将锚点呈现为 Button，文件名、授权、进度和失败仍由宿主负责。Blob 创建或鉴权流式传输依赖网络实现，应放在应用 hook 中，不属于视觉组件。

```html
<a class="btn" href="/exports/release-report.pdf" download="release-report.pdf">
  下载报告
</a>
```

只有激活后需要启动宿主异步导出时才使用按钮。此时必须具备等待、取消、错误和重试，不能把尚未生成的导出伪装成原生下载。

## 表单对话框

短小、可中断且必须整体完成或取消的编辑使用 Dialog 与 Form。长流程或多阶段配置应放到独立页面。校验通过后才关闭；提交失败时保留输入和对话框内的焦点。

```html
<dialog class="dialog" id="rename-dialog" aria-labelledby="rename-title">
  <div>
    <header><h2 id="rename-title">重命名工作区</h2></header>
    <section>
      <form class="form" id="rename-form">
        <label class="field"><span class="label">名称</span><input class="input" name="name" required /></label>
        <div data-form-error role="alert"></div>
      </form>
    </section>
    <footer>
      <button type="button" class="btn" data-variant="outline" onclick="this.closest('dialog').close('cancel')">取消</button>
      <button type="submit" class="btn" form="rename-form">保存</button>
    </footer>
  </div>
</dialog>
```

### React

```tsx
import { Dialog, Form, useDialog } from "@a3s-lab/ui/react";

export function RenameWorkspace() {
  const dialog = useDialog();
  return (
    <>
      <button type="button" onClick={() => dialog.call("showModal")}>重命名</button>
      <Dialog ref={dialog.ref} aria-labelledby="rename-title">
        <div>
          <header><h2 id="rename-title">重命名工作区</h2></header>
          <section>
            <Form id="rename-form">
              <label className="field"><span className="label">名称</span><input className="input" name="name" required /></label>
            </Form>
          </section>
          <footer><button type="submit" form="rename-form">保存</button></footer>
        </div>
      </Dialog>
    </>
  );
}
```

### Vue

```vue

const dialog = useDialog();

    </div>
  </Dialog>
</template>
```

## 惰性忙碌区域

`aria-busy` 表达状态；只有一个有边界区域内的全部控件都必须暂时不可用时才使用 `inert`。把可读状态放在惰性子树外，让辅助技术仍可收到进度。成功或失败时同时移除两个属性，并保留已输入内容。

```html
<section aria-labelledby="import-title" aria-busy="true">
  <h2 id="import-title">正在导入记录</h2>
  <div inert><form class="form">...</form></div>
  <div class="progress" role="progressbar" aria-label="导入进度" aria-valuenow="42"><div style="width:42%"></div></div>
  <p role="status">已完成 42%，你可以离开此页面。</p>
</section>
```

Skeleton 替代未知内容形状，Progress 表达可测量任务，Spinner 标记短暂且不可测量的等待。品牌加载只用于有边界的应用启动，不用于普通数据请求。

## 编辑器命令菜单

编辑器斜杠菜单由 Command 与宿主维护的光标锚点组成。编辑器拥有文本、选区、输入法状态、几何位置和撤销；Command 只负责筛选与键盘选择。Escape 返回编辑器且不插入文本，选择项目后由编辑器执行一次事务。

```html
<div class="command" data-editor-command aria-label="插入内容块">
  <input type="search" placeholder="搜索内容块" aria-label="搜索内容块" />
  <div role="listbox"><button type="button" role="option" data-value="code">代码块</button></div>
</div>
```

## 布局基础与安全区

Flex 和 Grid 是布局基础，不是产品组件。一维对齐使用 Flex，行列共同构成结构时使用 Grid。语义顺序保留在 DOM 中，断点只改变摆放位置。

```css
.action-row { display: flex; flex-wrap: wrap; align-items: center; gap: 0.5rem; }
.resource-layout { display: grid; grid-template-columns: repeat(auto-fit, minmax(min(16rem, 100%), 1fr)); gap: 1rem; }
.mobile-action-bar { padding-block-end: max(0.75rem, env(safe-area-inset-bottom)); }
```

安全区间距只属于真正贴近屏幕边缘的 Composer、Sheet、Viewer 或操作栏，不要加到每层卡片。200% 缩放时，布局应自动回流，不能产生第二条页面级横向滚动条。

## 复用决策

| 需求 | 组合 | 边界 |
| --- | --- | --- |
| 内容表面 | Card 或 Item | 根据内容展示或可操作语义选择 |
| 可调整侧边导航 | Split Pane 内的 Sidebar | 宿主持久化宽度 |
| 通用菜单 | Dropdown Menu、Context Menu 或 Command | 根据触发方式和选择任务决定 |
| 分段选择 | Tabs 或单选 Button Group | Tabs 切换面板，按钮组修改一个值 |
| 范围和精确值 | Slider 与 Input/Field | 宿主校验并同步同一个值 |
| 滚动边缘提示 | Scroll Area 与不拦截交互的边缘阴影 | 阴影不能阻挡滚动和焦点 |
| 头像堆叠 | 多个 Avatar 与剩余数量文本 | 宿主拥有成员与溢出计数 |
| 对话内容编辑 | 单个对话回合内的 Editable Text | 宿主拥有历史和持久化 |
| Token 预算 | Status Badge 与 Progress | 始终显示数值 |
| 原生媒体 | 带名称的 figure 或 Markdown 媒体槽中的 `video` | 宿主拥有来源信任、字幕和控制项 |
