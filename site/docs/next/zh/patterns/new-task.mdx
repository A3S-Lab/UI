# 新建任务

新建任务把第一条指令、工作区、模型和权限选择放在一个安静的起始界面中。它用于创建长期任务记录之前。

## 组合结构

使用任务启动页、一个 Agent 输入框和可选建议操作。外层表单是唯一提交边界。工作区发现、模型可用性、权限执行、附件上传和任务创建由应用负责。

## 响应式行为

建议在自己的行内滚动。手机上输入器接近全宽，保留 44 像素目标，工具可以换行或滚动，但不能隐藏提交操作。

## 无障碍

为建议导航和表单提供名称。模型、权限和工作区的锚定菜单关闭后把焦点还给触发器。创建失败时保留指令与所有选择，再聚焦直接的错误摘要。预览中的建议、工作区名称和权限标签均为示例数据。
