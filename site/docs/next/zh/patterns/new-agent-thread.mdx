## 组合结构

使用一个原生 `<form>`，并组合 Field、Native Select、Radio、Item 行和 Agent Composer Section。外层 Form 是唯一提交边界。

仓库可用性验证、分支或 Worktree 创建、环境动作解析和线程启动都由应用负责，A3S UI 不执行这些操作。预览中的项目路径、状态和指令均为示例数据。

## 响应式行为

DOM 顺序中先放环境选项，再放项目详情。窄屏改为单列，并让主操作位于指令之后。Windows 长路径、UNC、Unicode 和含空格路径必须在项目控件中换行或截断，且不得导致文档级横向溢出。

## 无障碍

互斥环境使用带 Legend 的 Fieldset 分组。禁用环境需要可见原因。提交后若设置失败，保留全部选择和第一条指令，然后把焦点移到与失败字段关联的错误摘要。
