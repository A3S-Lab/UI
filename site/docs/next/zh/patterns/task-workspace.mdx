## 组合结构

```text
App Shell
├── Activity Bar：入口、近期任务和项目
└── 任务工作区
    ├── 工作区标题栏
    ├── 任务记录
    │   ├── 消息状态、附件与引用
    │   ├── 任务计划 + 计划步骤
    │   ├── 工具调用、执行项与审批请求
    │   └── 终端、执行证据、产物卡与后续建议
    ├── Agent 输入框
    └── 任务窗格
        ├── 上下文选择器
        ├── 任务队列
        ├── 检查点
        └── 变更审阅
```

任务历史、计划转换、执行传输、权限策略、审批、文件变更、证据留存和持久化仍由宿主应用负责。预览中的名称、路径、数量和结果均为示例数据。

## 响应式行为

- 低于 768 像素时，App Shell 导航变为有边界的抽屉，关闭后退出布局。
- 低于 900 像素时，检查器退出网格，作为任务窗格浮层打开。
- 低于 520 像素时，检查器从底部打开，输入器保留安全区间距。
- 任务记录、输入器和检查器保持原有 DOM 顺序。较长的工具、终端、队列和变更内容在声明的滚动区域内滚动。

## 无障碍

为任务导航、任务记录、检查器、上下文控件和输入器提供名称。标记当前入口和计划步骤。关闭导航或检查器浮层后恢复焦点。只播报有边界的消息、执行、审批、队列和检查点变化，不把整段任务记录或终端输出设为实时区域。
