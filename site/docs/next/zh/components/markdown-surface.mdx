# Markdown 内容面

为已净化的 Markdown 输出提供一致的阅读层级、代码、表格、媒体和自定义渲染槽。

<Preview class="w-full">
<article class="markdown-surface"><h2>Run summary</h2><p>The task completed with <strong>three verified changes</strong>.</p><pre tabIndex="0"><code>npm run release:check</code></pre><blockquote>Review generated output before publishing.</blockquote></article>
</Preview>

## 使用方式

```html
<article class="markdown-surface">
  <h2>Run summary</h2><p>The task completed with <strong>three verified changes</strong>.</p><pre tabindex="0"><code>npm run release:check</code></pre><blockquote>Review generated output before publishing.</blockquote>
</article>
```

## React

```tsx
import { MarkdownSurface } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <MarkdownSurface>
      <h2>Run summary</h2><p>The task completed with <strong>three verified changes</strong>.</p><pre tabIndex="0"><code>npm run release:check</code></pre><blockquote>Review generated output before publishing.</blockquote>
    </MarkdownSurface>
  );
}
```

该组件没有额外行为控制器，React 适配器只渲染标准语义根。

## 产品边界

组件不解析不可信 HTML，不加载远程渲染器，也不决定链接是否安全。图表、数学与媒体插槽由宿主显式注册。

组件只发布可复用的交互边界。数据获取、持久化、权限、可信内容与业务实体继续由宿主产品拥有。

## 可访问性

标题层级保持连续，链接可见且可聚焦，代码方向从左到右。表格和代码在窄屏拥有自己的滚动边界。
