## 用途

<Steps>
  <Step title="Include CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者仅导入基本 CSS、面包组件 CSS 和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/breadcrumb.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="Add your breadcrumb HTML">

使用带有有序列表的导航地标。用 `aria-current="page"` 标记当前页面。

```html
<nav class="breadcrumb" aria-label="Breadcrumb">
  <ol>
    <li><a href="#">Home</a></li>
    <li aria-hidden="true"><svg data-rtl-flip class="lucide lucide-chevron-right" ...></svg></li>
    <li><span aria-current="page">Breadcrumb</span></li>
  </ol>
</nav>
```

  </Step>
</Steps>

## HTML结构

- `nav.breadcrumb` 是根地标，应包含 `aria-label="面包屑"`。
- `ol` 包含按层次结构顺序排列的面包屑项目。
- `li > a` 代表可导航的祖先。
- `li[aria-hidden="true"]` 表示视觉分隔符。
- `[aria-current="page"]` 代表当前页面。
- `li > span[aria-hidden="true"]` 表示折叠的省略号。

面包屑项目始终保持在同一命令行中。当可用宽度小于完整路径时，有序列表会横向滚动，不会把分隔符换到下一行。对于持续狭窄的界面，应折叠中间层级。
