# 滑块

滑块让用户在连续或分段范围内快速调整数值，适合结果可即时感知、无需精确键入的设置。

  <SliderDemo />
</Preview>

## 用法

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者仅导入基本 CSS、重新组件 CSS 和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/range.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

滑块使用 Range 组件 CSS。

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="引入 JavaScript">

复制或提供完整的 A3S UI JavaScript 包。

```html
<script src="/assets/js/all.min.js" defer></script>
```

或者复制或提供 A3S UI 运行时和脚本。

```html
<script src="/assets/js/runtime.min.js" defer></script>
<script src="/assets/js/range.min.js" defer></script>
```

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="添加滑块 HTML">

Use a native `<input type="range" class="input">`. Include `range.js` so A3S UI can keep the filled track in sync with the input value.

```html
<input type="range" class="input w-full" aria-label="音量" min="0" max="100" value="50" />
```

  </Step>
</Steps>

### HTML 结构

<dl>
  <dt><code>&lt;input type="range" class="input"&gt;</code></dt>
  <dd>Native range input styled as a slider. Width utilities such as <code>w-full</code> can be added directly.</dd>
</dl>

A3S UI 有意采用原生范围输入控件。与 shadcn/ui 的 Base UI Slider 不同，它不支持多个滑块手柄或垂直方向。

## React

```tsx
import { Slider, useSlider } from "@a3s-lab/ui/react";

export function Example() {
  const control = useSlider();
  return (
    <Slider ref={control.ref} aria-label="名称" />
  );
}
```

`useSlider` 订阅清单中声明的 DOM 事件，并且只调用清单中公开的方法。适配器不创建另一套框架专属状态。

## Vue

```vue
<script setup>
import { Slider, useSlider } from "@a3s-lab/ui/vue";

const control = useSlider();
const componentRef = control.componentRef;
</script>

<template>
  <Slider ref="componentRef" aria-label="名称" />
</template>
```

`useSlider` 订阅清单中声明的 DOM 事件，并且只调用清单中公开的方法。适配器不创建另一套框架专属状态。
