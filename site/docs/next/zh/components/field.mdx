## 用途

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者只导入基础 CSS、字段组件 CSS 和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/field.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用 CDN 或打包工具导入？请参阅[安装页](/installation)。

  </Step>
  <Step title="添加字段 HTML">

单个控件使用 `class="field"`，相关控件组使用 `class="fieldset"`。需要 `<legend>` 标题时使用原生 `<fieldset>`；其他情况使用带标签的 `role="group"`。

```html
<fieldset class="fieldset">
  <legend>个人资料</legend>
  <p>这些信息会显示在账单和邮件中。</p>
  <div role="group" aria-label="个人资料字段">
    <div role="group" class="field">
      <label for="name">姓名</label>
      <input id="name" autocomplete="off" placeholder="王小明" />
      <p>这些信息会显示在账单和邮件中。</p>
    </div>
    <div role="group" class="field" data-invalid>
      <label for="username">用户名</label>
      <input id="username" autocomplete="off" aria-invalid="true" aria-describedby="username-error" />
      <p id="username-error" role="alert">请换一个用户名。</p>
    </div>
    <div role="group" class="field" data-orientation="horizontal">
      <input id="newsletter" type="checkbox" role="switch" />
      <label for="newsletter">订阅新闻邮件</label>
    </div>
  </div>
</fieldset>
```

  </Step>
</Steps>

### HTML 结构

<dl>
  <dt><code>&lt;fieldset class="fieldset"&gt;</code></dt>
  <dd>相关字段的原生分组。使用 <code>&lt;legend&gt;</code> 作为标题，并用紧随其后的 <code>&lt;p&gt;</code> 提供说明。</dd>
  <dt><code>&lt;div role="group" class="fieldset"&gt;</code></dt>
  <dd>不适合使用 <code>&lt;fieldset&gt;</code> 时的结构分组。请添加 <code>aria-label</code> 或 <code>aria-labelledby</code>。</dd>
  <dt><code>&lt;div role="group" class="field"&gt;</code></dt>
  <dd>单个字段的容器。需要时添加 <code>data-orientation</code>。</dd>
  <dt><code>&lt;label&gt;</code></dt>
  <dd>控件标签。控件有 <code>id</code> 时，请用 <code>for</code> 与其关联。</dd>
  <dt><code>&lt;input&gt;</code>, <code>&lt;select&gt;</code>, <code>&lt;textarea&gt;</code></dt>
  <dd>原生表单控件。请将 <code>aria-invalid="true"</code> 添加到无效控件本身，而不只是外层容器。</dd>
  <dt><code>&lt;section&gt;</code></dt>
  <dd>控件与文字并排时，可用它包裹标签和说明。</dd>
  <dt><code>&lt;p&gt;</code></dt>
  <dd>帮助或错误文本。校验错误使用 <code>role="alert"</code>，并通过 <code>aria-describedby</code> 与控件关联。</dd>
</dl>

</Preview>
