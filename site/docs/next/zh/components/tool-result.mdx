# 工具结果

工具结果在一次调用完成后，把主要结果、诊断信息和结构化元数据放在同一可切换区域。它适合输出类型明确、用户需要比较多个视图的结果；简单的一行成功信息仍留在工具调用摘要中。

## 信息架构

第一个标签必须是用户最常用的判断视图，而不是机械地把 `stdout` 放在最前。标签页只用于同一结果的平级表示，例如摘要、输出、差异、预览和元数据；重试、下载、打开文件等命令放在页头动作区。

加载、空结果和错误都保留页头身份与状态。错误页提供原因和恢复动作，不能显示一个空白输出标签。二进制、图片或超大文件使用专门预览器或下载链接，不把整个资源塞进 DOM。

## 控制器与状态

工具结果复用 Tabs 的 `select(tab, focus)` 和 `refresh()`，并发送相同的可取消切换事件。根状态为 `ready`、`loading`、`empty` 或 `error`；标签选择是内部视图状态，不能覆盖结果是否可用。

## 无障碍

标签、面板、`aria-controls` 和 `aria-labelledby` 必须一一对应。方向键、Home 和 End 在标签列表内移动，非活动标签使用 `tabindex="-1"`，隐藏面板使用原生 `hidden`。页头状态、结果数量和退出码必须有文本，不依赖绿色或红色。
