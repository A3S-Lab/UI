# 折叠面板

折叠面板把相关但不需要同时阅读的内容收纳在一组标题下，适合减少页面长度，同时保留清晰的信息层级。

## 用法

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者仅导入基础 CSS、折叠面板组件 CSS 和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/accordion.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用 CDN 或包管理器集成时，请参见[安装页](/installation)。

  </Step>
  <Step title="引入 JavaScript">

复制或提供完整的 A3S UI JavaScript 包。

```html
<script src="/assets/js/all.min.js" defer></script>
```

或者仅加载 A3S UI 运行时和折叠面板脚本。

```html
<script src="/assets/js/runtime.min.js" defer></script>
<script src="/assets/js/accordion.min.js" defer></script>
```

使用 CDN 或包管理器集成时，请参见[安装页](/installation)。

  </Step>
  <Step title="添加折叠面板 HTML">

```html
<section class="accordion">
  <details open>
    <summary>
      是否支持键盘操作？
      <svg class="lucide lucide-chevron-down" xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m6 9 6 6 6-6" /></svg>
    </summary>
    <section>支持。组件保留原生详情元素的展开状态、焦点顺序与键盘行为。</section>
  </details>
</section>
```

  </Step>
</Steps>

A3S UI 保留原生 `<details>` 与 `<summary>` 的披露语义。脚本默认只允许打开一个项目，并阻止不可用项目切换；需要同时展开多个项目时，在根元素上添加 `data-multiple`。

### HTML 结构

<dl>
  <dt><code>&lt;section class="accordion"&gt;</code></dt>
  <dd>
    折叠面板根容器。添加 <code>data-multiple</code> 后可同时展开多个项目。
    <dl>
      <dt><code>&lt;details open&gt;</code></dt>
      <dd>
        单个折叠项目。用原生 <code>open</code> 设置初始展开项；项目不可切换时添加 <code>aria-disabled="true"</code>。
        <dl>
          <dt><code>&lt;summary&gt;</code></dt>
          <dd>折叠触发器。始终保留可见标题；尾部图标只辅助表达方向。</dd>
          <dt><code>&lt;section&gt;</code></dt>
          <dd>展开内容。根据内容选择合适的语义元素，不需要额外角色。</dd>
        </dl>
      </dd>
    </dl>
  </dd>
</dl>

### JavaScript API

折叠面板不公开自定义方法或事件。需要编程控制时，直接读写原生 `details.open` 布尔值。

```js
document.querySelector("#deployment-details").open = true;
```

## React

```tsx
import { Accordion, useAccordion } from "@a3s-lab/ui/react";

export function Example() {
  const control = useAccordion();
  return (
    <Accordion ref={control.ref} aria-label="发布说明">
      <details open>
        <summary>
          如何撤销发布？
          <svg aria-hidden="true" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2">
            <path d="m6 9 6 6 6-6" />
          </svg>
        </summary>
        <section>选择目标版本，确认受影响实例后发起回滚。</section>
      </details>
    </Accordion>
  );
}
```

`useAccordion` 订阅清单中声明的 DOM 事件，并且只调用清单中公开的方法。适配器不创建另一套框架专属状态。

## 可访问性

保留原生 `<details>` 与 `<summary>`，不要用普通容器模拟展开状态。标题必须可见且能独立说明内容；图标使用 `aria-hidden="true"`，不能替代标题。不可切换的项目同时设置 `aria-disabled="true"`，并由控制器阻止指针和键盘切换。展开状态由浏览器暴露，宿主只在状态变化需要跨区域反馈时增加简短播报。
