## 用法

```html
<details class="tool-call" data-state="success">
  <summary><span data-tool-identity><strong>读取仓库状态</strong><small>shell</small></span><span data-tool-status>成功</span></summary>
  <section><pre data-tool-input>...</pre><pre data-tool-output>...</pre></section>
</details>
```

### 参数

| API | 取值 | 用途 |
| --- | --- | --- |
| 根 `<details>` | 必须 | 原生折叠行为 |
| `data-state` | `queued`、`running`、`waiting`、`success`、`cancelled`、`error` | 调用状态 |
| `data-tool-input` | 可选 | 结构化参数 |
| `data-tool-output` | 可选 | 结构化结果或错误 |

## 状态与变体

输入输出结构本身重要时使用工具调用。更高层操作使用执行项，持续命令输出使用终端。

## 无障碍

可见标题在不依赖提供方或图标的情况下说明操作。渲染输入或输出前必须移除敏感信息。
