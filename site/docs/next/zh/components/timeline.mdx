# 时间线

Timeline 按顺序组织持久操作、部署与 Agent 语义事件，不限定应用如何管理状态。

## 用法

导入完整样式包，或把 Timeline 与每个条目所用的组件组合导入。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

```html
<ol class="timeline" aria-label="执行历史">
  <li data-state="success">
    <article class="item" data-variant="outline">…</article>
  </li>
  <li data-state="active" aria-current="step">
    <article class="item" data-variant="outline">…</article>
  </li>
</ol>
```

### 参数

| API                   | 值                                       | 用途                       |
| --------------------- | ---------------------------------------- | -------------------------- |
| `class="timeline"`    | 必需                                     | 有序时间线根元素           |
| `data-marker`         | 短文本或数字                             | 用紧凑标记替代圆点         |
| `data-state`          | `active`、`success`、`warning`、`danger` | 语义标记颜色               |
| `aria-current="step"` | 原生 ARIA                                | 标识当前步骤并应用活动状态 |

## 状态与变体

由宿主应用把领域状态映射到四种语义状态，不要把每个后端状态都变成样式 API。中性或未来事件省略 `data-state`；同时使用文本或 Badge，不能只靠颜色表达状态。

## 可访问性

顺序有意义时使用 `<ol>`，时间戳使用 `<time datetime="…">`。当前状态通过 `aria-current="step"` 明确表达。Timeline 仅提供 CSS；焦点、选择与实时播报仍由宿主应用负责。

## React

```tsx
import { Timeline } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <Timeline aria-label="Timeline"><li>组件内容</li></Timeline>
  );
}
```

适配器只替换指南中已记录的语义根元素，不增加包装层；内部标记继续使用上方 HTML 契约。
