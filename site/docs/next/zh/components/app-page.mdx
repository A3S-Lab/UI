# 应用页面

应用页面为 App Shell 内的项目、自动化、目录、表单和详情页提供开放且有宽度约束的页面框架。它稳定放置页面身份与操作，不会给整个视图再套一层卡片。

## 用法

```html
<section class="app-page" data-width="wide">
  <header>
    <div data-page-identity><h1>项目</h1><p>长期工作上下文。</p></div>
    <div data-page-actions>...</div>
  </header>
  <div data-page-content>...</div>
</section>
```

### 参数

| API | 可选值 | 用途 |
| --- | --- | --- |
| `class="app-page"` | 必填 | 开放式应用页面框架 |
| `data-page-identity` | 必填 | 标题和简短说明 |
| `data-page-actions` | 可选 | 页面级主要和次要操作 |
| `data-page-content` | 必填 | 页面内容 |
| `data-width` | `reading`、`wide`、省略 | 内容阅读宽度 |

## 状态和变体

空状态、加载、错误、部分数据和权限状态由 Empty、Skeleton、Alert、Resource Card、Table 或表单组件承担。不要再增加通用页面卡片。

## 无障碍

使用符合外层文档结构的标题级别。操作在 DOM 中位于页面身份之后，窄屏堆叠时保持同一顺序。

## React

```tsx
import { AppPage } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <AppPage aria-label="App Page">组件内容</AppPage>
  );
}
```

适配器只替换指南中已记录的语义根元素，不增加包装层；内部标记继续使用上方 HTML 契约。
