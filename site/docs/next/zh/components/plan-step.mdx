# 计划步骤

计划步骤是任务计划中的一个可观察工作单元，包含稳定标题、可选描述、状态和一个有限操作。

## 用法

```html
<li class="plan-step" data-state="active" aria-current="step">
  <span data-plan-marker aria-hidden="true">2</span>
  <div data-step-identity><h3>验证响应式行为</h3><p data-step-description>...</p></div>
  <span data-plan-step-status>进行中</span>
</li>
```

### 参数

| API | 取值 | 用途 |
| --- | --- | --- |
| `data-state` | `pending`、`active`、`complete`、`blocked`、`error`、`skipped` | 步骤状态 |
| `data-plan-marker` | 可选 | 紧凑索引或图标 |
| `data-step-identity` | 必须 | 标题和可选描述 |
| `data-plan-step-status` | 推荐 | 文本状态 |

## 状态与变体

等待外部输入或审批且之后可恢复时使用 `blocked`。执行失败且需要恢复操作时使用 `error`。

## 无障碍

有序列表已经表达位置时，索引标记应作为装饰。阻塞、错误和完成状态不能只靠颜色表达。
