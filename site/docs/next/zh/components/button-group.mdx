# 按钮组

按钮组把同一任务中相邻、同级的操作连接成一个视觉单元，同时保留每个按钮独立的名称、焦点和行为。

<Preview>
<div role="group" aria-label="编辑操作" class="button-group">
  <button type="button" class="btn" data-variant="outline">撤销</button>
  <button type="button" class="btn" data-variant="outline">重做</button>
  <button type="button" class="btn" data-variant="outline" data-size="icon" aria-label="更多编辑操作"><svg aria-hidden="true" xmlns="http://www.w3.org/2000/svg" width="18" height="18" viewBox="0 0 24 24" fill="currentColor"><circle cx="5" cy="12" r="1.5"/><circle cx="12" cy="12" r="1.5"/><circle cx="19" cy="12" r="1.5"/></svg></button>
</div>
</Preview>

## 用法

导入按钮组、按钮和一个完整视觉样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/button-group.css";
@import "@a3s-lab/ui/components/button.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

只有命令属于同一任务且视觉上需要连接时才分组。根元素使用 `role="group"` 和能说明共同目的的名称。

```html
<div role="group" aria-label="编辑操作" class="button-group">
  <button type="button" class="btn" data-variant="outline">撤销</button>
  <button type="button" class="btn" data-variant="outline">重做</button>
</div>
```

### 参数

| API | 取值 | 用途 |
| --- | --- | --- |
| `class="button-group"` | 必填 | 连接直接子控件的边界 |
| `role="group"` | 推荐 | 声明相关操作集合 |
| `aria-label` 或 `aria-labelledby` | 推荐 | 说明整组任务 |
| `data-orientation` | `horizontal`、`vertical` | 省略时为水平方向 |
| 直接子 `hr[role="separator"]` | 可选 | 为拆分操作提供视觉分隔 |

## 状态与变体

### 水平与垂直

水平组适合工具栏中的相邻命令；垂直组只适合空间或任务顺序本身要求纵向排列的场景。尺寸由每个子按钮统一设置，不能在同一组中混用高度。

<Preview>
<div class="flex flex-wrap items-start gap-6">
  <div role="group" aria-label="缩放" class="button-group">
    <button type="button" class="btn" data-size="sm" data-variant="outline">75%</button>
    <button type="button" class="btn" data-size="sm" data-variant="outline">100%</button>
    <button type="button" class="btn" data-size="sm" data-variant="outline">适合宽度</button>
  </div>
  <div role="group" aria-label="对象顺序" class="button-group" data-orientation="vertical">
    <button type="button" class="btn" data-size="sm" data-variant="outline">上移一层</button>
    <button type="button" class="btn" data-size="sm" data-variant="outline">下移一层</button>
  </div>
</div>
</Preview>

### 拆分操作

拆分按钮由一个可直接执行的主命令和一个打开备选菜单的按钮组成。两者必须有不同名称；附加按钮使用 `aria-haspopup="menu"`，并组合[下拉菜单](/components/dropdown-menu)的控制器。

<Preview>
<div role="group" aria-label="保存选项" class="button-group">
  <button type="button" class="btn">保存</button>
  <hr role="separator" />
  <button type="button" class="btn" data-size="icon" aria-label="选择保存方式" aria-haspopup="menu" aria-expanded="false"><svg aria-hidden="true" xmlns="http://www.w3.org/2000/svg" width="18" height="18" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><path d="m6 9 6 6 6-6"/></svg></button>
</div>
</Preview>

按钮组不管理选择状态，也不实现方向键漫游。互斥视图切换使用 Tabs 或分段控件；格式开关集合使用 Toggle Group；文本框与前后缀操作优先使用[输入组](/components/input-group)。不要把无关命令仅为了减少间距而塞进同一组。

### RTL

按钮组遵循 DOM 的逻辑顺序，不主动倒置命令。返回、前进等方向图标由宿主在 RTL 中翻转；保存、删除、加号等对象图标保持不变。

## React

```tsx
import { Button, ButtonGroup } from "@a3s-lab/ui/react";

export function EditActions() {
  return (
    <ButtonGroup role="group" aria-label="编辑操作">
      <Button type="button" data-variant="outline">撤销</Button>
      <Button type="button" data-variant="outline">重做</Button>
      <Button
        type="button"
        data-variant="outline"
        data-size="icon"
        aria-label="更多编辑操作"
      >
        <svg aria-hidden="true" viewBox="0 0 24 24">
          <circle cx="5" cy="12" r="1.5" />
          <circle cx="12" cy="12" r="1.5" />
          <circle cx="19" cy="12" r="1.5" />
        </svg>
      </Button>
    </ButtonGroup>
  );
}
```

`ButtonGroup` 只提供排列和边界连接，不维护命令状态，因此不提供组件 hook。事件仍由每个 `Button` 处理。

## Vue

```vue
<script setup>
import { Button, ButtonGroup } from "@a3s-lab/ui/vue";
</script>

<template>
  <ButtonGroup role="group" aria-label="编辑操作">
    <Button type="button" data-variant="outline">撤销</Button>
    <Button type="button" data-variant="outline">重做</Button>
    <Button
      type="button"
      data-variant="outline"
      data-size="icon"
      aria-label="更多编辑操作"
    >
      <svg aria-hidden="true" viewBox="0 0 24 24">
        <circle cx="5" cy="12" r="1.5" />
        <circle cx="12" cy="12" r="1.5" />
        <circle cx="19" cy="12" r="1.5" />
      </svg>
    </Button>
  </ButtonGroup>
</template>
```

Vue 适配器输出相同的组语义与直接子按钮，不增加包装层。

## 可访问性

每个按钮都必须保留独立、明确的可访问名称，整组再用 `aria-label` 或 `aria-labelledby` 说明共同任务。按钮组不会把多个按钮变成一个 Tab 停靠点，用户仍按正常顺序访问每个可用控件。禁用状态应施加在具体按钮上；不要禁用根组来掩盖每个命令的真实可用性。仅图标按钮必须命名，视觉分隔符从可访问性树中移除，拆分按钮的菜单触发器同步 `aria-expanded`。触控设备上的每个子按钮仍需达到最小目标尺寸。
