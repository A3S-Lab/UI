## 用途

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者只导入基础 CSS、所需组件 CSS 和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/button-group.css";
@import "@a3s-lab/ui/components/button.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

按钮组负责连接子控件的边界与交互状态。

使用 CDN 或打包工具导入？请参阅[安装页](/installation)。

  </Step>
  <Step title="添加按钮组 HTML">

将相关控件包装在 `button-group` 中。

```html
<div role="group" aria-label="消息操作" class="button-group">
  <button type="button" class="btn" data-variant="outline">归档</button>
  <button type="button" class="btn" data-variant="outline">举报</button>
</div>
```

  </Step>
</Steps>

使用 `data-orientation="vertical"` 垂直堆叠项目。拆分操作等场景需要可见分隔线时，在项目之间添加 `<hr role="separator" />`。非交互文本片段可使用直接子元素 `<span>`、`<label>` 或 `<output>`；直接子元素 `<div>` 不附加样式，可用于自定义布局。
