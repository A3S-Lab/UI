# 命令面板

命令面板让用户通过搜索快速定位并执行操作，适合键盘优先的导航、切换和高频工作流。它应提供可预测的命令名称、清晰的分组与快捷键，而不是承担复杂表单或长篇内容。

## 用法

<Callout title="支持模板宏" icon="code" action={{ label: "查看模板", href: "/templates#command" }}>
该组件为 Jinja 和 Nunjucks 提供 `command()` 和 `command_dialog()` 宏。
</Callout>

<Steps>
  <Step title="引入样式">

导入 Tailwind 和完整样式包：

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

拆分导入时，同时包含基础层、命令面板结构与主题样式：

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/command.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

  </Step>
  <Step title="引入脚本">

使用完整运行时：

```html
<script src="/assets/js/all.min.js" defer></script>
```

拆分加载时，同时引入共享运行时和命令面板控制器：

```html
<script src="/assets/js/runtime.min.js" defer></script>
<script src="/assets/js/command.min.js" defer></script>
```

  </Step>
  <Step title="添加语义化结构">

### HTML 结构

<dl>
  <dt><code>&lt;dialog class="command-dialog"&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
  <dd>模态命令面板容器。直接子元素应为 <code>.command</code>，并通过 <code>aria-label</code> 或 <code>aria-labelledby</code> 提供名称。</dd>
  <dt><code>&lt;div class="command"&gt;</code></dt>
  <dd>
    命令面板根元素。设置 <code>data-filter="manual"</code> 可由应用接管远程搜索或索引过滤。
    <dl>
      <dt><code>&lt;header&gt;</code></dt>
      <dd>搜索图标和输入框的容器。</dd>
      <dt><code>&lt;input role="combobox"&gt;</code></dt>
      <dd>命令搜索框。使用 <code>aria-controls</code> 指向命令列表，并保持 <code>aria-expanded</code> 与列表状态一致。</dd>
      <dt><code>&lt;div role="menu"&gt;</code></dt>
      <dd>命令列表；通过 <code>data-empty</code> 提供本地化的无结果文案。</dd>
      <dt><code>&lt;div role="group"&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
      <dd>组织相关命令；组内全部命令被过滤后会自动隐藏。</dd>
      <dt><code>&lt;span role="heading"&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
      <dd>命令组标题，应由父级的 <code>aria-labelledby</code> 引用。</dd>
      <dt><code>&lt;div role="menuitem"&gt;</code></dt>
      <dd>可执行操作。导航命令使用 <code>&lt;a role="menuitem"&gt;</code>；不可用操作使用 <code>aria-disabled="true"</code>。</dd>
      <dt><code>&lt;span data-shortcut&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
      <dd>位于行尾的快捷键提示。</dd>
      <dt><code>&lt;hr role="separator"&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
      <dd>命令组之间的分隔线；搜索期间会自动隐藏。</dd>
    </dl>
  </dd>
</dl>

### JavaScript API

| API | 类型 | 描述 |
| --- | --- | --- |
| `command.refresh()` | 方法 | 动态添加、移除或重命名命令后，重新扫描当前列表。 |

## React

```tsx
import { Command, useCommand } from "@a3s-lab/ui/react";

export function ProjectCommands() {
  const command = useCommand();

  return (
    <Command ref={command.ref} className="border" aria-label="项目命令">
      <header>
        <svg aria-hidden="true" viewBox="0 0 16 16" width="16" height="16"><circle cx="7" cy="7" r="4" fill="none" stroke="currentColor" /><path d="m10 10 3 3" stroke="currentColor" /></svg>
        <input
          id="project-command-input"
          type="text"
          role="combobox"
          aria-label="命令搜索"
          aria-expanded="true"
          aria-controls="project-command-menu"
          placeholder="输入命令或搜索…"
        />
      </header>
      <div id="project-command-menu" role="menu" data-empty="没有匹配结果。">
        <div role="menuitem" data-filter="打开项目 Open project">打开项目</div>
        <div role="menuitem" data-filter="新建任务 New task">新建任务</div>
      </div>
    </Command>
  );
}
```

`useCommand` 提供组件引用、就绪状态和 `call("refresh")`。动态增删命令后调用 `refresh`，无需维护第二套框架专属过滤状态。
