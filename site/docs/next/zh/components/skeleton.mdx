# 骨架

骨架屏在内容结构已知但数据尚未到达时保留布局，减少跳动并传达加载进度。

<Preview>
<div class="flex items-center gap-4">
  <div class="skeleton size-10 shrink-0 rounded-full"></div>
  <div class="grid gap-2">
    <div class="skeleton h-4 w-[250px]"></div>
    <div class="skeleton h-4 w-[200px]"></div>
  </div>
</div>
</Preview>

## 用法

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者只导入基本CSS、组件组件CSS和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/skeleton.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="添加骨架屏 HTML">

添加具有大小调整工具类的 `class="skeleton"` 以创建加载占位符。

```html
<div class="skeleton h-4 w-[150px]"></div>
```

  </Step>
</Steps>

## React

```tsx
import { Skeleton } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <Skeleton>组件内容</Skeleton>
  );
}
```

适配器只替换指南中已记录的语义根元素，不增加包装层；内部标记继续使用上方 HTML 契约。

## Vue

```vue
<script setup>
import { Skeleton } from "@a3s-lab/ui/vue";

</script>

<template>
  <Skeleton>组件内容</Skeleton>
</template>
```

适配器只替换指南中已记录的语义根元素，不增加包装层；内部标记继续使用上方 HTML 契约。
