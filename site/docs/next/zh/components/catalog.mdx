## 用法

目录根节点只拥有页面排列。搜索、筛选、排序、安装和数据请求仍由宿主实现；结果项组合[资源卡片](/components/resource-card)、列表或表格。

```html
<section class="catalog" aria-labelledby="capability-catalog-title">
  <header>
    <div data-catalog-identity>
      <h1 id="capability-catalog-title">能力</h1>
      <p>查找可复用的技能、连接器和工作模板。</p>
    </div>
    <div data-catalog-actions>
      <label for="capability-search">搜索能力</label>
      <input
        class="input"
        id="capability-search"
        type="search"
        placeholder="搜索名称或用途"
      />
    </div>
  </header>
  <div data-catalog-toolbar>
    <div data-catalog-filters aria-label="能力类型"></div>
    <div data-catalog-actions>
      <output data-catalog-count>12 项能力</output>
    </div>
  </div>
  <div data-catalog-results aria-label="能力结果"></div>
</section>
```

### 参数

| API | 必填 | 用途 |
| --- | --- | --- |
| `data-catalog-identity` | 是 | 页面标题与简短说明 |
| `data-catalog-actions` | 否 | 搜索、排序、视图或所有权操作 |
| `data-catalog-featured` | 否 | 数量有限且确实需要强调的精选集合 |
| `data-catalog-toolbar` | 推荐 | 筛选、结果数量与排序 |
| `data-catalog-filters` | 否 | 一组具有可见选中状态的筛选器 |
| `data-catalog-count` | 推荐 | 筛选后的结果数量 |
| `data-catalog-results` | 是 | 网格、列表、表格或状态反馈 |

## 状态与变体

`ready` 显示稳定结果；`loading` 保留标题、筛选器和结果区域尺寸；`empty` 解释当前条件没有匹配项并提供清除筛选；`error` 说明失败原因和重试路径；`partial` 表明仍在分页或加载更多结果。

精选区不是永久广告位。只保留少量、可解释的推荐，并在手机上堆叠为完整条目；不要用被裁切的横向卡片掩盖主要结果。目录中不同资源类型共享搜索与选择规则，类型差异由可见元数据表达。

## React

```tsx
import { useState } from "react";
import { Catalog, useCatalog } from "@a3s-lab/ui/react";

export function CapabilityCatalog() {
  const [query, setQuery] = useState("");
  const control = useCatalog({
    events: {
      input(event) {
        const target = event.target as HTMLInputElement;
        if (target.type === "search") setQuery(target.value);
      },
    },
  });

  return (
    <Catalog ref={control.ref} aria-labelledby="catalog-title">
      <header>
        <div data-catalog-identity>
          <h1 id="catalog-title">能力</h1>
          <p>查找可复用的技能、连接器和工作模板。</p>
        </div>
        <div data-catalog-actions>
          <label htmlFor="catalog-search">搜索能力</label>
          <input
            id="catalog-search"
            className="input"
            type="search"
            defaultValue=""
          />
        </div>
      </header>
      <div data-catalog-toolbar>
        <output data-catalog-count>1 项能力</output>
      </div>
      <div data-catalog-results>
        <article className="resource-card"><h2>代码审查</h2></article>
      </div>
    </Catalog>
  );
}
```

`useCatalog` 在目录根节点统一观察标准 `input` 事件，没有控制器方法。这里让 hook 成为查询状态的唯一更新路径；普通 React 表单也可以不使用 hook，改为只用 `onChange`。

## Vue

```vue
<script setup lang="ts">
import { ref } from "vue";
import { Catalog, useCatalog } from "@a3s-lab/ui/vue";

const query = ref("");
const control = useCatalog({
  events: {
    input(event) {
      const target = event.target as HTMLInputElement;
      if (target.type === "search") query.value = target.value;
    },
  },
});
const componentRef = control.componentRef;
</script>

<template>
  <Catalog ref="componentRef" aria-labelledby="catalog-title">
    <header>
      <div data-catalog-identity>
        <h1 id="catalog-title">能力</h1>
        <p>查找可复用的技能、连接器和工作模板。</p>
      </div>
      <div data-catalog-actions>
        <label for="catalog-search">搜索能力</label>
        <input
          id="catalog-search"
          :value="query"
          class="input"
          type="search"
        />
      </div>
    </header>
    <div data-catalog-toolbar>
      <output data-catalog-count>1 项能力</output>
    </div>
    <div data-catalog-results>
      <article class="resource-card"><h2>代码审查</h2></article>
    </div>
  </Catalog>
</template>
```

Vue 组合式函数是查询状态的唯一更新路径；若改用 `v-model`，应移除 hook 中的 `input` 处理。查询、筛选和结果仍属于应用状态。

## 可访问性

目录必须有唯一页面标题，搜索输入框需要可见或隐藏标签，筛选按钮使用 `aria-pressed` 或等价选择语义。筛选后在 `data-catalog-count` 中礼貌播报结果数量，但不要移动焦点或重置滚动。加载、空白和错误状态保留标题与筛选上下文；重试或清除筛选后把焦点留在原控件。精选条目和结果条目使用真实链接或按钮，不能让整张卡片与内部操作形成嵌套点击目标。宿主负责查询、分页、推荐依据、安装权限和可信元数据；组件只负责信息架构与响应式排列。
