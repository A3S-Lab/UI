## 用法

```html
<section class="catalog">
  <header>...</header>
  <div data-catalog-featured>...</div>
  <div data-catalog-toolbar>...</div>
  <div class="resource-grid" data-catalog-results>...</div>
</section>
```

### 参数

| API | 用途 |
| --- | --- |
| `data-catalog-identity` | 标题和说明 |
| `data-catalog-actions` | 搜索、排序、视图和所有权操作 |
| `data-catalog-featured` | 可选的横向精选集合 |
| `data-catalog-toolbar` | 筛选、结果数、排序和视图控件 |
| `data-catalog-results` | 资源网格、列表、表格或空状态 |

## 状态和变体

页面骨架保持稳定，卡片内容用于区分助理、技能和连接器。结果区域必须覆盖加载、空白、错误、选中、已安装、不可用和分页状态。

## 无障碍

使用真实搜索输入框，切换型筛选使用按下状态。筛选后播报结果数量，但不要移动焦点。精选内容可以横向滚动，文档本身不能溢出。
