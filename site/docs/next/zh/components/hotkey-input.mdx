# 快捷键输入

录制一个规范化键盘组合，并在提交前让用户看清当前组合、冲突和清除路径。

## 使用方式

```html
<div class="hotkey-input" data-hotkey-value="Meta+K">
  <input aria-label="Keyboard shortcut" /><span data-hotkey-preview></span><button type="button" class="btn" data-size="icon-sm" data-variant="ghost" data-hotkey-clear aria-label="Clear shortcut">Clear</button>
</div>
```

### 独立控制器

```js
import "@a3s-lab/ui/runtime";
import "@a3s-lab/ui/hotkey-input";

const component = document.querySelector(".hotkey-input");
component.getValue();
```

控制器是幂等的；完整包可改为一次导入 `@a3s-lab/ui/all`。宿主通过可取消的 `before-*` 事件执行权限与业务校验。

## React

```tsx
import { HotkeyInput, useHotkeyInput } from "@a3s-lab/ui/react";

export function Example() {
  const control = useHotkeyInput();
  return (
    <HotkeyInput ref={control.ref} data-hotkey-value="Meta+K">
      <input aria-label="Keyboard shortcut" /><span data-hotkey-preview></span><button type="button" className="btn" data-size="icon-sm" data-variant="ghost" data-hotkey-clear aria-label="Clear shortcut">Clear</button>
    </HotkeyInput>
  );
}
```

`useHotkeyInput` 返回同一 DOM 契约的 `ref`、就绪状态、事件订阅和受类型约束的方法调用；它不会创建框架专属状态。

## Vue

```vue
<script setup>
import { HotkeyInput, useHotkeyInput } from "@a3s-lab/ui/vue";

const control = useHotkeyInput();
const componentRef = control.componentRef;
</script>

<template>
  <HotkeyInput ref="componentRef" data-hotkey-value="Meta+K">
    <input aria-label="Keyboard shortcut" /><span data-hotkey-preview></span><button type="button" class="btn" data-size="icon-sm" data-variant="ghost" data-hotkey-clear aria-label="Clear shortcut">Clear</button>
  </HotkeyInput>
</template>
```

`useHotkeyInput` 与 React hook 暴露相同的事件和方法集合，模板仍输出同一个根类与原生属性。

## 契约

| 接口 | 值 |
| --- | --- |
| 根选择器 | `.hotkey-input` |
| 原生根元素 | `<div>` |
| 状态 | `ready`, `recording`, `disabled`, `invalid` |
| 事件 | `a3s:hotkey-before-change`, `a3s:hotkey-change`, `a3s:hotkey-recording-change` |
| 方法 | `clear`, `getValue`, `setValue`, `start`, `stop` |

## 产品边界

组件不注册全局快捷键、不解决冲突，也不绕过操作系统保留组合。实际绑定和权限判断由宿主负责。

组件只发布可复用的交互边界。数据获取、持久化、权限、可信内容与业务实体继续由宿主产品拥有。

## 可访问性

Tab 始终可以离开控件，Escape 恢复录制前的值，删除键清空组合。可视按键与 aria-keyshortcuts 保持一致。
