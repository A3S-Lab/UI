# 任务队列

任务队列展示在当前任务之后或并行等待的工作。调度、并发、优先级和取消仍由宿主应用负责。

## 用法

```html
<section class="task-queue" data-state="running" aria-labelledby="queue-title">
  <header><h2 id="queue-title">任务队列</h2><span data-queue-status>运行中</span></header>
  <ol><li data-state="queued">...</li></ol>
</section>
```

### 参数

| API | 取值 | 用途 |
| --- | --- | --- |
| `data-state` | `idle`、`running`、`paused`、`blocked`、`complete`、`error` | 队列总体状态 |
| 条目 `data-state` | `queued`、`running`、`blocked`、`complete`、`error` | 单个任务状态 |
| `data-queue-actions` | 可选 | 打开、重试、取消或调整优先级 |

## 状态与变体

列表顺序必须与执行顺序一致。重排需要显式手柄和即时确认，默认不要让整行可拖动。

## 无障碍

使用有序列表和文本状态。只播报有意义的队列变化，不播报计时器更新。
