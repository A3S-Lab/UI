# 组件

## 选择原则

- 操作、输入和选择优先使用原生元素，让浏览器管理焦点、表单状态与可访问性。
- 只有原生平台没有提供完整行为时，才引入组件运行时，例如复合选择器、可调整窗格和设备预览。
- 页面外壳、工具栏和资源布局属于工作区结构，不应代替更小的输入或反馈组件。
- 任务、执行、审阅与开发工具集中在 [Harness](/harness/) 中；这些组件仍使用稳定的 `/components/*` 页面地址。

## API 模型

| API 表面       | 用途                 | 示例                                            |
| -------------- | -------------------- | ----------------------------------------------- |
| 根类名         | 选择组件             | `class="resource-card"`                         |
| 原生属性       | 行为与可访问性       | `disabled`、`checked`、`aria-current="page"`    |
| `data-*` 属性  | 有限的视觉或行为变体 | `data-size="sm"`、`data-orientation="vertical"` |
| CSS 自定义属性 | 连续布局值与主题决策 | `--split-position: 40%`                         |
| JavaScript     | 浏览器未提供的行为   | 分割窗格调整、设备预览与复合控件键盘交互        |

原生元素始终是状态的单一事实来源。例如，禁用按钮直接使用 `disabled`，不需要额外维护一份组件状态。

## 框架接入

HTML 是所有组件的公开契约。React 与 Vue 适配器复用同一语义根元素，不增加包装层；组件只有在暴露事件或方法时才提供对应的 hook 或组合式函数。每个组件页面会明确列出实际可用的接口，不使用占位 API。

| 能力              | 通用组件         | 布局与工作区     | Harness          |
| ----------------- | ---------------- | ---------------- | ---------------- |
| 语义化 HTML       | 必须             | 必须             | 必须             |
| React 与 Vue      | 语义根适配器     | 语义根适配器     | 语义根适配器     |
| Hook / 组合式函数 | 有行为接口时提供 | 有行为接口时提供 | 有行为接口时提供 |
| 浅色与深色主题    | 支持             | 支持             | 支持             |
| RTL 逻辑布局      | 支持             | 支持             | 支持             |
| 响应式布局        | 按组件提供       | 内置             | 按工作流提供     |
| Nunjucks 与 Jinja | 已有组件模板     | 通过 HTML 组合   | 通过 HTML 组合   |

新产品应优先使用 A3S 视觉风格。Vega、Nova、Maia、Lyra、Mira、Luma、Sera 与 Rhea 仅用于需要兼容既有外观的应用。
