## API 模型

A3S UI 的参数尽量贴近浏览器平台：

| API 表面        | 用途                 | 示例                                            |
| --------------- | -------------------- | ----------------------------------------------- |
| 根类名          | 选择组件             | `class="resource-card"`                         |
| 原生属性        | 行为与可访问性       | `disabled`、`checked`、`aria-current="page"`    |
| `data-*` 属性   | 有限的视觉或行为变体 | `data-size="sm"`、`data-orientation="vertical"` |
| CSS 自定义属性  | 连续布局值与主题决策 | `--split-position: 40%`                         |
| 原生 JavaScript | 浏览器没有提供的行为 | 分割窗格调整、设备预览与复合控件键盘交互        |

原生元素始终是状态的单一事实来源。例如，禁用按钮直接使用 `disabled`，不需要额外的组件布尔参数。

### Harness

[Harness](/harness/) 按“任务与对话”“执行与审阅”“工具”三段组织 24 个 Coding Agent 组件，并保留每个组件原有的 `/components/*` 稳定路由。

## 支持矩阵

| 能力              | 通用组件         | 布局与工作区   | Harness              |
| ----------------- | ---------------- | -------------- | -------------------- |
| 语义化 HTML       | 必须             | 必须           | 必须                 |
| 浅色与深色主题    | 支持             | 支持           | 支持                 |
| RTL 逻辑布局      | 支持             | 支持           | 支持                 |
| 响应式布局        | 按组件提供       | 内置           | 按工作流提供         |
| Nunjucks 与 Jinja | 已有组件模板     | 通过 HTML 组合 | 通过 HTML 组合       |
| JavaScript 依赖   | 仅交互式复合组件 | 仅交互布局     | 执行、编辑与预览工具 |

新产品应优先使用 A3S 视觉风格。Vega、Nova、Maia、Lyra、Mira、Luma、Sera 与 Rhea 仍可用于需要旧版兼容外观的应用。
