# 表情选择器

在可搜索、可键盘遍历的有限集合中选择一个表情，并把选择结果作为普通文本交给宿主。

### 独立控制器

```js
import "@a3s-lab/ui/runtime";
import "@a3s-lab/ui/emoji-picker";

const component = document.querySelector(".emoji-picker");
component.getState();
```

控制器是幂等的；完整包可改为一次导入 `@a3s-lab/ui/all`。宿主通过可取消的 `before-*` 事件执行权限与业务校验。

## React

```tsx
import { EmojiPicker, useEmojiPicker } from "@a3s-lab/ui/react";

export function Example() {
  const control = useEmojiPicker();
  return (
    <EmojiPicker ref={control.ref} aria-label="Choose a reaction">
      <input className="input" type="search" placeholder="Search reactions" aria-label="Search reactions" /><div data-emoji-grid role="listbox"><button type="button" data-emoji-value="👍" aria-label="Thumbs up">👍</button><button type="button" data-emoji-value="🎉" aria-label="Celebrate">🎉</button><button type="button" data-emoji-value="❤️" aria-label="Love">❤️</button><p hidden data-emoji-empty>No reactions match.</p></div>
    </EmojiPicker>
  );
}
```

`useEmojiPicker` 返回同一 DOM 契约的 `ref`、就绪状态、事件订阅和受类型约束的方法调用；它不会创建框架专属状态。

## Vue

```vue
<script setup>
import { EmojiPicker, useEmojiPicker } from "@a3s-lab/ui/vue";

const control = useEmojiPicker();
const componentRef = control.componentRef;
</script>

<template>
  <EmojiPicker ref="componentRef" aria-label="Choose a reaction">
    <input class="input" type="search" placeholder="Search reactions" aria-label="Search reactions" /><div data-emoji-grid role="listbox"><button type="button" data-emoji-value="👍" aria-label="Thumbs up">👍</button><button type="button" data-emoji-value="🎉" aria-label="Celebrate">🎉</button><button type="button" data-emoji-value="❤️" aria-label="Love">❤️</button><p hidden data-emoji-empty>No reactions match.</p></div>
  </EmojiPicker>
</template>
```

`useEmojiPicker` 与 React hook 暴露相同的事件和方法集合，模板仍输出同一个根类与原生属性。

## 契约

| 接口 | 值 |
| --- | --- |
| 根选择器 | `.emoji-picker` |
| 原生根元素 | `<section>` |
| 状态 | `ready`, `empty`, `disabled` |
| 事件 | `a3s:emoji-before-select`, `a3s:emoji-query-change`, `a3s:emoji-select` |
| 方法 | `getState`, `refresh`, `select`, `setQuery` |

## 产品边界

组件不管理最近使用、皮肤偏好、远程表情包或消息发送。大型目录应由宿主提供分组、虚拟化和本地化搜索数据。

组件只发布可复用的交互边界。数据获取、持久化、权限、可信内容与业务实体继续由宿主产品拥有。

## 可访问性

每个表情按钮需要名称，方向键在可见结果中移动，空结果明确播报。表情是内容，不承担无文字界面图标的职责。
