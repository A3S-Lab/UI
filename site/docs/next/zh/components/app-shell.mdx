## 用法

```html
<div class="app-shell" data-navigation="expanded">
  <aside data-app-navigation>...</aside>
  <main data-app-main>
    <header class="workspace-header">
      <button type="button" data-app-navigation-trigger>切换导航</button>
    </header>
    <div data-app-content>...</div>
  </main>
</div>
```

### HTML 结构

| 参数 | 可选值 | 默认 | 目的 |
| --- | --- | --- | --- |
| `data-navigation` | `expanded`、`collapsed`、`hidden` | `expanded` | 桌面导航状态 |
| `data-mobile-navigation` | `open` 或省略 | 省略 | 移动端抽屉是否可见 |
| `data-app-navigation-trigger` | 存在或省略 | 省略 | 切换桌面导航或紧凑抽屉 |
| `data-viewport` | `window` 或省略 | 省略 | 让外壳独占 `100dvh` |
| `--app-shell-navigation-size` | CSS 长度 | `15.5rem` | 展开后的导航宽度 |
| `--app-shell-navigation-collapsed-size` | CSS 长度 | `2.875rem` | 与 Office 对齐的图标栏宽度 |
| `--app-shell-navigation-max-size` | CSS 长度或百分比 | `38%` | 展开导航最多占用的比例 |
| `--app-shell-height` | CSS 长度或 `auto` | `auto` | 可选的有界外壳高度 |
| `--app-shell-min-height` | CSS 长度 | `36rem` | 外壳最小高度 |

### JavaScript API

导入 `@a3s-lab/ui/all`，或者先导入 `@a3s-lab/ui/runtime`，再导入 `@a3s-lab/ui/app-shell`。控制器在外壳根元素上提供 `expandNavigation()`、`collapseNavigation()`、`hideNavigation()`、`openNavigation()`、`closeNavigation()`、`toggleNavigation()` 与 `refresh()`。状态变化后会派发 `a3s:app-navigation-change`，详情为 `{ navigation, mobileOpen, mode, source }`。可用 `data-app-navigation-open-label`、`data-app-navigation-close-label`、`data-app-navigation-expand-label` 和 `data-app-navigation-collapse-label` 覆盖本地化标签。

## 状态与变体

App Shell 支持展开、折叠、隐藏、全视口与移动端打开状态。低于 768px 时，导航会成为限制在外壳内部的浮层。控制器会为关闭状态设置 `inert` 与 `aria-hidden="true"`，打开后把焦点移到首个控件，并支持 Escape、遮罩和目的地选择关闭。导航与主内容分别拥有自己的滚动区域。宿主应用可以持久化 `data-navigation` 并与路由协调；程序化修改后若需要立即同步，可调用 `refresh()`。

## React

```tsx
import { AppShell, useAppShell } from "@a3s-lab/ui/react";

export function Example() {
  const control = useAppShell();
  return (
    <AppShell ref={control.ref} data-navigation="expanded">
      <aside data-app-navigation="">
        <nav aria-label="工作区">
          <a href="/tasks" aria-current="page">
            任务
          </a>
        </nav>
      </aside>
      <main data-app-main="">
        <header className="workspace-header">
          <button type="button" data-app-navigation-trigger="">
            切换导航
          </button>
        </header>
        <div data-app-content="">
          <section aria-labelledby="workspace-title">
            <h1 id="workspace-title">设计系统工作区</h1>
            <p>检查当前任务和文件。</p>
          </section>
        </div>
      </main>
    </AppShell>
  );
}
```

`useAppShell` 订阅根节点的导航变化事件，并调用控制器公开的 `toggleNavigation` 等方法。若使用 `data-app-navigation-trigger`，控制器会直接处理点击，不要再在同一按钮上重复调用 hook。

        <button type="button" data-app-navigation-trigger="">切换导航</button>
      </header>
      <div data-app-content="">
        <section aria-labelledby="workspace-title">

Vue composable 使用相同的根元素、事件和方法，不创建另一套导航状态。

## 可访问性

使用 `aside`、`nav`、`main` 和 `header` 建立真实地标，并为每个导航区域提供可区分的名称。控制器同步触发器的 `aria-expanded` 与本地化名称；关闭移动导航时使导航 `inert`，打开时使主内容 `inert`，把焦点移入导航并在其中约束 Tab，最后把焦点还给触发器。导航必须是外壳的直接区域，遮罩只能覆盖当前外壳。宿主负责路由、权限与桌面折叠偏好；组件负责断点状态、焦点、Escape 和关闭行为。
