## Usage

```html
<aside class="task-pane">
  <header>
    <h2>属性</h2>
    ...
  </header>
  <section>...</section>
  <footer>...</footer>
</aside>
```

### Parameters

| 参数                    | 必填 | 用途                       |
| ----------------------- | ---- | -------------------------- |
| 语义化 `header`         | 推荐 | 标题、关闭或更多操作       |
| 语义化 `section`        | 是   | 可滚动的窗格内容           |
| 语义化 `footer`         | 否   | 持续显示的操作             |
| `--task-pane-width`     | 否   | 窗格宽度，默认 `18rem`     |
| `--task-pane-min-width` | 否   | 最小窗格宽度，默认 `14rem` |

## States and variants

宿主应用负责决定窗格是挂载、覆盖还是放入 Split Pane。根组件契约只负责内部布局与视觉。

## Accessibility

窗格作为编辑器补充内容时使用 `<aside>`，并通过标题提供稳定名称。关闭后应把焦点返回打开窗格的控件。
