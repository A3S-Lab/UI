# 3D 代码图谱

3D 代码图谱用于理解大型代码库的入口、模块、组件、测试和配置关系。它将三维探索、搜索、选中邻域和属性检查组合在同一工作面，并始终保留可操作的列表视图。

## 为什么是图谱

文件树适合回答“文件在哪里”，图谱适合回答“改动会影响谁”。默认视图优先显示入口、高连接节点以及当前选择的直接邻居；超过 600 个节点或 4000 条边时进入 `partial`，完整数量仍显示在状态区，列表和搜索继续可用。

## 交互与降级

拖动旋转，滚轮或加减键缩放，方向键旋转，Home 重置视角。节点选择发送可取消的 `a3s:code-graph-before-selection-change`，随后发送 `a3s:code-graph-selection-change`。Canvas 不可用时自动切到列表视图；列表使用真实按钮，不能把可访问性寄托在 Canvas 命中区域上。
