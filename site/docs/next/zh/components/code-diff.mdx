## 产品边界

代码差异负责阅读呈现，不负责生成补丁、解析版本库或决定变更是否可信。复杂审查流程应组合变更审查与审批组件。

组件只发布可复用的交互边界。数据获取、持久化、权限、可信内容与业务实体继续由宿主产品拥有。

## 可访问性

每行必须保留加减符号或文字含义。代码方向固定为从左到右，容器支持键盘聚焦和横向滚动。
