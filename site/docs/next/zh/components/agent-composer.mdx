# Agent 输入框

Agent 输入框用于提交下一条指令，并呈现附加上下文、排队消息以及发送或停止操作。上传、快捷键、提交、取消和队列持久化由宿主应用负责。

## 用法

```html
<form class="agent-composer" aria-label="向编码 Agent 发送消息">
  <ul data-composer-context aria-label="已附加上下文">
    ...
  </ul>
  <textarea name="prompt" aria-label="指令"></textarea>
  <footer>
    <div data-composer-tools>...</div>
    <div data-composer-actions>
      <button type="submit" class="btn">发送</button>
    </div>
  </footer>
</form>
```

### 参数

| API                           | 取值                                                             | 用途                                        |
| ----------------------------- | ---------------------------------------------------------------- | ------------------------------------------- |
| `class="agent-composer"`      | 必须                                                             | 独立 `<form>`，或归外层 Form 所有的 Section |
| `data-state`                  | `idle`、`submitting`、`streaming`、`queued`、`error`、`disabled` | 由宿主管理的有限展示状态                    |
| `data-composer-context`       | 可选列表                                                         | 附件、文件、符号、源码范围、图片或 URL      |
| `data-composer-tools`         | 可选容器                                                         | 附件与上下文控件                            |
| `data-composer-actions`       | 推荐容器                                                         | 发送、排队、停止或重试操作                  |
| `data-composer-status`        | 可选状态文本                                                     | 提交或排队反馈                              |
| `data-composer-queue`         | 可选有序列表                                                     | 在当前 Turn 之后等待的消息                  |
| `--agent-composer-min-height` | CSS 长度，默认 `5.5rem`                                          | 文本区域最小高度                            |
| `--agent-composer-max-height` | CSS 长度，默认 `18rem`                                           | 文本区域开始内部滚动前的最大高度            |

## 状态与变体

单个控件使用原生 `disabled`。只有整个输入框均不可用时才使用 `aria-disabled="true"`。提交失败时保留输入内容。流式执行期间，应用可以立即发送、加入队列或禁用提交，但按钮文案和状态文本必须明确说明实际行为。

附件和排队消息都是应用数据。A3S UI 不上传文件，也不修改队列。原生 `submit` 与按钮事件就是集成点。只有祖先 Form 已经提供提交边界时才使用 `<section class="agent-composer">`，嵌套 Form 是无效标记。

## 无障碍

为表单和文本区域提供可访问名称。移除按钮应紧邻对应条目，标签中应包含条目名称。异步状态使用礼貌型实时区域，但不要逐 Token 播报流式内容。保留普通的输入法组合和多行输入行为；产品快捷键不得在输入法组合期间拦截 Enter。
