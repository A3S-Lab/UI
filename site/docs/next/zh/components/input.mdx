# 输入

输入框用于录入单行文本或结构化值，并通过标签、格式提示和即时反馈降低输入错误。

<Preview class="w-full max-w-xs">
  <input
    class="input"
    type="email"
    aria-label="电子邮箱"
    placeholder="name@example.com"
  />
</Preview>

## 用法

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者只导入基本CSS、输入组件CSS和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/input.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="添加输入框 HTML">

为受支持的 `<input>` 元素添加 `class="input"`。常见文本输入放在 `class="field"` 容器内时，也会自动获得同一套样式。

使用原生HTML属性来实现：`disabled`用于禁止输入，`required`用于必填字段行为，`aria-invalid="true"`用于无效状态样式。

```html
<input
  class="input"
  type="email"
  aria-label="电子邮箱"
  placeholder="name@example.com"
/>
```

  </Step>
</Steps>

### RTL

输入通过原生浏览器方向处理支持从右到左的布局。将 `dir="rtl"` 添加到输入、字段或祖先。

<Preview class="w-full max-w-xs">
  <div role="group" class="field" dir="rtl">
    <label for="input-rtl-api-key">مفتاح API</label>
    <input id="input-rtl-api-key" type="password" placeholder="sk-..." />
    <p>مفتاح API الخاص بك مشفر ومخزن بأمان.</p>
  </div>
</Preview>

## React

```tsx
import { Input, useInput } from "@a3s-lab/ui/react";

export function Example() {
  const control = useInput();
  return <Input ref={control.ref} aria-label="名称" />;
}
```

`useInput` 订阅清单中声明的 DOM 事件，并且只调用清单中公开的方法。适配器不创建另一套框架专属状态。

## Vue

```vue
<script setup>
import { Input, useInput } from "@a3s-lab/ui/vue";

const control = useInput();
const componentRef = control.componentRef;
</script>

<template>
  <Input ref="componentRef" aria-label="名称" />
</template>
```

`useInput` 订阅清单中声明的 DOM 事件，并且只调用清单中公开的方法。适配器不创建另一套框架专属状态。
