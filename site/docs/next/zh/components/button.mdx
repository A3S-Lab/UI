# 按钮

按钮触发当前界面中的操作；需要前往其他地址时，应使用带 `href` 的链接并应用相同视觉样式。

## 用法

导入 Tailwind 与完整 A3S 样式包：

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

然后在原生按钮上添加 `btn` 类。务必显式设置 `type="button"`，避免按钮在表单中意外提交。

```html
<button type="button" class="btn">保存更改</button>
```

需要按组件加载时，依次导入基础样式、按钮结构和 A3S 视觉样式。CDN 与其他接入方式见[安装](/installation)。

```css
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/button.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

### 参数

| 参数           | 值                                                                   | 用途                               |
| -------------- | -------------------------------------------------------------------- | ---------------------------------- |
| 根元素         | `<button>` 或 `<a>`                                                  | 操作使用按钮，页面跳转使用链接     |
| `class`        | `btn`                                                                | 必填的组件根类名                   |
| `data-variant` | `primary`、`secondary`、`outline`、`ghost`、`link`、`destructive`    | 控制操作层级；省略时为主按钮       |
| `data-size`    | `xs`、`sm`、`default`、`lg`、`icon-xs`、`icon-sm`、`icon`、`icon-lg` | 控制点击目标与视觉密度             |
| `data-icon`    | `inline-start` 或 `inline-end`                                       | 放在文字按钮的内联图标上，校正间距 |
| 原生状态       | `disabled`、`aria-busy`、`aria-pressed`                              | 表达不可用、处理中与切换状态       |

## 状态与变体

同一区域通常只保留一个主按钮。`secondary` 与 `outline` 用于次级操作，`ghost` 用于低强调工具操作，`destructive` 只用于有明确破坏后果的动作。`link` 只是按钮的视觉变体，真正的页面导航仍应使用 `<a href>`。

## React

```tsx
import { useState } from "react";
import { Button } from "@a3s-lab/ui/react";

export function SaveButton({
  saveChanges,
}: {
  saveChanges: () => Promise<void>;
}) {
  const [saving, setSaving] = useState(false);

  async function save() {
    setSaving(true);
    try {
      await saveChanges();
    } finally {
      setSaving(false);
    }
  }

  return (
    <Button type="button" disabled={saving} aria-busy={saving} onClick={save}>
      {saving ? "保存中…" : "保存更改"}
    </Button>
  );
}
```

`Button` 使用清单定义的原生 `<button>` 根元素，也可通过 `as="a"` 渲染链接。按钮没有组件私有事件或方法，因此不提供 `useButton`；直接使用 React 事件与状态即可。

## Vue

```vue
<script setup lang="ts">
import { ref } from "vue";
import { Button } from "@a3s-lab/ui/vue";

const props = defineProps<{
  saveChanges: () => Promise<void>;
}>();
const saving = ref(false);

async function save() {
  saving.value = true;
  try {
    await props.saveChanges();
  } finally {
    saving.value = false;
  }
}
</script>

<template>
  <Button type="button" :disabled="saving" :aria-busy="saving" @click="save">
    {{ saving ? "保存中…" : "保存更改" }}
  </Button>
</template>
```

Vue 适配器同样不增加包装层。按钮没有专用组合式函数，交互状态由 Vue 事件和响应式状态管理。

## 可访问性

- 操作使用 `<button>`，导航使用带 `href` 的 `<a>`；不要用点击事件伪装链接。
- 仅图标按钮必须有可访问名称，通常使用 `aria-label`。
- 加载状态保留描述动作的文字，并同步 `disabled` 与 `aria-busy="true"`。
- 切换按钮由应用维护 `aria-pressed="true|false"`；展开浮层的按钮使用 `aria-expanded` 与 `aria-controls`。
- 破坏性按钮只表达操作性质。需要二次确认时，使用[警报对话框](/components/alert-dialog)。
- A3S 样式包提供可见焦点环；不要在应用样式中移除它。
