## 用法

导入 Tailwind 与完整 A3S 样式包：

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

然后在原生按钮上添加 `btn` 类。务必显式设置 `type="button"`，避免按钮在表单中意外提交。

```html
<button type="button" class="btn">保存更改</button>
```

需要按组件加载时，依次导入基础样式、按钮结构和 A3S 视觉样式。CDN 与其他接入方式见[安装](/installation)。

```css
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/button.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

### 参数

| 参数           | 值                                                                   | 用途                               |
| -------------- | -------------------------------------------------------------------- | ---------------------------------- |
| 根元素         | `<button>` 或 `<a>`                                                  | 操作使用按钮，页面跳转使用链接     |
| `class`        | `btn`                                                                | 必填的组件根类名                   |
| `data-variant` | `primary`、`secondary`、`outline`、`ghost`、`link`、`destructive`    | 控制操作层级；省略时为主按钮       |
| `data-size`    | `xs`、`sm`、`default`、`lg`、`icon-xs`、`icon-sm`、`icon`、`icon-lg` | 控制点击目标与视觉密度             |
| `data-icon`    | `inline-start` 或 `inline-end`                                       | 放在文字按钮的内联图标上，校正间距 |
| 原生状态       | `disabled`、`aria-busy`、`aria-pressed`                              | 表达不可用、处理中与切换状态       |

按钮没有 JavaScript 控制器或专用框架 Hook。HTML、React 和 Vue 使用相同的原生激活与状态属性；异步操作和防重复提交由应用状态负责。

## 状态与变体

同一区域通常只保留一个主按钮。`secondary` 与 `outline` 用于次级操作，`ghost` 用于低强调工具操作，`destructive` 只用于有明确破坏后果的动作。`link` 只是按钮的视觉变体，真正的页面导航仍应使用 `<a href>`。

## 可访问性

- 操作使用 `<button>`，导航使用带 `href` 的 `<a>`；不要用点击事件伪装链接。
- 仅图标按钮必须有可访问名称，通常使用 `aria-label`。
- 加载状态保留具体的动作文字，同步 `disabled` 与 `aria-busy="true"`，并在等待业务操作前立即设置防重复提交保护。
- 切换按钮由应用维护 `aria-pressed="true|false"`；展开浮层的按钮使用 `aria-expanded` 与 `aria-controls`。
- 破坏性按钮只表达操作性质。需要二次确认时，使用[警报对话框](/components/alert-dialog)。
- A3S 样式包使用单一外移焦点轮廓，不会叠加 box-shadow 光环；不要在应用样式中移除它。
