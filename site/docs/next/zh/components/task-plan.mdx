# 任务计划

任务计划用有限步骤展示可观察的工作顺序，不把内部推理直接暴露为界面文案。计划创建、步骤流转、持久化与取消由宿主应用负责。

## 用法

```html
<section class="task-plan" data-state="active" aria-labelledby="plan-title">
  <header>
    <h2 id="plan-title">发布计划</h2>
    ...
  </header>
  <ol>
    <li class="plan-step" data-state="complete">...</li>
    <li class="plan-step" data-state="active" aria-current="step">...</li>
  </ol>
  <footer>...</footer>
</section>
```

### 参数

| API                | 取值                                             | 用途                                         |
| ------------------ | ------------------------------------------------ | -------------------------------------------- |
| `data-state`       | `draft`、`active`、`paused`、`complete`、`error` | 计划生命周期                                 |
| `data-variant`     | `plain`                                          | 移除计划自身表面，供检查器或会话分区直接承载 |
| 直接子 `<ol>`      | 必须                                             | 有序计划步骤                                 |
| `data-plan-status` | 推荐                                             | 可见生命周期文案                             |
| 原生进度条语义     | 可选                                             | 有界总进度                                   |

## 状态与变体

暂停执行时保留已完成步骤和当前步骤。单个步骤失败时优先在该计划步骤上标记，只有整个计划无法继续时才使用计划级错误。父级表面已经拥有边界时才使用 `data-variant="plain"`；它移除任务计划的边框和行内边距，但不改变步骤语义。

```html
<section class="task-plan" data-state="active" data-variant="plain">
  <header>
    <h2>执行计划</h2>
    <span data-plan-status>进行中</span>
  </header>
  <ol>
    <li class="plan-step" data-state="active" aria-current="step">...</li>
  </ol>
</section>
```

## 无障碍

使用标题命名整个区域，并且只出现一个 `aria-current="step"`。不显示可视进度条时仍需提供文本进度。

## React

```tsx
import { TaskPlan } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <TaskPlan data-state="active" aria-labelledby="plan-title">
      <header>
        <h2 id="plan-title">发布计划</h2>
        <p>已完成 3 步中的 2 步</p>
      </header>
      <ol>
        <li className="plan-step" data-state="complete">
          <strong>构建软件包</strong>
          <span>已完成</span>
        </li>
        <li className="plan-step" data-state="active" aria-current="step">
          <strong>验证响应式行为</strong>
          <span>进行中</span>
        </li>
      </ol>
      <footer>
        <button type="button">暂停计划</button>
      </footer>
    </TaskPlan>
  );
}
```

适配器只替换指南中已记录的语义根元素，不增加包装层；内部标记继续使用上方 HTML 契约。
