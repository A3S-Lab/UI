# 输入组

输入组把文本输入与前后缀、图标或紧密相关的操作组合为一个输入边界。

<Preview class="w-full max-w-xs">
<div class="input-group">
  <input type="text" aria-label="搜索" placeholder="搜索…" />
  <span data-align="start" aria-hidden="true"><svg class="lucide lucide-search" xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m21 21-4.34-4.34" /><circle cx="11" cy="11" r="8" /></svg></span>
  <span data-align="end">12 条结果</span>
</div>
</Preview>

## 用法

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者只导入基础 CSS、输入组组件 CSS 和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/input-group.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用 CDN 或打包工具导入？请参阅[安装页](/installation)。

  </Step>
  <Step title="添加输入组 HTML">

```html
<div class="input-group">
  <input type="text" aria-label="搜索" placeholder="搜索…" />
  <span data-align="start" aria-hidden="true"> <!-- icon --></span>
  <span data-align="end">12 条结果</span>
</div>
```

  </Step>
</Steps>

在根元素上添加 `class="input-group"`。原生控件保留自身语义，并作为组合外壳内的无边界子控件。

<dl>
  <dt><code>&lt;div class="input-group"&gt;</code></dt>
  <dd>
    输入组的外层容器。只有当组合本身需要命名时，才添加 <code>role="group"</code> 和无障碍标签。
    <dl>
      <dt><code>&lt;input&gt;</code>, <code>&lt;textarea&gt;</code>, <code>&lt;select&gt;</code></dt>
      <dd>原生输入控件。无效状态使用 <code>aria-invalid="true"</code>，禁用状态使用 <code>disabled</code>。</dd>
      <dt><code>&lt;span&gt;</code>, <code>&lt;svg&gt;</code>, <code>&lt;kbd&gt;</code></dt>
      <dd>装饰或辅助内容。纯装饰图标使用 <code>aria-hidden="true"</code>。</dd>
      <dt><code>&lt;button&gt;</code>, <code>&lt;div role="group"&gt;</code></dt>
      <dd>交互操作。同一侧有多个相关操作时，使用带无障碍标签的 <code>role="group"</code>。</dd>
      <dt><code>&lt;header&gt;</code>, <code>&lt;footer&gt;</code></dt>
      <dd>垂直输入组的头部或底部附加行。</dd>
      <dt><code>data-align="start|end"</code></dt>
      <dd>可选的视觉位置。值采用逻辑方向，因此 start/end 会在 RTL 中自动翻转。头部或底部布局需要在根元素上使用 <code>data-orientation="vertical"</code>。</dd>
      <dt><code>[data-control]</code></dt>
      <dd>用于非原生 <code>input</code>、<code>textarea</code> 或 <code>select</code> 的自定义控件。</dd>
    </dl>
  </dd>
</dl>

在附加内容容器上使用 `data-align="start|end"` 将其放在行内两侧。配合 `data-orientation="vertical"`、`header` 或 `footer` 可创建块级布局。
