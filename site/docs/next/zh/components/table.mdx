## 用途

<Steps>
  <Step title="Include CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者只导入基本CSS、表格组件CSS和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/table.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="Add your table HTML">

将 `class="table"` 添加到您的表元素中。当需要水平滚动时，将其包裹在`class="table-container"`中。

```html
<div class="table-container">
<table class="table">
  <!-- Content of your table -->
</table>
</div>
```

  </Step>
</Steps>

<Callout type="warning" title="Scrollable tables clip overlays" icon="triangle-alert">
请勿将内联弹出框、下拉菜单、选择或工具提示放置在 `.table-container` 内。表格容器对宽表格使用水平溢出，因此可以剪切绝对定位的覆盖层或创建滚动条。将覆盖操作保留在可滚动表格区域之外，或者当表格不需要水平滚动时省略 `.table-container`。
</Callout>

## React

```tsx
import { Table, useTable } from "@a3s-lab/ui/react";

export function Example() {
  const control = useTable();
  return (
    <Table ref={control.ref}><table><caption>组件摘要</caption><tbody><tr><th scope="row">名称</th><td>组件内容</td></tr></tbody></table></Table>
  );
}
```

`useTable` 订阅清单中声明的 DOM 事件，并且只调用清单中公开的方法。适配器不创建另一套框架专属状态。

## Vue

```vue
<script setup>
import { Table, useTable } from "@a3s-lab/ui/vue";

const control = useTable();
const componentRef = control.componentRef;
</script>

<template>
  <Table ref="componentRef"><table><caption>组件摘要</caption><tbody><tr><th scope="row">名称</th><td>组件内容</td></tr></tbody></table></Table>
</template>
```
