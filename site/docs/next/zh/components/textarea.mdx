# 文本区域

文本区域用于录入可能换行的较长内容，并应为字数、格式或校验要求提供持续反馈。

<Preview class="w-full max-w-xs">
<textarea class="textarea" aria-label="消息" placeholder="Type your message here"></textarea>
</Preview>

## 用法

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者只导入基本CSS、Textarea组件CSS和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/textarea.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="添加文本区域 HTML">

Add `class="textarea"` to a `<textarea>` element. Textareas inside a `class="field"` container also receive the same styling automatically.

使用原生 HTML 属性进行：`disabled` 用于取消文本区域，`aria-invalid="true"` 用于无效状态行为样式。

```html
<textarea class="textarea" aria-label="消息" placeholder="Type your message here"></textarea>
```

  </Step>
</Steps>

文本区域通过原生浏览器方向处理支持从右到左的布局。

## 示例

### 现场

使用带有标签和说明的 `field` 创建可访问的文本区域。

<Preview class="w-full max-w-xs">
<div role="group" class="field">
  <label for="textarea-field">Message</label>
  <textarea id="textarea-field" placeholder="Type your message here"></textarea>
  <p>Write a short message.</p>
</div>
</Preview>

### 已禁用

<Preview class="w-full max-w-xs">
<textarea class="textarea" aria-label="消息" placeholder="Type your message here" disabled></textarea>
</Preview>

  <textarea class="textarea" id="textarea-invalid" placeholder="Type your message here" aria-invalid="true"></textarea>

### RTL

将 `dir="rtl"` 添加到文本区域、字段或祖先。

<Preview class="w-full max-w-xs">
<div role="group" class="field w-full max-w-xs" dir="rtl">
  <label for="textarea-rtl">التعليقات</label>
  <textarea id="textarea-rtl" placeholder="تعليقاتك تساعدنا على التحسين..." rows="4"></textarea>
  <p>شاركنا أفكارك حول الخدمة.</p>
</div>
</Preview>

## React

```tsx
import { Textarea, useTextarea } from "@a3s-lab/ui/react";

export function Example() {
  const control = useTextarea();
  return (
    <Textarea ref={control.ref} aria-label="名称" defaultValue="组件内容" />
  );
}
```

`useTextarea` 订阅清单中声明的 DOM 事件，并且只调用清单中公开的方法。适配器不创建另一套框架专属状态。

## Vue

```vue
<script setup>
import { Textarea, useTextarea } from "@a3s-lab/ui/vue";

const control = useTextarea();
const componentRef = control.componentRef;
</script>

<template>
  <Textarea ref="componentRef" aria-label="名称" value="组件内容" />
</template>
```

`useTextarea` 订阅清单中声明的 DOM 事件，并且只调用清单中公开的方法。适配器不创建另一套框架专属状态。
