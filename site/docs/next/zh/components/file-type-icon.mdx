# 文件类型图标

文件类型图标用文件页或文件夹图形、语义颜色和可选扩展名，为本地文件提供清晰的身份提示。它适用于文件管理器、最近工作列表、任务上下文选择器和编辑器标签页。

对于与 A3S Office 编辑器保持一致的工作台，可使用 `data-file-icon-style="office"`。该变体保留相同的类型和尺寸契约，但把宿主提供的真实图标库 glyph 放进紧凑的圆角身份块中。

## 用法

在基础 token 之后加载组件 CSS。宿主应用提供语义类型，并使用文档中约定的 `data-*` 标记绘制装饰性的文件页或文件夹图形。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/file-type-icon.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

```html
<span class="file-type-icon" data-file-type="document" data-file-format="word" data-file-icon-size="list" aria-hidden="true">
  <svg data-file-sheet viewBox="0 0 48 56" aria-hidden="true">
    <path d="M9 2.75h19.5L40 14.25v35A4.75 4.75 0 0 1 35.25 54H9a4.75 4.75 0 0 1-4.75-4.75V7.5A4.75 4.75 0 0 1 9 2.75Z" data-file-page />
    <path d="M28.5 2.75v8.5a3 3 0 0 0 3 3H40" data-file-fold />
    <path d="M11 20.5h13M11 25.5h8" data-file-lines />
  </svg>
  <span data-file-extension>DOCX</span>
</span>
```

Office glyph 变体的宿主标记如下（`data-file-office-glyph` 内可以放置 Lucide 或其他一致的 SVG glyph）：

```html
<span class="file-type-icon" data-file-type="spreadsheet" data-file-format="excel" data-file-icon-style="office" data-file-icon-size="list" aria-hidden="true">
  <svg data-file-office-glyph viewBox="0 0 24 24" aria-hidden="true"><!-- host glyph --></svg>
</span>
```

### 参数

| API | 值 | 用途 |
| --- | --- | --- |
| `class="file-type-icon"` | 必需 | 根元素与图形布局 |
| `data-file-type` | `folder`、`code`、`document`、`spreadsheet`、`presentation`、`pdf`、`image`、`archive`、`media`、`file` | 语义颜色族 |
| `data-file-format` | `word`、`excel`、`powerpoint`、`markdown`、`pdf` 或宿主定义的格式 | 可选的 Office 对齐颜色覆盖 |
| `data-file-icon-size` | `grid`、`list`、`navigation`、`preview` | 使用场景对应的尺寸 |
| `data-file-icon-style` | `office` | 使用 A3S Office 圆角身份块与宿主 glyph |
| `data-file-icon-state` | `selected`、`loading`、`disabled`、`error` | 宿主管理的可选视觉状态 |
| `data-file-extension` | 文本内容 | 可选的扩展名标签 |
| `data-file-folder` | SVG 标记 | 文件夹图形根元素 |
| `data-file-sheet` | SVG 标记 | 文件图形根元素 |
| `data-file-page`、`data-file-fold`、`data-file-lines` | SVG 标记 | 文件页子图形 |
| `data-file-favorite` | 标记容器 | 由宿主提供的可选收藏徽标 |
| `--file-color` | CSS 颜色 | 显式覆盖语义颜色 |

## 状态与变体

目录使用 `folder`，无法识别更具体类型时使用 `file`。文件卡片使用 `grid`，表格和菜单使用 `list`，紧凑侧边栏使用 `navigation`，文件标题旁使用 `preview`。需要区分格式时保留扩展名文本；颜色只是辅助信号，不能作为唯一的类型提示。

可选状态标记只负责视觉提示。文件行仍应使用文字说明权限、重试操
作和错误原因，并由所属控件提供播报。`loading` 会显示紧凑的加载指示
器，`selected`、`disabled` 和 `error` 提供不只依赖颜色的强调。不要用
图标状态替代所属控件的 `aria-busy`、`disabled` 或错误消息。

Office 变体不会强制 UI 包依赖某个图标库；宿主负责选择 glyph，但必须保持同一套线宽、`viewBox` 和类型映射。

## 可访问性

当相邻文件名和类型已经会被播报时，图标属于装饰内容，应使用 `aria-hidden="true"`。如果图标在没有文本标签时承担信息传达，请在所属文件控件上提供可访问名称，并保留扩展名文本。不要只依赖颜色。文件操作应使用真实的 `<button>` 或 `<a>`，图标根元素不应承担交互语义。
