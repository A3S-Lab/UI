# 文件类型图标

在文件列表和附件中提供稳定、克制的类型提示，同时让真实文件名继续承担主要识别职责。

<Preview class="w-full">
<span class="file-type-icon" role="img" aria-label="TypeScript file" style="--file-color:#249bf6"><span data-file-extension>TS</span></span>
</Preview>

## 使用方式

```html
<span class="file-type-icon" role="img" aria-label="TypeScript file" style="--file-color:#249bf6">
  <span data-file-extension>TS</span>
</span>
```

## React

```tsx
import { FileTypeIcon } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <FileTypeIcon role="img" aria-label="TypeScript file" style={{ "--file-color": "#249bf6" }}>
      <span data-file-extension>TS</span>
    </FileTypeIcon>
  );
}
```

该组件没有额外行为控制器，React 适配器只渲染标准语义根。

## Vue

```vue
<script setup>
import { FileTypeIcon } from "@a3s-lab/ui/vue";

</script>

<template>
  <FileTypeIcon role="img" aria-label="TypeScript file" style="--file-color:#249bf6">
    <span data-file-extension>TS</span>
  </FileTypeIcon>
</template>
```

Vue 适配器不包装额外容器，也不改变原生属性。

## 产品边界

图标不判断文件安全性、可执行能力或 MIME 真实性。品牌与供应商图形由宿主通过通用图标槽提供。

组件只发布可复用的交互边界。数据获取、持久化、权限、可信内容与业务实体继续由宿主产品拥有。

## 可访问性

装饰性图标使用 aria-hidden；仅显示图标时必须提供文件类型名称。扩展名文字保持可读，不能只靠颜色区分。
