# 执行证据

执行证据记录一项可验证结果，例如测试运行、截图、报告、跟踪或无障碍快照。

## 用法

```html
<article class="execution-evidence" data-state="verified">
  <header>
    <h3>组件语义覆盖</h3>
    <span data-evidence-result>已验证</span>
  </header>
  <section>可观察结果与来源。</section>
  <footer>...</footer>
</article>
```

### 参数

| API                    | 取值                                                      | 用途             |
| ---------------------- | --------------------------------------------------------- | ---------------- |
| `data-state`           | `capturing`、`verified`、`unverified`、`expired`、`error` | 证据生命周期     |
| `data-evidence-result` | 必须                                                      | 文本验证结果     |
| `data-evidence-meta`   | 推荐                                                      | 时间、来源与环境 |

## 状态与变体

已验证仅表示证据支持所述结论，不代表整个任务完全正确。证据过期后继续显示，并说明使其失效的条件。

## 无障碍

证据摘要使用文本和结构化数据。截图需要有用的替代文本或相邻的文本结果。
