# 警报

警报用于在当前页面中传达需要注意的状态、结果或风险，不打断用户正在进行的任务。

## 用法

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者仅导入基本 CSS、警报组件 CSS 和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/alert.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用 CDN 或包管理器集成时，请参见[安装页](/installation)。

  </Step>
  <Step title="添加警报 HTML">

使用 `alert` 作为中性提示；通过 `data-variant="info"`、`success`、`warning` 或 `destructive` 表达信息、成功、警告和错误。只有动态插入的紧急错误才添加 `role="alert"`；可延后处理的状态使用 `role="status"`，静态说明不需要实时角色。直接添加 `<footer>` 子元素可提供一个与提示紧密相关的恢复操作。

```html
<div class="alert"><svg aria-hidden="true" class="lucide lucide-info" xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><circle cx="12" cy="12" r="10" /><path d="M12 16v-4" /><path d="M12 8h.01" /></svg>
  <h2>网关配置需要重新验证</h2>
  <section>证书已更新，请先验证连接再继续发布。</section>
  <footer>
    <button type="button" class="btn" data-variant="outline">立即验证</button>
  </footer>
</div>
```

  </Step>
</Steps>

### HTML 结构

<dl>
  <dt><code>&lt;div class="alert"&gt;</code></dt>
  <dd>
    主容器。使用 <code>data-variant="info"</code>、<code>success</code> 或 <code>destructive</code> 表达语义状态。
    <dl>
      <dt><code>&lt;svg&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
      <dd>辅助识别状态的图标。必须设置 <code>aria-hidden="true"</code>，不能替代标题。</dd>
      <dt><code>&lt;h2&gt;</code></dt>
      <dd>简短结果或问题名称。根据页面层级选择合适的标题级别，也可使用 <code>&lt;strong data-title&gt;</code>。</dd>
      <dt><code>&lt;section&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
      <dd>影响、原因和恢复方式。</dd>
      <dt><code>&lt;footer&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
      <dd>行末操作区。只放与当前提示直接相关的按钮或链接，避免形成第二套工具栏。</dd>
    </dl>
  </dd>
</dl>

## 状态与变体

### 基本

中性提示用于说明当前上下文，不暗示成功或失败。

### 动作

当存在明确恢复路径时，使用 `<footer>` 提供一个主操作。不要把与提示无关的命令放进警报。

<Preview class="w-full max-w-md">
<div class="alert">
  <h2>检测到新的访问范围</h2>
  <section>当前密钥请求写入生产环境，需要重新确认权限。</section>
  <footer>
    <button type="button" class="btn" data-size="xs">审查权限</button>
  </footer>
</div>
</Preview>

### 警告

## React

```tsx
import { Alert } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <Alert data-variant="warning" role="status">
      <svg aria-hidden="true" viewBox="0 0 24 24">
        <path d="M12 9v4m0 4h.01" />
      </svg>
      <h2>生产证书将在 3 天后过期</h2>
      <section>请在到期前完成轮换并验证调用方，避免连接中断。</section>
      <footer>
        <button type="button">开始轮换</button>
      </footer>
    </Alert>
  );
}
```

`Alert` 只映射语义根元素，标题、说明和恢复操作仍遵循上方 HTML 契约。这里使用 `role="status"` 是因为宿主会在证书状态变化后动态插入提示；页面初始就存在的说明不需要实时角色。

## Vue

```vue
<script setup>
import { Alert } from "@a3s-lab/ui/vue";
</script>

<template>
  <Alert data-variant="warning" role="status">
    <svg aria-hidden="true" viewBox="0 0 24 24">
      <path d="M12 9v4m0 4h.01" />
    </svg>
    <h2>生产证书将在 3 天后过期</h2>
    <section>请在到期前完成轮换并验证调用方，避免连接中断。</section>
    <footer>
      <button type="button">开始轮换</button>
    </footer>
  </Alert>
</template>
```

`Alert` 只映射语义根元素，Vue 版本不会增加框架专属状态或包装层。静态警报没有控制器，因此不提供伪造的 hook。

## 可访问性

标题必须独立说明结果或风险，说明文本再补充影响与恢复路径；图标只用于快速识别状态，并设置 `aria-hidden="true"`。静态说明不添加实时角色；异步完成且不紧急的结果使用 `role="status"`，需要用户立即处理的动态错误才使用 `role="alert"`。不要在已有实时区域中嵌套警报，也不要因为颜色或图标不同而省略状态文字。宿主负责决定何时插入或更新警报、把焦点保持在原任务上，并让警报中的恢复操作回到可预测的焦点位置。
