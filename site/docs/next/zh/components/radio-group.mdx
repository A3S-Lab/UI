# 单选组

单选组用于呈现一小组互斥选项。适合所有选项都能在当前界面直接理解，并且用户需要选择一个值才能继续或完成当前设置的场景。

## 用法

导入 Tailwind 和完整的 A3S 样式包：

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

为相关的原生单选按钮设置相同的 `name`，为每个按钮关联可见标签，再通过 `fieldset` 与 `legend`，或 `role="radiogroup"` 与 `aria-labelledby`，为整组选择提供一个无障碍名称。

```html
<fieldset class="fieldset">
  <legend data-variant="label">视图密度</legend>
  <div class="grid gap-3">
    <div class="field" data-orientation="horizontal">
      <input
        class="input"
        type="radio"
        id="density-default"
        name="density"
        value="default"
      />
      <label for="density-default">默认</label>
    </div>
    <div class="field" data-orientation="horizontal">
      <input
        class="input"
        type="radio"
        id="density-compact"
        name="density"
        value="compact"
        checked
      />
      <label for="density-compact">紧凑</label>
    </div>
  </div>
</fieldset>
```

如需按组件加载，请依次导入基础样式、Radio 结构、Field 结构与 A3S 视觉样式。CDN 等其他接入方式参见[安装](/installation)。

```css
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/radio.css";
@import "@a3s-lab/ui/components/field.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

### 参数

| 参数               | 值                                  | 用途                                         |
| ------------------ | ----------------------------------- | -------------------------------------------- |
| 分组               | `<fieldset>` 或 `role="radiogroup"` | 为相关选项建立一个有名称的语义边界           |
| 根类名             | `radio-group`                       | 应用稳定的分组布局和框架适配器契约           |
| 选项根元素         | `<input type="radio">`              | 保留原生表单、校验、键盘与无障碍行为         |
| `class`            | `input`                             | 应用 Radio 结构和视觉样式                    |
| `name`             | 相同字符串                          | 让选项互斥并只提交一个值                     |
| `value`            | 稳定字符串                          | 提供提交给应用的值，不要根据显示文案临时生成 |
| `checked`          | 布尔属性                            | 标记真实的初始选择；必须由用户选择时应省略   |
| `disabled`         | 布尔属性                            | 阻止选择，并需要解释该项不可用的原因         |
| `required`         | 布尔属性                            | 要求同名原生单选组在提交前至少选择一项       |
| `aria-invalid`     | `true`                              | 在完成校验后公开失败状态                     |
| `aria-describedby` | 元素 ID                             | 关联约束、选择后果或恢复说明                 |

## 状态与变体

未选中与已选中是正常交互状态。焦点进入原生单选组后，方向键在组选项间移动并同步选择；Tab 只把整组作为一个进出位置。只有当相邻内容解释约束或恢复方式时，禁用态和错误态才有意义。

## React

`RadioGroup` 渲染清单声明的根元素。`useRadioGroup` 监听冒泡的原生 `change` 事件，选中值与表单提交仍由应用负责。

```tsx
import { useState } from "react";
import { RadioGroup, useRadioGroup } from "@a3s-lab/ui/react";

export function DensitySetting() {
  const [density, setDensity] = useState("comfortable");
  const group = useRadioGroup({
    events: {
      change(event) {
        const option = event.target as HTMLInputElement;
        if (option.type === "radio" && option.checked) setDensity(option.value);
      },
    },
  });

  return (
    <RadioGroup
      ref={group.ref}
      aria-labelledby="density-label"
      className="w-fit"
    >
      <span id="density-label" className="label">
        视图密度
      </span>
      {[
        ["default", "默认"],
        ["comfortable", "宽松"],
        ["compact", "紧凑"],
      ].map(([value, label]) => (
        <div className="field" data-orientation="horizontal" key={value}>
          <input
            className="input"
            type="radio"
            id={`density-${value}`}
            name="density"
            value={value}
            defaultChecked={value === density}
          />
          <label htmlFor={`density-${value}`}>{label}</label>
        </div>
      ))}
      <output>当前密度：{density}</output>
    </RadioGroup>
  );
}
```

## Vue

Vue 组合式函数订阅相同的原生事件。模板 ref 连接语义分组，响应式状态仍归应用所有。

```vue
<script setup lang="ts">
import { ref } from "vue";
import { RadioGroup, useRadioGroup } from "@a3s-lab/ui/vue";

const density = ref("comfortable");
const group = useRadioGroup({
  events: {
    change(event) {
      const option = event.target as HTMLInputElement;
      if (option.type === "radio" && option.checked)
        density.value = option.value;
    },
  },
});
const componentRef = group.componentRef;
const options = [
  ["default", "默认"],
  ["comfortable", "宽松"],
  ["compact", "紧凑"],
];
</script>

<template>
  <RadioGroup ref="componentRef" aria-labelledby="density-label" class="w-fit">
    <span id="density-label" class="label">视图密度</span>
    <div
      v-for="[value, label] in options"
      :key="value"
      class="field"
      data-orientation="horizontal"
    >
      <input
        class="input"
        type="radio"
        :id="`density-${value}`"
        name="density"
        :value="value"
        :checked="value === density"
      />
      <label :for="`density-${value}`">{{ label }}</label>
    </div>
    <output>当前密度：{{ density }}</output>
  </RadioGroup>
</template>
```

## 无障碍

- 为整组选择提供一个简洁的无障碍名称。表单内优先使用 `fieldset` 与 `legend`；其他场景使用 `role="radiogroup"` 搭配 `aria-labelledby` 或 `aria-label`。
- 每个单选按钮都需要可见 `label` 和稳定的提交 `value`。说明文字通过 `aria-describedby` 关联，不要把长段说明塞进无障碍名称。
- 互斥选项必须使用同一个 `name`。不要通过彼此独立的按钮或只存在于应用状态中的逻辑模拟互斥。
- 保留原生方向键行为。Tab 进入当前选项，方向键移动并选择，Tab 离开整组；不要让每个选项都成为独立 Tab 停靠点。
- 不要给每个选项行添加 `role="group"`。radiogroup 或 fieldset 是唯一的分组边界。
- 只给不可用选项设置 `disabled` 并保持原因可见。如果全部选项都不可用，应禁用所属表单操作并说明阻塞条件。
- 完成校验后再显示错误。使用 `required`、`aria-invalid="true"` 与 `aria-describedby` 关联可恢复的错误说明，并在用户选择合法值或重置表单后清除过期的错误属性与文案。
- 在粗指针设备上让完整点击目标至少达到 44px，视觉圆点仍保持紧凑。
