# 设置行

设置行在稳定网格中对齐设置名称、直接说明、控件和可选验证信息。多个设置行放在设置列表中，再组合进设置布局。

## 用法

```html
<div class="setting-list">
  <div class="setting-row">
    <div data-setting-identity>
      <strong>语言</strong>
      <p>选择界面显示语言。</p>
    </div>
    <div data-setting-control>
      <select class="select">
        ...
      </select>
    </div>
    <p data-setting-message>...</p>
  </div>
</div>
```

### 参数

| API                     | 用途                     |
| ----------------------- | ------------------------ |
| `class="setting-list"`  | 组合相邻设置行和共享边界 |
| `class="setting-row"`   | 稳定的名称与控件网格     |
| `data-setting-identity` | 设置名称和直接说明       |
| `data-setting-control`  | 原生或复合控件           |
| `data-setting-message`  | 可选验证或恢复信息       |
| `data-state="invalid"`  | 无效设置行样式           |

## 状态和变体

焦点、禁用、加载、选中和只读状态由子控件承担。设置行负责建立名称、控件和错误恢复之间的关系。低于 640 像素时按 DOM 顺序堆叠。

## 无障碍

用原生标签或明确的 ARIA 名称关联控件。说明和错误信息通过 `aria-describedby` 关联，无效控件同时设置 `aria-invalid="true"`。

## React

```tsx
import { SettingRow, useSettingRow } from "@a3s-lab/ui/react";

export function Example() {
  const control = useSettingRow();
  return (
    <SettingRow ref={control.ref}>
      <div data-setting-identity="">
        <strong>语言</strong>
        <p>选择界面显示语言。</p>
      </div>
      <div data-setting-control="">
        <select className="select">
          <option value="zh-CN">简体中文</option>
          <option value="en">English</option>
        </select>
      </div>
      <p data-setting-message="">更改会自动保存。</p>
    </SettingRow>
  );
}
```

`useSettingRow` 订阅清单中声明的 DOM 事件，并且只调用清单中公开的方法。适配器不创建另一套框架专属状态。
