# 资源卡

Resource Card 表示文件、模板、助理、配置与其他工作台资源。克制的预览与明确文案共同传达类型和状态；静态卡片保持扁平。

## 用途

```html
<div class="resource-grid">
  <button type="button" class="resource-card" data-kind="agent">
    <figure>...</figure>
    <section><strong>Coding agent</strong><small>CLI + 6 skills</small></section>
  </button>
</div>
```

### 参数

| 参数 | 可选值 | 默认 | 目的 |
| --- | --- | --- | --- |
| `data-kind` | `document`、`spreadsheet`、`presentation`、`agent`、`danger` | `document` | 语义资源类型；`agent` 使用 A3S 蓝 |
| `data-orientation` | `horizontal` 或省略 | 省略 | 预览与文本布局 |
| `--resource-grid-min` | CSS 长度 | `12rem` | 最小网格轨道宽度 |
| `--resource-grid-gap` | CSS 长度 | `1rem` | 网格间距 |
| `--resource-preview-height` | CSS 长度 | `8.5rem` | 预览区域高度 |
| `--resource-accent` | CSS 颜色 | 类型令牌 | 覆盖单个资源的强调色 |

## 状态和变体

按钮用于就地操作；链接用于导航。两者在悬停时只改变边界与底色，不上移。`disabled` 仅与按钮根一起使用。`data-state="loading"`、`data-state="unavailable"` 和 `data-selected="true"` 用于目录状态；水平方向适合最近文件和搜索结果。

## 可访问性

预览图稿件是装饰性的，除非它传达了独特的内容；使用 `aria-hidden="true"` 隐藏装饰性 SVG。保留标题文本并输入。避免在交互链接或按钮内交互式控件。

## React

```tsx
import { ResourceCard } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <ResourceCard>组件内容</ResourceCard>
  );
}
```

适配器只替换指南中已记录的语义根元素，不增加包装层；内部标记继续使用上方 HTML 契约。
