# 选择器

选择器提供经过设计的单选列表，适合需要一致浮层或丰富选项内容的场景。需要搜索或创建值时应使用组合框。

### HTML 结构

<dl>
  <dt><code>&lt;div class="select"&gt;</code></dt>
  <dd>
    选择器根节点。使用 <code>data-placeholder</code> 显示未选择时的提示文本；多选模式支持 <code>data-close-on-select="true"</code>，对象序列化支持 <code>data-format="object"</code>。
    <dl>
      <dt><code>&lt;button type="button"&gt;</code></dt>
      <dd>只读选择组合框的触发器。必须通过关联的 <code>&lt;label&gt;</code>、<code>aria-label</code> 或 <code>aria-labelledby</code> 提供稳定的无障碍名称；占位文本只是值提示，不能替代标签。使用 <code>role="combobox"</code>、<code>aria-haspopup="listbox"</code>、<code>aria-autocomplete="none"</code>、<code>aria-expanded</code> 和 <code>aria-controls</code>。控制器会为选项补充稳定 ID，并通过 <code>aria-activedescendant</code> 暴露当前选项。</dd>
      <dt><code>&lt;div data-popover aria-hidden="true"&gt;</code></dt>
      <dd>
        浮层内容。通过共享 Popover 规则支持 <code>data-side</code> 和 <code>data-align</code>；运行时会根据可视视口翻转并限制列表位置。
        <dl>
          <dt><code>&lt;div role="listbox"&gt;</code></dt>
          <dd>
            选项容器。多选模式添加 <code>aria-multiselectable="true"</code>。
            <dl>
              <dt><code>&lt;div role="option" data-value="..." data-label="..."&gt;</code></dt>
              <dd>可选择的选项。提交值来自 <code>data-value</code>。可选的 <code>data-label</code> 控制已选显示文本和 <code>data-format="object"</code> 中的标签；省略时使用去除首尾空白后的文本内容。</dd>
              <dt><code>&lt;hr role="separator"&gt;</code> <span class="badge" data-variant="secondary">Optional</span></dt>
              <dd>分隔选项组或相邻选项。</dd>
              <dt><code>&lt;div role="group"&gt;</code> <span class="badge" data-variant="secondary">Optional</span></dt>
              <dd>选项组。使用 <code>aria-labelledby</code> 关联组标题。</dd>
              <dt><code>&lt;span role="heading"&gt;</code> <span class="badge" data-variant="secondary">Optional</span></dt>
              <dd>选项组标题。</dd>
            </dl>
          </dd>
        </dl>
      </dd>
      <dt><code>&lt;input type="hidden"&gt;</code></dt>
      <dd>提交值。根节点存在 <code>data-placeholder</code> 时，空值表示尚未选择。单选保存字符串，多选保存 JSON 数组；设置 <code>data-format="object"</code> 后，值序列化为 <code>&#123; value, label &#125;</code> 对象。</dd>
    </dl>
  </dd>
</dl>

### JavaScript API

| 应用程序编程接口 | 类型 | 描述 |
| --- | --- | --- |
| `change` | 活动 | 在 `event.detail.value` 和 `event.detail.selected` 的选择发生更改时调度。 |
| `select.refresh()` | 方法 | 在现有 `role="listbox"` 元素内的子项发生更改后重新扫描选项。 |

## 无障碍

每个触发器都必须通过关联标签、`aria-label` 或 `aria-labelledby` 获得稳定的无障碍名称；占位文本和当前值不能替代字段标签。焦点始终保留在只读选择组合框触发器上，当前选项由 `aria-activedescendant` 标识。方向键只在可用选项间移动，Home 和 End 到达首尾可用选项，可打印字符执行忽略重音符号的键入匹配，Enter 或空格提交，Escape 在不改变值的情况下关闭并把焦点还给触发器。
