# 图标

为宿主提供统一尺寸、笔画和对齐的图形槽，适用于装饰提示或带有明确名称的独立图标。

## 用法

```html
<span class="icon" role="img" aria-label="Verified">
  <svg viewBox="0 0 24 24" aria-hidden="true"><path d="M20 6 9 17l-5-5" /></svg>
</span>
```

## React

```tsx
import { Icon } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <Icon role="img" aria-label="Verified">
      <svg viewBox="0 0 24 24" aria-hidden="true"><path d="M20 6 9 17l-5-5" /></svg>
    </Icon>
  );
}
```

该组件没有额外行为控制器，React 适配器只渲染标准语义根。

## Vue

```vue
<script setup>
```

Vue 适配器不包装额外容器，也不改变原生属性。

## 产品边界

图标不内置供应商品牌，也不能替代按钮标签和状态文字。官方品牌标识使用 Brand Lockup，不通过普通 Icon 伪装。

组件只发布可复用的交互边界。数据获取、持久化、权限、可信内容与业务实体继续由宿主产品拥有。

## 可访问性

装饰图标使用 aria-hidden；承担信息时使用 role=img 和名称。不要用 Unicode 字符代替一致的图标资产。
