# 卡片

卡片把一组可以独立理解的内容与少量相关操作组织在同一边界内。边界服务于信息分组，不应成为页面的默认容器。

## 用法

导入完整样式包，或按需导入卡片结构与视觉样式。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/card.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

根据内容语义选择根元素。独立条目使用 `<article>`，普通布局分组可以使用 `<div>`；不要为了获得外观改变内容本身的标题层级。

```html
<article class="card" aria-labelledby="release-title">
  <header>
    <h2 id="release-title">发布准备</h2>
    <p>汇总当前版本最重要的交付信号。</p>
  </header>
  <section>
    <p>24 / 26 项检查已通过。</p>
  </section>
  <footer>
    <button type="button" class="btn">开始审查</button>
  </footer>
</article>
```

### HTML 结构

| 元素或属性 | 必填 | 用途 |
| --- | --- | --- |
| `.card` | 是 | 卡片根边界 |
| 直接子 `header` | 推荐 | 标题、说明与头部操作 |
| `h2`、`h3` 或 `[data-title]` | 推荐 | 与页面层级一致的标题 |
| `.card-action` | 否 | 一个紧邻标题的状态或低频操作 |
| 直接子 `section` | 推荐 | 主内容 |
| 直接子 `footer` | 否 | 与当前内容直接相关的操作 |
| `data-size="sm"` | 否 | 高密度列表或侧栏中的紧凑间距 |

## 状态与变体

### 紧凑卡片

小尺寸只改变密度，不降低信息完整性。适合侧栏摘要、检查结果或窄列表；触控界面中的按钮仍保持足够目标尺寸。

### 媒体

只有图片本身提供理解内容所需的信息时才放入卡片。图像保持真实宽高比并提供替代文本；装饰图使用空 `alt`。不要用无关封面填补空白。

卡片本身不是选择控件，也没有统一的禁用状态。需要整卡导航时使用一个覆盖明确内容的链接模式；需要多选时在卡片内放置具名复选框，并让集合拥有选择状态。不要同时给整个卡片和内部操作添加冲突的点击行为。

### RTL

卡片使用逻辑内外边距，标题操作会随文本方向移动。图片、图表和产品 Logo 不镜像；有方向含义的箭头由宿主单独翻转。

## React

```tsx
import { Button, Card } from "@a3s-lab/ui/react";

export function ReleaseReadinessCard() {
  return (
    <Card as="article" aria-labelledby="release-title">
      <header>
        <h2 id="release-title">0.4.0 发布准备</h2>
        <p>24 / 26 项检查已通过。</p>
      </header>
      <section>
        <p>还有 2 个阻塞项需要审查。</p>
      </section>
      <footer>
        <Button type="button">开始审查</Button>
      </footer>
    </Card>
  );
}
```

`Card` 只映射语义根元素和稳定子结构。内容、导航和选择由宿主拥有，因此不提供组件 hook。

## Vue

```vue
<script setup>
import { Button, Card } from "@a3s-lab/ui/vue";
</script>

<template>
  <Card as="article" aria-labelledby="release-title">
    <header>
      <h2 id="release-title">0.4.0 发布准备</h2>
      <p>24 / 26 项检查已通过。</p>
    </header>
    <section>
      <p>还有 2 个阻塞项需要审查。</p>
    </section>
    <footer>
      <Button type="button">开始审查</Button>
    </footer>
  </Card>
</template>
```

Vue 适配器使用相同的 `article`、标题、内容和操作区，不增加包装层。

## 可访问性

卡片不是独立 ARIA 角色。使用 `article`、`section` 或普通 `div` 取决于内容语义，并用页面层级正确的标题帮助导航。不要让整卡点击区域吞掉内部链接和按钮；如果整卡只导航到一个目标，链接必须有清晰名称并保留可见焦点。头部状态不能只靠颜色，图片需要合适替代文本，操作顺序与视觉顺序必须一致。宿主负责数据、导航、选择和权限；组件只负责内容边界与排版。
