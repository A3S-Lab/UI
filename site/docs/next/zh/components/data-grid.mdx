# 数据网格

数据网格用于需要排序、选择、批量操作和远程分页的资源集合。它建立在表格、复选框、筛选栏和分页组件上，不接管查询、权限或数据获取。

## 用法

先加载运行时和数据网格控制器，或直接使用完整 JavaScript 包。

```html
<script src="/assets/js/runtime.min.js" defer></script>
<script src="/assets/js/data-grid.min.js" defer></script>
```

```html
<section class="data-grid" data-responsive="stack" aria-labelledby="grid-title">
  <header><div data-grid-identity><h2 id="grid-title">运行环境</h2></div></header>
  <div data-grid-viewport tabindex="0">
    <table class="table">
      <thead><tr><th><input type="checkbox" data-grid-select-all aria-label="选择全部" /></th><th aria-sort="none"><button type="button" data-grid-sort="name">名称</button></th></tr></thead>
      <tbody><tr data-value="production"><td data-grid-select-cell><input type="checkbox" data-grid-select value="production" aria-label="选择生产环境" /></td><td data-label="名称">生产环境</td></tr></tbody>
    </table>
  </div>
</section>
```

### 参数

| API | 用途 |
| --- | --- |
| `data-grid-viewport` | 数据网格唯一的横向和纵向滚动区域 |
| `data-grid-select` / `data-grid-select-all` | 行选择与全选复选框 |
| `data-grid-sort="key"` | 更新表头 `aria-sort` 并请求宿主排序 |
| `data-responsive="stack"` | 在 640px 以下把每行重排为带标签的记录；单元格需提供 `data-label` |
| `--data-grid-max-height` | 可选的网格最大高度 |

### JavaScript API

```js
const grid = document.querySelector(".data-grid");
grid.selectAll();
grid.clearSelection();
grid.refresh();
grid.addEventListener("a3s:data-grid-sort", ({ detail }) => loadPage(detail));
```

选择变化触发 `a3s:data-grid-selection-change`，详情包含 `values`、`rows` 和 `selectedCount`。排序触发 `a3s:data-grid-sort`，详情为 `{ key, direction }`；控制器不会擅自重排行或请求数据。

## 状态与变体

客户端集合可以直接替换行；服务端集合应保持当前筛选和排序，并在加载时保留列宽。空白、错误和权限不足使用一个跨列的 `data-grid-state` 区域。行操作属于网格契约，不需要单独的公共组件。

默认模式在窄屏保留横向滚动；只有当记录字段仍能线性阅读时才使用 `data-responsive="stack"`。大量列、可编辑单元格或列间比较任务应继续使用滚动表格。

## 无障碍

表头必须使用真实 `<th>`，可排序列把 `aria-sort` 放在表头而不是按钮上。每个复选框都需要包含行名称的标签；批量操作出现后不移动焦点。服务端更新结果数量时使用礼貌播报，加载期间不要清空当前选择而不解释原因。
