# 设置布局

Settings Layout 提供可导航的配置分区与真实表单控件，适用于运维配置、偏好、策略、Provider、路由与其他结构化设置。

## 用途

```html
<div class="settings-layout">
  <aside><nav aria-label="Settings sections">...</nav></aside>
  <main><section id="general">...</section></main>
</div>
```

### 参数

| 参数 | 默认 | 目的 |
| --- | --- | --- |
| `--settings-navigation-size` | `14rem` | 导航栏宽度 |
| `--settings-layout-height` | `auto` | 可选有界高度，导航与内容独立滚动 |
| `--settings-section-gap` | `1.5rem` | 配置部分之间的间隙 |
| `aria-current="page"` | — | 标记活动设置目标 |

## 变体和状态

布局使用固定的二级导航边界和独立滚动内容区。低于 768px 时，导航变成有边界的横向分区列表。表单状态属于子组件：`required`、`disabled`、`aria-invalid`、验证消息、脏状态和保存反馈。需要稳定的“名称—控件”网格时，组合[设置行](/components/setting-row)。

## 可访问性

使用真实表单控件与字段标签，不要用未结构化的源码编辑器代替配置界面。原始配置源码可作为高级入口保留。每个分区都需要唯一标题与 ID，供导航直接定位。
