# 代码高亮器

呈现已经由可信渲染器处理的代码，并支持聚焦、横向滚动与局部标记。

## 用法

```html
<pre class="highlighter" tabindex="0">
  <code><span data-code-line>const status = <mark>"ready"</mark>;</span><span data-code-line>render(status);</span></code>
</pre>
```

## React

```tsx
import { Highlighter } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <Highlighter tabIndex="0">
      <code><span data-code-line>const status = <mark>"ready"</mark>;</span><span data-code-line>render(status);</span></code>
    </Highlighter>
  );
}
```

该组件没有额外行为控制器，React 适配器只渲染标准语义根。

## Vue

Vue 适配器不包装额外容器，也不改变原生属性。

| 方法 | — |

## 产品边界

组件不执行代码、不推断语言，也不接收未经净化的 HTML。语法标记和安全边界属于宿主渲染器。

组件只发布可复用的交互边界。数据获取、持久化、权限、可信内容与业务实体继续由宿主产品拥有。

## 可访问性

代码方向固定从左到右，颜色具有足够对比度，局部强调同时使用背景或结构而非只改变文字颜色。
