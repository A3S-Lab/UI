# 消息引用

消息引用把一项陈述连接到具名来源，同时保持阅读连续性。来源获取和预览行为由宿主应用负责。

</Preview>

## 用法

```html
<a class="message-citation" href="#source-1">
  <span data-citation-index>1</span>
  <span data-citation-title>组件清单</span>
  <span data-citation-source>components.json</span>
</a>
```

### 参数

| API | 取值 | 用途 |
| --- | --- | --- |
| 根 `<a>` | 必须 | 跳转到来源的原生导航 |
| `data-citation-index` | 可选 | 紧凑引用序号 |
| `data-citation-title` | 必须 | 人可读的来源标题 |
| `data-citation-source` | 可选 | 主机、文件或发布方 |

## 状态与变体

来源不可用时保留文本并明确标记不可用，不要留下仍可操作的失效链接。

## 无障碍

链接名称脱离上下文后仍应有意义。关闭引用预览后将焦点恢复到引用链接。

## React

```tsx
import { MessageCitation } from "@a3s-lab/ui/react";

export function Example() {
  return (
    <MessageCitation href="#example">组件内容</MessageCitation>
  );
}
```

适配器只替换指南中已记录的语义根元素，不增加包装层；内部标记继续使用上方 HTML 契约。

<script setup>
import { MessageCitation } from "@a3s-lab/ui/vue";
