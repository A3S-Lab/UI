# 条件分支

> [!IMPORTANT]
> 本页记录 A3S Flow `0.4.2` 八节点兼容 API，仅用于迁移。新编辑器请使用 [Flow 1.0 DAG 节点契约](/components/form-system/workflow-node-embedding)和 `A3SFlowDagNodeConfigurationPanel`。

`flow.condition` 根据工作流数据计算一条无副作用的条件规则，并选择下一条执行路径。

<A3SFlowNodeDemo nodeType="flow.condition" />

## 开发者契约

| 契约 | 值 |
| --- | --- |
| 分类 | 流程控制 |
| Runtime binding | `runtime_condition` |
| A3S Flow 版本 | `0.4.2` |
| 稳定命令 ID | 不适用 |
| Lowering | 接入系统在恢复执行时以确定性方式计算条件 |

## 在 MDX 中使用

传入稳定节点类型即可嵌入带两个分支端口的条件配置：

```mdx
import { A3SFlowNodeDemo } from '../../../../../../theme/mdx/form/A3SFlowNodeDemo';

<A3SFlowNodeDemo nodeType="flow.condition" />
```

## 配置属性

| 属性 | 值类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `input` | JSON object | 否 | `{}` | 提供给谓词的 JSON 值或上游数据。 |
| `expression` | Flow expression | 是 | `input.approved == true` | 只读取已保存的工作流状态，不产生副作用。 |
| `matched_label` | `string` | 是 | `Matched` | true 路径的画布标签。 |
| `otherwise_label` | `string` | 是 | `Otherwise` | false 路径的画布标签。 |

## 端口

| 方向 | ID | 标签 | 类型 | 数据类型 | 可用条件 |
| --- | --- | --- | --- | --- | --- |
| 输入 | `in` | 执行判断 | Control | `FlowControl` | 始终可用 |
| 输入 | `value` | 待判断数据 | Data | `JsonValue` | 始终可用 |
| 输出 | `matched` | 条件成立 | Control | `FlowControl` | 谓词返回 `true` |
| 输出 | `otherwise` | 条件不成立 | Control | `FlowControl` | 谓词返回 `false` |

## 配置值

```json
{
  "input": { "approved": true },
  "expression": {
    "apiVersion": "a3s.dev/flow-expression/v1",
    "expression": {
      "op": "eq",
      "left": { "op": "field", "path": "input.approved" },
      "right": { "op": "literal", "value": true }
    }
  },
  "matched_label": "Approved",
  "otherwise_label": "Needs review"
}
```

## 校验与运行时契约

- 表单校验检查标签和 JSON 属性结构。
- 节点校验检查表达式版本封套与支持的 AST 操作符。
- 节点级校验不会证明字段路径来自工作流输入或持久化历史。
- 宿主/编译器限制字段根、解析输入端口映射，并保证求值过程没有副作用。
- 分支标签只影响画布显示；图边始终绑定稳定的 `matched` 与 `otherwise` 端口 ID。
