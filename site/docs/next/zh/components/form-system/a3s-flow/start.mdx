# 工作流开始

> [!IMPORTANT]
> 本页记录 A3S Flow `0.4.2` 八节点兼容 API，仅用于迁移。新编辑器请使用 [Flow 1.0 DAG 节点契约](/components/form-system/workflow-node-embedding)和 `A3SFlowDagNodeConfigurationPanel`。

`flow.start` 设置工作流标识、运行入口、输入规则和可选运行 ID，用于启动一次工作流运行。

<A3SFlowNodeDemo nodeType="flow.start" />

## 开发者契约

| 契约 | 值 |
| --- | --- |
| 分类 | 流程控制 |
| Runtime binding | `workflow_input` |
| A3S Flow 版本 | `0.4.2` |
| 稳定命令 ID | 不适用 |
| Lowering | 宿主调用 `start` 或 `start_with_id` |

## 在 MDX 中使用

传入稳定节点类型即可嵌入工作流开始的配置示例：

```mdx
import { A3SFlowNodeDemo } from '../../../../../../theme/mdx/form/A3SFlowNodeDemo';

<A3SFlowNodeDemo nodeType="flow.start" />
```

## 配置属性

| 属性 | 值类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `workflow_name` | `string` | 是 | `workflow.main` | 写入 `WorkflowSpec` 的稳定标识。 |
| `workflow_version` | `string` | 是 | `0.1.0` | 恢复执行时使用的不可变版本。 |
| `runtime_kind` | `native_ts \| rust_embedded` | 是 | `native_ts` | 使用紧凑标签页控件。 |
| `entrypoint` | `string` | 是 | `workflows/main.ts` | 运行时源码路径或嵌入式运行时键。 |
| `export_name` | `string` | 是 | `main` | 导出的工作流函数。 |
| `input_schema` | JSON object | 是 | `{ "type": "object", "additionalProperties": true }` | 宿主启动运行时接受的 JSON Schema。 |
| `run_id_expression` | Flow expression | 否 | 字面量 `null` | 高级设置；非空值选择幂等 `start_with_id`。 |

## 端口

工作流开始没有输入端口。

| 方向 | ID | 标签 | 类型 | 数据类型 | 可用条件 |
| --- | --- | --- | --- | --- | --- |
| 输出 | `next` | 继续 | Control | `FlowControl` | 始终可用 |
| 输出 | `input` | 工作流输入 | Data | `JsonValue` | 始终可用 |

## 配置值

```json
{
  "workflow_name": "records.review",
  "workflow_version": "0.1.0",
  "runtime_kind": "native_ts",
  "entrypoint": "workflows/records-review.ts",
  "export_name": "main",
  "input_schema": {
    "type": "object",
    "properties": {
      "requestId": { "type": "string" },
      "recordId": { "type": "string" }
    },
    "required": ["requestId", "recordId"],
    "additionalProperties": false
  },
  "run_id_expression": {
    "apiVersion": "a3s.dev/flow-expression/v1",
    "expression": { "op": "field", "path": "input.requestId" }
  }
}
```

## 校验与运行时契约

- 表单校验检查必填字符串和 JSON 对象结构。
- 节点校验检查表达式版本封套与支持的 AST 操作符。
- 非空运行 ID 表达式必须至少引用一个字段；节点级校验不会限制字段路径命名空间。
- 接入系统按 `input_schema` 校验输入，把运行 ID 路径限制为工作流输入或已保存状态，并解析运行时入口。
- 空运行 ID 表达式使用 `start`；非空表达式由宿主解析后使用 `start_with_id`。
