# 批量执行步骤

> [!IMPORTANT]
> 本页记录 A3S Flow `0.4.2` 八节点兼容 API，仅用于迁移。新编辑器请使用 [Flow 1.0 DAG 节点契约](/components/form-system/workflow-node-embedding)和 `A3SFlowDagNodeConfigurationPanel`。

`flow.batch` 按列表顺序执行一组非空步骤并收集结果，当前采用串行处理而不是并行执行。

<A3SFlowNodeDemo nodeType="flow.batch" />

## 开发者契约

| 契约 | 值 |
| --- | --- |
| 分类 | 任务执行 |
| Runtime binding | `schedule_steps` |
| A3S Flow command | `ScheduleSteps` |
| 稳定命令 ID | 不可变图节点 ID 加 `step_key` |
| A3S Flow 版本 | `0.4.2` |

## 在 MDX 中使用

表格中的每一行都直接写入 `steps` 配置，行界面元数据不会进入保存结果。

```mdx
import { A3SFlowNodeDemo } from '../../../../../../theme/mdx/form/A3SFlowNodeDemo';

```

## 配置属性

节点只有一个必填的 `steps` 表格。每个成员包含以下属性。

| 成员属性 | 值类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `step_key` | `string` | 是 | — | 批次内非空且唯一。 |
| `step_name` | `string` | 是 | — | 接入系统已注册的任务。 |
| `input_mapping` | Flow expression | 是 | 字段 `input` | 调度前解析。 |
| `max_attempts` | Integer `1..100` | 是 | `3` | 包含首次执行。 |
| `retry_delay_ms` | Integer `0..86400000` | 是 | `0` | 每次尝试之间的持久化延迟。 |
| `on_exhausted` | `fail_run \| continue_workflow` | 是 | `fail_run` | 控制批次的可恢复错误端口。 |

## 端口

| 方向 | ID | 标签 | 类型 | 数据类型 | 可用条件 |
| --- | --- | --- | --- | --- | --- |
| 输入 | `in` | 执行批次 | Control | `FlowControl` | 始终可用 |
| 输入 | `input` | 批次输入 | Data | `JsonValue` | 始终可用 |
| 输出 | `done` | 批次完成 | Control | `FlowControl` | 始终可用 |
| 输出 | `results` | 步骤结果 | Data | `JsonValue[]` | 始终可用 |
| 输出 | `recoverable_failure` | 失败分支 | Control | `FlowControl` | 至少一个成员继续工作流 |
| 输出 | `errors` | 失败详情 | Data | `String[]` | 至少一个成员继续工作流 |

## 配置值

```json
{
  "steps": [
    {
      "step_key": "load-record",
      "step_name": "records.load",
      "input_mapping": {
        "apiVersion": "a3s.dev/flow-expression/v1",
        "expression": { "op": "field", "path": "input.recordId" }
      },
      "max_attempts": 3,
      "retry_delay_ms": 500,
      "on_exhausted": "fail_run"
    },
    {
      "step_key": "write-audit",
      "step_name": "audit.write",
      "input_mapping": {
        "apiVersion": "a3s.dev/flow-expression/v1",
        "expression": { "op": "field", "path": "input.requestId" }
      },
      "max_attempts": 2,
      "retry_delay_ms": 1000,
      "on_exhausted": "continue_workflow"
    }
  ]
}
```

## 校验与运行时契约

- 表单校验检查表格与成员属性结构。
- 节点校验拒绝空批次、非对象成员、空键或重复键、空处理器名、无效表达式、越界重试参数和不可用的已连接端口。
- 只有至少一个成员使用 `continue_workflow` 时，`recoverable_failure` 和 `errors` 才可用。
- 宿主解析每个处理器，并以不可变图节点 ID 与 `step_key` 生成持久化成员 ID。
- 恢复执行时，成员顺序和键必须保持稳定；修改键会改变持久化命令身份。
