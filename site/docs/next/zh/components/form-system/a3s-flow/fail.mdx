# 标记工作流失败

> [!IMPORTANT]
> 本页记录 A3S Flow `0.4.2` 八节点兼容 API，仅用于迁移。新编辑器请使用 [Flow 1.0 DAG 节点契约](/components/form-system/workflow-node-embedding)和 `A3SFlowDagNodeConfigurationPanel`。

`flow.fail` 结束工作流并保存由错误表达式生成的失败原因，不负责重试、补偿或通知。

<A3SFlowNodeDemo nodeType="flow.fail" />

## 开发者契约

| 契约 | 值 |
| --- | --- |
| 分类 | 流程控制 |
| Runtime binding | `fail` |
| A3S Flow command | `Fail` |
| 稳定命令 ID | 描述符未声明稳定 ID 绑定 |
| A3S Flow 版本 | `0.4.2` |

## 在 MDX 中使用

示例包含失败节点预览和错误映射配置；标记工作流失败没有输出端口。

```mdx
import { A3SFlowNodeDemo } from '../../../../../../theme/mdx/form/A3SFlowNodeDemo';

<A3SFlowNodeDemo nodeType="flow.fail" />
```

## 配置属性

| 属性 | 值类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `error_expression` | Flow expression | 是 | `"Workflow failed: " + input.reason` | 解析结果写入失败状态。 |

## 端口

| 方向 | ID | 标签 | 类型 | 数据类型 | 可用条件 |
| --- | --- | --- | --- | --- | --- |
| 输入 | `in` | 标记失败 | Control | `FlowControl` | 始终可用 |
| 输入 | `error` | 失败原因 | Data | `String` | 始终可用 |

标记工作流失败没有输出端口。

## 配置值

```json
{
  "error_expression": {
    "apiVersion": "a3s.dev/flow-expression/v1",
    "expression": {
      "op": "concat",
      "values": [
        { "op": "literal", "value": "Workflow failed: " },
        { "op": "field", "path": "input.reason" }
      ]
    }
  }
}
```

## 校验与运行时契约

- 表单校验要求 `error_expression` 为对象。
- 节点校验检查表达式版本封套与 AST 操作符。
- A3S Form 不会静态证明表达式结果一定是字符串；宿主或运行时负责最终类型检查。
- 宿主限制字段路径来源，并把解析结果降低为 `Fail` 命令的错误文本。
- 重试耗尽策略选择 `fail_run` 时可以直接进入失败终态；`continue_workflow` 则使用 Step 的可恢复错误端口。
