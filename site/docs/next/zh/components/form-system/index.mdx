# Form 系统

A3S UI 的结构化表单组件把 Schema、可视化设计、受控渲染、校验和工作流节点配置放在同一份确定性契约上。它与按钮、字段、数据网格和应用外壳使用同一套 A3S UI 视觉语言，不再作为独立产品站发布。

<Callout title="在统一 Playground 中试用" icon="code" action={{ label: "打开 Form Playground", href: "https://a3s-lab.github.io/UI/playground/forms/" }}>
  Form Playground 属于 A3S UI 的 Playground 路由族，可直接编辑、校验、预览和导入表单 JSON。
</Callout>

## 选择接入层

| 接入层 | 入口 | 适用场景 |
| --- | --- | --- |
| Form Core | `@a3s-lab/ui/form/core` | 编译、规则、校验、补丁、locale 与无界面状态 |
| React 组件 | `@a3s-lab/ui/form/react` | Designer、Renderer、Flow 配置面板与扩展字段 |
| React Hooks | `@a3s-lab/ui/form/react-hooks` | React Hook Form resolver、订阅、字段数组和 Renderer 绑定 |
| Vue 组件 | `@a3s-lab/ui/form/vue` | Vue 3 Designer 与 Renderer 适配器 |
| Vue composables | `@a3s-lab/ui/form/vue-hooks` | 表单、字段、字段数组、上下文、校验和提交状态 |
| Web Components | `@a3s-lab/ui/form/web-component` | 框架无关的 Designer 与 Renderer 自定义元素 |
| Workflow | `@a3s-lab/ui/form/workflow` | 工作流配置、受保护提交与交互 digest |

```bash
npm install @a3s-lab/ui
```

React 应用按需安装 `react`、`react-dom` 与 `react-hook-form`；Vue 应用按需安装 `vue`。这些框架接口共享同一个 Form Core，不会生成第二份 Schema 或校验语义。

## 当前组件能力

- 23 个内置字段，以及矩阵、重复字段组、数据表格、文件上传和签名扩展；
- 网格、分栏、卡片、标签页、折叠内容和分支向导布局；
- 确定性计算规则、异步宿主校验、动态数据源与本地化目录；
- A3S Form Schema Profile 1 与原生 Rust/WASM 提交值求值；
- 18 个可见 A3S Flow 1.0 DAG manifest、无损校验与语义 digest；
- React、Vue 和 Web Component 受控适配器，共享只读、错误、locale 和宿主能力边界。

## 产品边界

组件负责文档编译、受控值、交互和可检查的变更。持久化、身份、权限、凭证、文件存储、网络请求、业务副作用与最终提交继续由宿主产品拥有。
