# 形状与阴影

形状通过 6px 控件圆角、10px 稳定表面圆角和 14px 抬升表面圆角表达层级。阴影只属于浮动或重叠表面。

## 圆角

| 令牌 | 默认值 | 用途 |
| --- | ---: | --- |
| `--radius-sm` | 基础值减 4px | Badge 与微型控件 |
| `--radius-md` | 基础值减 2px | Button、Input 与导航项 |
| `--radius-lg` | 基础圆角 | Toolbar 与侧边导航 |
| `--radius-xl` | 基础值加 4px | Card 与 Panel |
| `--a3s-radius` | `14px` | 主要与抬升表面 |

## 阴影层级

| 令牌 | 用途 |
| --- | --- |
| `--a3s-shadow-composer` | 固定或浮动的任务输入器 |
| `--a3s-shadow-soft` | 菜单、弹出框、抽屉与紧凑浮层 |
| `--a3s-shadow` | 模态 Dialog 与大型浮动面板 |

边框与色调差是默认分隔方式。静态卡片、外壳、目录、任务记录和设置行不使用阴影。默认只用可见边框或宽柔阴影表达一条边，不叠加两者。
