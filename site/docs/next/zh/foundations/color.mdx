# 颜色

A3S UI 以中性色承担结构，以虹膜色承担焦点与选择。品牌蓝只属于身份和信息提示；绿色、琥珀色与红色只表达结果，不能替代文本、图标或结构。

## 语义令牌

| 角色                    | 浅色      | 深色      | 用途             |
| ----------------------- | --------- | --------- | ---------------- |
| `--background`          | `#ffffff` | `#0d0d0f` | 应用画布         |
| `--foreground`          | `#111113` | `#f4f4f5` | 主要内容         |
| `--card`                | `#ffffff` | `#151518` | 稳定与抬升表面   |
| `--muted`               | `#f7f7f8` | `#19191d` | 弱化表面         |
| `--accent`              | `#f4f4f5` | `#202024` | 悬停表面         |
| `--a3s-panel-strong`    | `#eeeeef` | `#26262b` | 激活表面         |
| `--muted-foreground`    | `#52525b` | `#b4b4bc` | 辅助文本         |
| `--a3s-subtle`          | `#71717a` | `#888891` | 非关键注释       |
| `--border`              | `#dedee1` | `#333338` | 控件与浮层边界   |
| `--input`               | `#c9c9ce` | `#45454b` | 强边界           |
| `--primary`             | `#111113` | `#f4f4f5` | 默认主操作       |
| `--ring` / `--a3s-blue` | `#5b57d9` | `#8378f0` | 焦点、链接与选择 |
| `--a3s-brand-blue`      | `#249bf6` | `#38a8eb` | A3S 身份与信息   |

浅色主题中的成功、警告和危险值分别是 `#16845b`、`#a86412` 与 `#c93d45`；深色主题分别是 `#57c795`、`#e7ad55` 与 `#ef7a82`。普通卡片、导航和工具栏不使用这些状态色装饰。

```css
.selection-region {
  --ring: var(--a3s-blue);
}
```

## 参数

主题切换通过 `<html>` 上的 `dark` 类完成。应用可以在 `:root`、`.dark` 或局部产品容器中覆盖语义令牌，但必须同时验证文本对比度、焦点可见性与状态含义。
