# 颜色

A3S 调色板使用冷调中性色与刻意克制的单一蓝色。绿色、琥珀色和红色只报告语义状态，不作为页面主题或分类品牌色。

## 语义令牌

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--background` | `#f8f9fb` | `#101118` | 应用画布 |
| `--foreground` | `#17191d` | `#f2f3f5` | 主要内容 |
| `--card` | `#ffffff` | `#171820` | 抬升或分组表面 |
| `--muted` | `#f1f3f6` | `#1e2028` | 低强调填充与控件 |
| `--muted-foreground` | `#667085` | `#a4a8b2` | 辅助文本 |
| `--border` | `#e6e8ec` | `#2a2d35` | 分隔线与边界 |
| `--primary` | `#2864e8` | `#6ca3ff` | 主要操作与选中 |
| `--ring` | `#2864e8` | `#6ca3ff` | 键盘焦点 |
| `--destructive` | `#c9363c` | `#f27777` | 错误与破坏性操作 |

蓝色用于操作、选中、进度和焦点。绿色、琥珀色和红色只在状态确实需要时使用，不能铺满整个导航或页面区域。浅色与深色主题都必须保持足够对比度。

```css
.my-resource {
  --resource-accent: var(--a3s-blue);
}
```

## 参数

主题切换通过 `<html>` 上的 `dark` 类完成。应用可以在 `:root`、`.dark` 或局部产品容器中覆盖语义令牌，但应保持令牌名称稳定，让组件与文档预览始终同步。
