## 字体族

| 令牌 | 字体栈 | 用途 |
| --- | --- | --- |
| `--font-sans` | Geist Sans、System UI、PingFang SC、Microsoft YaHei、Noto Sans CJK SC | 界面与文档文本 |
| `--font-mono` | Geist Mono、SFMono-Regular、Consolas、Liberation Mono、Menlo | 代码、命令、路径与测量值 |

## 字号层级

| 角色 | 字号 / 行高 | 字重 | 说明 |
| --- | ---: | ---: | --- |
| 展示标题 | `28–40 / 32–46px` | `650` | 仅起始页与空状态 |
| 页面标题 | `24 / 30px` | `650` | 每个视图一个 |
| 分区标题 | `16 / 22px` | `650` | 设置与检查器区域 |
| 控件 | `13 / 20px` | `500–600` | 紧凑应用工具栏 |
| 正文 | `14 / 22px` | `400` | 默认正文，每行控制在 65–75 个字符 |
| 说明文字 | `12 / 16px` | `400–500` | 元数据与状态 |

## 参数

在应用根节点覆盖 `--font-sans` 与 `--font-mono`。除非产品已经完成密度测量，否则应保留字号与行高关系。不要把状态、文件名或长标签全部转成大写。
