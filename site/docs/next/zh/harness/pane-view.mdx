# Pane View

Pane View 是带标题、折叠状态和可调整内容高度的工具窗格栈。它适合文件大纲、符号、筛选器、历史记录和属性分区；当每个区域必须同时可见且不需要折叠时，使用 [Split View](/harness/split-view)。

React `usePaneview` 返回 `api`、`ready` 与稳定的 `onReady`；Vue composable 返回 `api` shallow ref 与 `onReady`。折叠、展开、调整尺寸和顺序仍由原生 `PaneviewApi` 与面板 API 管理。

## 状态与行为

- 标题必须描述窗格内容，不能只显示图标或内部 ID。
- 默认展开高频内容；低频、昂贵或上下文相关的区域可以默认折叠。
- 监听 `onDidExpansionChange` 同步宿主偏好，但不要因为异步数据为空而自动折叠。
- 自定义 Header 必须保留展开状态、点击目标、键盘操作、焦点样式和可访问名称。
- 拖放重排只改变展示顺序；数据所有权和权限不会随窗格位置变化。

## 无障碍

标题与内容应形成明确关联，展开状态必须可被读屏识别。折叠后把内容从焦点顺序中移除，展开后不要强行移动用户焦点。粗指针环境下标题目标至少 44px 高。
