# Harness

Harness 集中放置构建 Coding Agent 工作流需要的组件。它把任务输入、对话、执行、权限、审阅、证据和预览工具从通用应用布局中分离出来，让组件选择从用户任务出发，而不是从页面外观出发。

当前 Harness 包含 28 个公开组件，所有页面继续使用稳定的 `/components/*` 路由，现有链接与包导入方式不变。

## 工作区布局

[Dock 工作区](/harness/dock-workspace) · [Grid View](/harness/grid-view) · [Split View](/harness/split-view) · [Pane View](/harness/pane-view)

这一组是可选布局集成，不计入 114 个语义组件清单。Dock 工作区负责标签、拖放、浮动、弹出、Edge Group 和布局恢复；Grid、Split 与 Pane View 分别解决固定二维网格、单轴分栏和可折叠工具窗格。四类布局均保留原生、React、Vue 用法和对应 Hook。

[任务计划](/components/task-plan) · [计划步骤](/components/plan-step) · [任务队列](/components/task-queue) · [审批请求](/components/approval-request) · [执行项](/components/execution-item) · [检查点](/components/checkpoint) · [工具调用](/components/tool-call) · [工具调用时间线](/components/tool-call-timeline) · [工具结果](/components/tool-result) · [变更审阅](/components/change-review) · [执行证据](/components/execution-evidence) · [产物卡](/components/artifact-card)
