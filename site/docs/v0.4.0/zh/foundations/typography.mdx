## 字体族

| 令牌          | 字体栈                                                | 用途                             |
| ------------- | ----------------------------------------------------- | -------------------------------- |
| `--font-sans` | Geist、HarmonyOS Sans SC、PingFang SC、系统无衬线字体 | 界面与文档文本                   |
| `--font-mono` | Geist Mono、SFMono-Regular、Consolas、系统等宽字体    | 代码、命令、路径、快捷键与测量值 |

## 字号层级

| 角色     | 字号 / 行高                       |  字重 | 用途                   |
| -------- | --------------------------------- | ----: | ---------------------- |
| 展示标题 | `clamp(32px, 4vw, 40px)` / `1.08` | `680` | 文档首页与空状态地标   |
| 页面标题 | `24px` / `1.2`                    | `660` | 页面身份               |
| 分区标题 | `20px` / `1.3`                    | `650` | 主要文档与应用区域     |
| 子标题   | `16px` / `1.4`                    | `620` | 表单组与检查器区域     |
| 正文     | `15px` / `1.7`                    | `400` | 文档与长任务输出       |
| 界面     | `14px` / `1.4`                    | `520` | 控件、导航、表格与菜单 |
| 注释     | `13px` / `1.45`                   | `450` | 元数据与说明           |
| 微型     | `12px` / `1.4`                    | `560` | 少量密集标签与测量值   |

展示标题字距保持在 `-0.035em` 到 `-0.02em`，界面标签使用正常字距。标题上方留白大于下方，正文行宽保持在 65–75 个字符。中文与英文使用相同角色，不强制大写。

## 参数

在应用根节点覆盖 `--font-sans` 与 `--font-mono`。除非产品完成过密度测量，否则不要独立缩小字号或行高；这会同时损害中英文可读性与 200% 缩放表现。
