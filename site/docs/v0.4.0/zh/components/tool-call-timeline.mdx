# 工具调用时间线

工具调用时间线把一次任务中的多次调用按发生顺序组织起来，并在顶部汇总运行、等待处理、完成和异常数量。它解决的是“任务现在卡在哪里”，不是替代完整审计日志。

## 何时使用

当一次任务包含至少两次可独立理解的调用，并且用户需要判断顺序、当前阻塞或异常来源时使用时间线。只有一次调用时直接使用工具调用；跨会话检索、筛选和导出属于审计日志。

历史默认只收起较早的稳定调用。正在运行、等待确认、失败和最新调用始终可见，不能为了节省空间隐藏需要处理的状态。`data-visible-calls` 定义折叠时保留的最新数量。

## 汇总与控制器

`getSummary()` 返回 `total`、`active`、`attention`、`completed`、`problems` 和派生状态。等待确认优先于异常，异常优先于运行，以保证需要人工处理的状态不会被“仍在运行”掩盖。`expandHistory()` 和 `collapseHistory()` 同步历史条目、按钮可见性，并发送可持久化的偏好事件。

## 无障碍

列表保持真实 DOM 顺序。汇总使用一个 `aria-live="polite"` 输出，不为每个流式片段播报。折叠历史后，隐藏条目必须离开可访问树；展开按钮说明它会显示“较早调用”，不能只写“更多”。
