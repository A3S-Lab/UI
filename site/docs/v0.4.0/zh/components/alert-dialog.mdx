# 警报对话框

警报对话框要求用户在高风险或不可逆操作前做出明确选择；只有缺少响应就无法安全继续时才使用。

## 用法

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者仅导入基础 CSS、对话框组件 CSS 和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/dialog.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

警报对话框复用对话框组件 CSS，不需要额外样式文件。

使用 CDN 或包管理器集成时，请参见[安装页](/installation)。

  </Step>
  <Step title="添加警报对话框 HTML">

警报对话框使用原生 `<dialog class="alert-dialog">`。当用户必须明确选择才能安全继续时，不提供右上角关闭按钮，也不允许点击背景关闭。

```html
<button type="button" onclick="document.getElementById('demo-alert-dialog').showModal()" class="btn" data-variant="outline">删除账户</button>
<dialog id="demo-alert-dialog" class="alert-dialog" aria-labelledby="demo-alert-dialog-title" aria-describedby="demo-alert-dialog-description">
  <div>
    <header>
      <h2 id="demo-alert-dialog-title">确认删除账户？</h2>
      <p id="demo-alert-dialog-description">账户、项目和历史记录将被永久删除，且无法恢复。</p>
    </header>
    <footer>
      <button class="btn" data-variant="outline" onclick="this.closest('dialog').close('cancel')">取消</button>
      <button class="btn" data-variant="destructive" onclick="this.closest('dialog').close('confirm')">删除账户</button>
    </footer>
  </div>
</dialog>
```

  </Step>
</Steps>

### HTML 结构

<dl>
  <dt><code>&lt;button type="button" onclick="dialog.showModal()"&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
  <dd>触发按钮。使用原生 <code>HTMLDialogElement.showModal()</code> 打开模态对话框。</dd>
  <dt><code>&lt;dialog class="alert-dialog" id="&#123; DIALOG_ID &#125;"&gt;</code></dt>
  <dd>
    原生模态对话框。存在标题和说明时，分别通过 <code>aria-labelledby</code> 与 <code>aria-describedby</code> 建立关系；紧凑布局使用 <code>data-size="sm"</code>。
    <dl>
      <dt><code>&lt;div&gt;</code></dt>
      <dd>
        对话框内容表面。
        <dl>
          <dt><code>&lt;header&gt;</code></dt>
          <dd>
            警报对话框标题区。
            <dl>
              <dt><code>&lt;figure&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
              <dd>用于解释风险类型的图标或图片，不能替代标题。</dd>
              <dt><code>&lt;h2 id="&#123; TITLE_ID &#125;"&gt;</code></dt>
              <dd>警报标题，由 <code>aria-labelledby</code> 引用。</dd>
              <dt><code>&lt;p id="&#123; DESCRIPTION_ID &#125;"&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
              <dd>结果与恢复说明，由 <code>aria-describedby</code> 引用。</dd>
            </dl>
          </dd>
          <dt><code>&lt;footer&gt;</code></dt>
          <dd>操作区。至少提供安全退出操作和明确命名的确认操作。</dd>
        </dl>
      </dd>
    </dl>
  </dd>
</dl>

### JavaScript API

警报对话框保留原生 `HTMLDialogElement` 契约。React 与 Vue 的 `useAlertDialog` 可调用 `showModal()` 和 `close(returnValue)`；`cancel` 与 `close` 仍是原生 DOM 事件。

## React

```tsx
import { AlertDialog, useAlertDialog } from "@a3s-lab/ui/react";

export function Example() {
  const control = useAlertDialog();
  return (
    <>
      <button type="button" onClick={() => control.call("showModal")}>
        删除运行记录
      </button>
      <AlertDialog
        ref={control.ref}
        aria-labelledby="delete-run-title"
        aria-describedby="delete-run-description"
      >
        <div>
          <header>
            <h2 id="delete-run-title">永久删除运行记录？</h2>
            <p id="delete-run-description">日志、证据和产物索引都将被删除，且无法恢复。</p>
          </header>
          <footer>
            <button type="button" onClick={() => control.call("close", "cancel")}>取消</button>
            <button type="button" onClick={() => control.call("close", "confirm")}>删除记录</button>
          </footer>
        </div>
      </AlertDialog>
    </>
  );
}
```

`useAlertDialog` 订阅清单中声明的 DOM 事件，并且只调用清单中公开的方法。适配器不创建另一套框架专属状态。

## 可访问性

标题必须准确命名决策，说明必须写明继续操作的影响以及是否可恢复，并通过 `aria-labelledby`、`aria-describedby` 与对话框关联。打开后把焦点放在最安全、最可预测的操作上；关闭后归还给原触发器。保留原生 Escape 与焦点约束，但当缺少明确选择就无法安全继续时，应拦截 `cancel`，且不能允许背景点击关闭。确认按钮使用动词和对象命名，不能只写“继续”。
