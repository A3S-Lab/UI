# 原生选择器

原生选择器让用户从较短的固定选项中选择一个值，并保留操作系统熟悉的交互与无障碍能力。

<Preview>
<div class="field w-full">
  <label for="native-select-fruit-zh">水果</label>
  <select id="native-select-fruit-zh" class="native-select w-full" aria-describedby="native-select-fruit-help-zh">
    <option value="">选择水果</option>
    <option value="apple">苹果</option>
    <option value="banana">香蕉</option>
    <option value="blueberry">蓝莓</option>
    <option value="pineapple">菠萝</option>

  </select>
  <p id="native-select-fruit-help-zh">为当前订单选择一种水果。</p>
</div>
</Preview>

## 用法

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者只导入基本CSS、原生选择CSS组件和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/native-select.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="添加原生选择器 HTML">

为原生 `<select>` 添加规范类 `class="native-select"`，并继续使用标准 `<option>` 与 `<optgroup>` 元素。旧的 `select` 类仅作为迁移期视觉别名保留；新代码与框架适配器统一使用 `native-select`，避免与自定义 Select 根节点混淆。

```html
<div class="field">
  <label for="native-select-fruit-html">水果</label>
  <select id="native-select-fruit-html" class="native-select" aria-describedby="native-select-fruit-help-html">
    <option value="">选择水果</option>
    <option value="apple">苹果</option>
    <option value="banana">香蕉</option>
    <option value="blueberry">蓝莓</option>
    <option value="pineapple">菠萝</option>
  </select>
  <p id="native-select-fruit-help-html">为当前订单选择一种水果。</p>
</div>
```

  </Step>
</Steps>

使用 Native Select 实现原生浏览器行为、表单集成和移动优化选择器。使用 [Select](/components/select) 自定义选项内容、多选行为或 JavaScript API。

## React

```tsx
import { NativeSelect, useNativeSelect } from "@a3s-lab/ui/react";

export function Example() {
  const control = useNativeSelect();
  return (
    <div className="field">
      <label htmlFor="native-select-fruit-react">水果</label>
      <NativeSelect
        id="native-select-fruit-react"
        ref={control.ref}
        defaultValue=""
        aria-describedby="native-select-fruit-help-react"
      >
        <option value="">选择水果</option>
        <option value="apple">苹果</option>
        <option value="banana">香蕉</option>
      </NativeSelect>
      <p id="native-select-fruit-help-react">为当前订单选择一种水果。</p>
    </div>
  );
}
```

`useNativeSelect` 订阅清单中声明的 DOM 事件，并且只调用清单中公开的方法。适配器不创建另一套框架专属状态。
