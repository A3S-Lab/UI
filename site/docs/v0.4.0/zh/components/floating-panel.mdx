# 浮动面板

让检查器、辅助工具或短期上下文停靠在主要任务旁，并在窄屏上自然转为底部面板。

## 用法

```html
<aside class="floating-panel" data-position="docked" data-state="open">
  <header><strong>检查器</strong><button type="button" class="btn" data-size="sm" data-variant="ghost" data-floating-panel-action="close">关闭</button></header><section><p>无需离开当前任务即可检查所选资源。</p></section>
</aside>
```

### 独立控制器

```js
import "@a3s-lab/ui/runtime";
import "@a3s-lab/ui/floating-panel";

const component = document.querySelector(".floating-panel");
component.getState();
```

控制器是幂等的；完整包可改为一次导入 `@a3s-lab/ui/all`。宿主通过可取消的 `before-*` 事件执行权限与业务校验。

## React

```tsx
import { FloatingPanel, useFloatingPanel } from "@a3s-lab/ui/react";

export function Example() {
  const control = useFloatingPanel();
  return (
    <FloatingPanel ref={control.ref} data-position="docked" data-state="open">
      <header><strong>检查器</strong><button type="button" className="btn" data-size="sm" data-variant="ghost" data-floating-panel-action="close">关闭</button></header><section><p>无需离开当前任务即可检查所选资源。</p></section>
    </FloatingPanel>
  );
}
```

`useFloatingPanel` 返回同一 DOM 契约的 `ref`、就绪状态、事件订阅和受类型约束的方法调用；它不会创建框架专属状态。

## Vue

```vue
<script setup>
import { FloatingPanel, useFloatingPanel } from "@a3s-lab/ui/vue";

const control = useFloatingPanel();
const componentRef = control.componentRef;
</script>

<template>
  <FloatingPanel ref="componentRef" data-position="docked" data-state="open">
    <header><strong>检查器</strong><button type="button" class="btn" data-size="sm" data-variant="ghost" data-floating-panel-action="close">关闭</button></header><section><p>无需离开当前任务即可检查所选资源。</p></section>
  </FloatingPanel>
</template>
```

`useFloatingPanel` 与 React hook 暴露相同的事件和方法集合，模板仍输出同一个根类与原生属性。

## 契约

| 接口 | 值 |
| --- | --- |
| 根选择器 | `.floating-panel` |
| 原生根元素 | `<aside>` |
| 状态 | `open`, `closed`, `floating`, `docked`, `sheet` |
| 事件 | `a3s:floating-panel-before-close`, `a3s:floating-panel-before-open`, `a3s:floating-panel-close`, `a3s:floating-panel-open` |
| 方法 | `close`, `getState`, `open`, `toggle` |

## 产品边界

浮动面板不等于通用卡片，也不用于必须中断用户的确认。宿主拥有持久化位置、尺寸和工作区布局。

组件只发布可复用的交互边界。数据获取、持久化、权限、可信内容与业务实体继续由宿主产品拥有。

## 可访问性

关闭操作可由 Escape 触发并把焦点还给开启者。停靠、浮动与移动端面板保持同一内容顺序和操作语义。
