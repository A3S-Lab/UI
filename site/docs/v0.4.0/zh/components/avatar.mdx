# 头像

头像用照片或稳定的后备标识帮助用户快速识别人、团队或自动化身份；它补充可见名称，不代替名称。

## 用法

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和完整样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

也可以只导入基础样式、头像组件和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/avatar.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

  </Step>
  <Step title="添加头像 HTML">

由根元素提供稳定名称；图片使用空 `alt`，后备首字母对读屏隐藏。这样图片加载成功或失败时都只读一次身份。

```html
<span class="avatar" role="img" aria-label="林然" data-state="ready">
  <img src="/people/lin-ran.jpg" alt="" />
  <span aria-hidden="true">LR</span>
</span>
```

图片加载失败后由宿主把 `data-state` 改为 `fallback`。组件会隐藏失败图片并显示后备内容。

  </Step>
</Steps>

### HTML 结构

| 元素或属性 | 必填 | 用途 |
| --- | --- | --- |
| `<span class="avatar">` | 是 | 单个身份的行内根元素 |
| `role="img"` 与 `aria-label` | 独立头像 | 提供不随图片状态变化的身份名称 |
| 直接子 `<img alt="">` | 可选 | 照片；空替代文本避免与根名称重复 |
| 直接子 `<span aria-hidden="true">` | 是 | 首字母、图标或其他后备标识 |
| `data-state` | `ready`、`fallback` | 由宿主同步图片加载结果 |
| `data-size` | `sm`、省略、`lg` | 24px、32px、40px 三个稳定尺寸 |
| `.avatar-badge` | 可选 | 角落状态提示，只作为辅助视觉信号 |
| `.avatar-group` | 可选 | 直接排列多个头像与一个 `data-count` 汇总项 |

## 状态与变体

### 图片与后备标识

后备内容不是错误提示，而是身份的等价视觉表示。首字母必须来自稳定名称，不能用随机颜色或无法解释的占位图标。

### 交互入口

头像本身不是按钮。需要打开账户菜单时，把头像放进真实按钮，并由按钮命名操作；按钮内的头像设为装饰，避免重复朗读。

## React

```tsx
import { useState } from "react";
import { Avatar } from "@a3s-lab/ui/react";

export function Example() {
  const [failed, setFailed] = useState(false);

  return (
    <Avatar
      role="img"
      aria-label="林然"
      data-state={failed ? "fallback" : "ready"}
    >
      {!failed && (
        <img src="/people/lin-ran.jpg" alt="" onError={() => setFailed(true)} />
      )}
      <span aria-hidden="true">LR</span>
    </Avatar>
  );
}
```

`Avatar` 映射同一个行内根元素。图片加载与后备状态属于应用数据，因此不提供没有行为依据的组件 hook。

## Vue

```vue
<script setup lang="ts">
import { ref } from "vue";
import { Avatar } from "@a3s-lab/ui/vue";

const failed = ref(false);
</script>

<template>
  <Avatar
    role="img"
    aria-label="林然"
    :data-state='failed ? "fallback" : "ready"'
  >
    <img v-if="!failed" src="/people/lin-ran.jpg" alt="" @error="failed = true" />
    <span aria-hidden="true">LR</span>
  </Avatar>
</template>
```

Vue 版本使用同一图片错误状态和语义根元素，不把头像资源请求放入适配器。

## 可访问性

独立头像由根元素提供一个稳定名称，图片 `alt` 为空、后备内容 `aria-hidden="true"`，避免图片和首字母被重复朗读。头像紧邻同名文本时，可以把整个头像设为 `aria-hidden="true"`。状态徽点只作视觉补充，在线、忙碌或离线必须同时有文字。可点击头像必须由外层按钮或链接承担名称、焦点和键盘行为。宿主负责身份数据、图片授权、加载失败、隐私与状态真实性；组件只负责呈现，不应根据头像颜色推断角色、在线状态或权限。
