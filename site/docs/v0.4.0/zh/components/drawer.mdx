## 用法

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者只导入基本CSS、抽屉组件CSS和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/drawer.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="引入 JavaScript">

复制或提供完整的 A3S UI JavaScript 包。

```html
<script src="/assets/js/all.min.js" defer></script>
```

或者复制或提供A3S UI运行时和抽屉脚本。

```html
<script src="/assets/js/runtime.min.js" defer></script>
<script src="/assets/js/drawer.min.js" defer></script>
```

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="添加抽屉 HTML">

A3S UI 使用原生 `<dialog>` 实现抽屉，让浏览器直接负责模态语义、焦点约束和背景内容的不可交互状态。抽屉脚本补充了安全的遮罩点击关闭，并等待退出动效结束后再调用原生关闭方法。该组件不模拟拖动手势、吸附点或拖动手柄。

### HTML 结构

<Callout type="warning" title="不提供拖动手柄" icon="triangle-alert">
A3S UI 不实现拖动关闭手势、吸附点或拖动手柄。抽屉通过点击遮罩、按下 Escape 或使用明确的关闭控件关闭。
</Callout>

<dl>
  <dt><code>&lt;button type="button" onclick="drawer.showModal()"&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
  <dd>触发按钮。A3S UI 直接使用原生 <code>HTMLDialogElement.showModal()</code> 方法。</dd>
  <dt><code>&lt;dialog class="drawer" data-side="bottom|top|left|right"&gt;</code></dt>
  <dd>
    原生模态抽屉。省略 <code>data-side</code> 时从底部打开；存在标题和说明时添加 <code>aria-labelledby</code> 与 <code>aria-describedby</code>。JavaScript 会添加 <code>data-drawer-initialized</code> 标记并管理带动效的关闭过程。
    <dl>
      <dt><code>&lt;article&gt;</code></dt>
      <dd>
        抽屉内容表面。
        <dl>
          <dt><code>&lt;header&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
          <dd>包含标题与可选说明的抽屉标题区。</dd>
          <dt><code>&lt;section&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
          <dd>可滚动的主体内容区。</dd>
          <dt><code>&lt;footer&gt;</code> <span class="badge" data-variant="secondary">可选</span></dt>
          <dd>位于主体之后的操作区。</dd>
        </dl>
      </dd>
    </dl>
  </dd>
</dl>

### JavaScript API

React 的 `useDrawer` 与 Vue 的同名 composable 暴露原生 `showModal()` 与增强后的 `close(returnValue)`。`close()` 会等待不超过 220ms 的退出过渡，并在减少动效环境中立即完成。

## React

```tsx
import { Drawer, useDrawer } from "@a3s-lab/ui/react";

export function GoalDrawer() {
  const drawer = useDrawer();
  return (
    <>
      <button type="button" onClick={() => drawer.call("showModal")}>
        调整目标
      </button>
      <Drawer
        ref={drawer.ref}
        data-side="right"
        aria-labelledby="goal-drawer-title"
        aria-describedby="goal-drawer-description"
      >
        <article>
          <header>
            <h2 id="goal-drawer-title">调整每日目标</h2>
            <p id="goal-drawer-description">选择一个可持续的任务目标。</p>
          </header>
          <section>
            <label>每日任务数 <input type="number" min="1" max="20" defaultValue="8" /></label>
          </section>
          <footer>
            <button type="button" onClick={() => drawer.call("close", "saved")}>保存更改</button>
            <button type="button" onClick={() => drawer.call("close")}>取消</button>
          </footer>
        </article>
      </Drawer>
    </>
  );
}
```

`useDrawer` 通过 `call()` 提供 `showModal` 与 `close(returnValue)`，保留原生对话框生命周期，不创建框架专属的重复打开状态。
