### HTML 结构

<dl>
  <dt>
    <code>&lt;div class="tabs"&gt;</code>
  </dt>
  <dd>
    标签页根容器。布局方向由子级标签列表的 <code>aria-orientation</code> 决定。
    <dl>
      <dt>
        <code>&lt;nav role="tablist" aria-orientation="horizontal"&gt;</code>
      </dt>
      <dd>
        包含标签按钮的列表。使用 <code>aria-orientation="vertical"</code>{" "}
        切换为垂直布局，使用 <code>data-variant="line"</code> 启用线型样式。
        <dl>
          <dt>
            <code>
              &lt;button role="tab" id="&#123; TAB_ID &#125;"
              aria-controls="&#123; PANEL_ID &#125;" aria-selected="true"
              tabindex="0"&gt;
            </code>
          </dt>
          <dd>
            标签触发按钮。当前标签使用 <code>aria-selected="true"</code> 和{" "}
            <code>tabindex="0"</code>，其余标签使用 <code>tabindex="-1"</code>
            。禁用标签使用 <code>disabled</code> 或{" "}
            <code>aria-disabled="true"</code>。
          </dd>
        </dl>
      </dd>
      <dt>
        <code>
          &lt;div role="tabpanel" id="&#123; PANEL_ID &#125;"
          aria-labelledby="&#123; TAB_ID &#125;"&gt;
        </code>
      </dt>
      <dd>由标签控制的内容面板，非当前面板保持隐藏。</dd>
    </dl>
  </dd>
</dl>

### JavaScript API

| API                | 类型 | 描述                                                              |
| ------------------ | ---- | ----------------------------------------------------------------- |
| `tabs.select(tab)` | 方法 | 选择选项卡列表中的选项卡按钮。                                    |
| `tabs.refresh()`   | 方法 | 在现有选项卡列表/面板结构内的子项发生更改后重新扫描选项卡和面板。 |

React 的 `useTabs` 与 Vue 的同名 composable 通过 `call("select", tab, focus)` 和 `call("refresh")` 暴露相同契约。

水平选项卡列表会将溢出限制在自身范围内，并自动滚动以显示当前选项卡。方向键遵循视觉顺序，在 RTL 中左右方向会反转；`Home` 和 `End` 分别选择第一个和最后一个可用选项卡。
