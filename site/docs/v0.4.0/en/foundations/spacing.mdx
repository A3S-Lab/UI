# Spacing

A3S UI uses a 4px base. Tight relationships use 4, 6, 8, 12, and 16px; region relationships use 24, 32, 48, 64, and 96px. Headings receive more space above than below, and grouping must not depend on extra cards.

## Layout benchmarks

| Role                  |  Default | Notes                                     |
| --------------------- | -------: | ----------------------------------------- |
| Standard control      |   `36px` | Buttons, fields, and compound controls    |
| Compact control       |   `28px` | Ribbon and explicitly compact contexts    |
| Coarse-pointer target |   `44px` | Minimum touch and coarse-pointer hit area |
| Header                |   `56px` | Documentation and workspace header        |
| Documentation sidebar |  `248px` | Persistent documentation navigation       |
| Reading column        |  `752px` | Approximately 65–75 characters            |
| Documentation shell   | `1440px` | Maximum content width                     |

Page padding is 16px on phones, 24px on tablets, and 32–48px on desktop. Below 900px, secondary inspectors become overlays. Below 768px, persistent navigation becomes dismissible. Below 520px, headers retain identity and essential actions while bottom actions protect the safe area.

## Application parameters

| Variable                        |     Default | Component                     |
| ------------------------------- | ----------: | ----------------------------- |
| `--a3s-control-height`          |   `2.25rem` | Standard controls             |
| `--a3s-control-height-sm`       |   `1.75rem` | Compact controls              |
| `--a3s-touch-target`            |   `2.75rem` | Coarse-pointer hit target     |
| `--a3s-task-navigation-size`    |   `15.5rem` | App Shell and task navigation |
| `--a3s-task-reading-size`       |   `47.5rem` | Task transcript and composer  |
| `--a3s-task-inspector-size`     |     `21rem` | Task inspector                |
| `--a3s-activity-rail-size`      |  `2.875rem` | Collapsed navigation rail     |
| `--a3s-workspace-header-height` |    `3.5rem` | Workspace Header              |
| `--a3s-toolbar-height`          | `2.6875rem` | Standalone Toolbar row        |
| `--a3s-toolbar-control-height`  | `1.8125rem` | Toolbar commands              |
| `--a3s-ribbon-tabs-height`      |   `2.25rem` | Ribbon tabs                   |
| `--a3s-ribbon-panel-height`     |  `4.625rem` | Ribbon command panel          |
| `--a3s-status-height`           |   `1.75rem` | Status Bar                    |

Override public variables before internal grid selectors. Keep the 4px baseline and validate desktop, 320px width, 200% zoom, and coarse pointers whenever density changes.
