# Native Select

Native Select lets users choose one value from a short fixed list while preserving familiar operating-system interaction and accessibility.

<Preview>
<div class="field w-full">
  <label for="native-select-fruit-en">Fruit</label>
  <select id="native-select-fruit-en" class="native-select w-full" aria-describedby="native-select-fruit-help-en">
    <option value="">Select a fruit</option>
    <option value="apple">Apple</option>
    <option value="banana">Banana</option>
    <option value="blueberry">Blueberry</option>
    <option value="pineapple">Pineapple</option>
    <option value="long-label">Dragon fruit from the seasonal international produce collection</option>
  </select>
  <p id="native-select-fruit-help-en">Choose one fruit for the current order.</p>
</div>
</Preview>

## Usage

<Steps>
  <Step title="Include CSS">

Import Tailwind and one full A3S UI style bundle.

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

Or import only the base CSS, Native Select component CSS, and one style pack.

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/native-select.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

Using CDN or bundler imports? See the [Installation page](/installation).

  </Step>
  <Step title="Add your native select HTML">

Add the canonical `class="native-select"` to a native `<select>`. Use standard `<option>` and `<optgroup>` elements. The former `select` class remains a visual migration alias, but new markup and framework adapters use `native-select` so it cannot be confused with the custom Select root.

```html
<div class="field">
  <label for="native-select-fruit-html">Fruit</label>
  <select id="native-select-fruit-html" class="native-select" aria-describedby="native-select-fruit-help-html">
    <option value="">Select a fruit</option>
    <option value="apple">Apple</option>
    <option value="banana">Banana</option>
    <option value="blueberry">Blueberry</option>
    <option value="pineapple">Pineapple</option>
  </select>
  <p id="native-select-fruit-help-html">Choose one fruit for the current order.</p>
</div>
```

  </Step>
</Steps>

Use Native Select for native browser behavior, form integration, and mobile-optimized pickers. Use [Select](/components/select) for custom option content, multi-select behavior, or JavaScript APIs.

## React

```tsx
import { NativeSelect, useNativeSelect } from "@a3s-lab/ui/react";

export function Example() {
  const control = useNativeSelect();
  return (
    <div className="field">
      <label htmlFor="native-select-fruit-react">Fruit</label>
      <NativeSelect
        id="native-select-fruit-react"
        ref={control.ref}
        defaultValue=""
        aria-describedby="native-select-fruit-help-react"
      >
        <option value="">Select a fruit</option>
        <option value="apple">Apple</option>
        <option value="banana">Banana</option>
      </NativeSelect>
      <p id="native-select-fruit-help-react">Choose one fruit for the current order.</p>
    </div>
  );
}
```

`useNativeSelect` subscribes to manifest-declared DOM events and calls only public manifest methods. The adapter creates no second, framework-only state model.
