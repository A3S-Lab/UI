# Ribbon

A Ribbon combines tab navigation with grouped application commands. The pattern is extracted from A3S Office and generalized for editors, topology tools, and operational workbenches.

## Usage

Load the Tabs controller and combine `ribbon` with `tabs`.

```html
<div class="ribbon tabs" data-accent="blue">
  <div role="tablist" aria-label="Editor commands">...</div>
  <div role="tabpanel">
    <fieldset data-ribbon-group>
      <legend>Clipboard</legend>
      ...
    </fieldset>
  </div>
</div>
```

### Parameters

| Parameter                           | Values                              | Default     | Purpose                                |
| ----------------------------------- | ----------------------------------- | ----------- | -------------------------------------- |
| `data-accent`                       | `blue`, `green`, `orange`, `purple` | `blue`      | Legacy product accent; `purple` resolves to A3S blue      |
| `role="tablist"`                    | —                                   | Required    | Tab navigation container               |
| `aria-selected`                     | `true`, `false`                     | Required    | Active tab state                       |
| `aria-controls` / `aria-labelledby` | Element IDs                         | Required    | Associates tabs and panels             |
| `data-ribbon-group`                 | —                                   | Required    | Command group layout                   |
| `data-ribbon-controls`              | —                                   | Recommended | Aligns commands above the group legend |
| `--ribbon-tabs-height`              | CSS length                          | `2.25rem`   | Fixed tab-strip height                  |
| `--ribbon-panel-height`             | CSS length                          | `4.625rem`  | Fixed command-panel height              |
| `--ribbon-group-height`             | CSS length                          | `4.0625rem` | Fixed command-group height              |

## States and variants

Use blue for current A3S workspaces. Green and orange remain available for legacy document-specific integrations, while the retained `purple` compatibility value resolves to A3S blue. Disabled tabs and commands use native `disabled`. The default 36-pixel tab strip and 74-pixel command panel remain compact; narrow viewports keep tabs unshrunk and scroll them horizontally.

### JavaScript API

Ribbon behavior comes from the [Tabs](/components/tabs) controller. `window.a3sUI.refresh(ribbon)` rescans dynamically added tabs. No Ribbon-specific JavaScript is required.

## Accessibility

Use the complete Tabs keyboard contract. Group commands with `<fieldset>` and a visible or screen-reader-only `<legend>`. If a ribbon becomes too dense, allow horizontal scrolling rather than shrinking labels below a readable size.

## React

```tsx
import { Ribbon, useRibbon } from "@a3s-lab/ui/react";

export function Example() {
  const control = useRibbon();
  return (
    <Ribbon ref={control.ref} className="tabs" data-accent="blue">
      <div role="tablist" aria-label="Editor commands">
        <button type="button" role="tab" aria-selected="true">
          Home
        </button>
      </div>
      <div role="tabpanel">
        <fieldset data-ribbon-group="">
          <legend>Clipboard</legend>
          <button type="button">Paste</button>
          <button type="button">Copy</button>
        </fieldset>
      </div>
    </Ribbon>
  );
}
```

`useRibbon` subscribes to manifest-declared DOM events and calls only public manifest methods. The adapter creates no second, framework-only state model.
