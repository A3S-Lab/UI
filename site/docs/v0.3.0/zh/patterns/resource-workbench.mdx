# 资源工作台

Resource Workbench 是一套完整的 Office 衍生组合模式：App Shell 承载导航，Workspace Header 提供资源身份与操作，Resource Grid 展示可搜索模板，Split Pane 组织编辑器与检查器。

## 组成

```text
App Shell
├── Activity Bar
└── Main workspace
    ├── Workspace Header
    └── Search + Resource Grid
        └── Resource Card
```

当资源需要与检查器、智能体助手或调用链详情并排打开时，使用 [Split Pane](/components/split-pane)。只有资源确实拥有足够多的常驻命令时，才添加 [Ribbon](/components/ribbon)。

## 参数及状态

工作台本身不引入新的公共类。组合时使用各组件已经记录的参数，并在宿主应用中保存业务状态，例如搜索词、选中资源、保存状态与导航偏好。

## 响应行为

- 在压缩主内容之前，先折叠或隐藏持久导航。
- 让 Resource Grid 通过 `--resource-grid-min` 自动减少列数。
- 在窄屏上隐藏次要 Workspace Header 操作。
- 当两个 Split Pane 都无法正常使用时，将侧边检查器转换为 Drawer。

## 可访问性

提供页面标题、具名导航地标、带标签的搜索输入与清晰资源名称。导航完成后把焦点移到资源标题；不要仅因网格重排而移动焦点。
