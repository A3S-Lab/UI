## 用途

<Steps>
  <Step title="引入 CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者仅导入基础 CSS、单选组组件 CSS 和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/field.css";
@import "@a3s-lab/ui/components/radio.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

单选组使用 Radio 样式，并在复杂示例中组合 Field 样式。

使用 CDN 或打包工具导入？请参阅[安装页](/installation)。

  </Step>
  <Step title="添加单选组 HTML">

为单选按钮添加 `class="input"`。互斥选项共用同一个 `name` 属性，并使用语义化的 `<fieldset>` 或带有 `role="radiogroup"` 的元素包裹相关选项。

```html
<input type="radio" name="plan" class="input" />
```

  </Step>
</Steps>

      <input type="radio" id="invalid-email" name="notification-preference" value="email" class="input" aria-invalid="true" defaultChecked />
      <label for="invalid-email" class="font-normal">仅邮件</label>

```tsx
export function RadioGroupExample() {
  return (
    <div role="radiogroup" aria-label="运行模式">
      <input type="radio" name="plan" className="input" />
    </div>
  );
}
```

该发布版本尚未提供框架适配器；示例直接渲染同一语义 DOM，并由该版本的浏览器运行时增强交互。
