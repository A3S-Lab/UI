## 用途

<Steps>
  <Step title="Include CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者仅导入基本CSS和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

区域滚动使用A3S UI 滚动条组件类。

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="Add your scroll area HTML">

在已使用 `overflow-auto`、`overflow-y-auto` 或 `overflow-x-auto` 滚动的元素上使用 `scrollbar` 或 `scrollbar-sm`。

```html
<div class="scrollbar h-72 overflow-y-auto rounded-md border p-4">
  Your scrollable content here.
</div>
```

  </Step>
</Steps>

在已使用 `overflow-auto`、`overflow-y-auto` 或 `overflow-x-auto` 滚动的元素上使用 `scrollbar` 或 `scrollbar-sm`。

组件类增强了原生滚动的跨浏览器样式。它不封装内容、取代浏览器滚动行为或需要 JavaScript。
