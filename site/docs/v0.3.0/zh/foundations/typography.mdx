## 字体族

| 令牌 | 字体栈 | 用途 |
| --- | --- | --- |
| `--font-sans` | System UI、PingFang SC、Microsoft YaHei、Noto Sans CJK SC | 界面与文档文本 |
| `--font-mono` | SFMono-Regular、Consolas、Liberation Mono、Menlo | 代码、标识符、指标与快捷键 |

## 字号层级

| 角色 | 字号 / 行高 | 字重 | 说明 |
| --- | ---: | ---: | --- |
| 展示标题 | `36 / 40px` | `600` | 首页或空状态主张 |
| 页面标题 | `24 / 32px` | `600` | 每个视图一个 |
| 分区标题 | `16 / 24px` | `600–650` | 设置卡片与面板 |
| 控件 | `13 / 20px` | `500–600` | 紧凑应用工具栏 |
| 正文 | `14 / 22px` | `400` | 默认文档正文 |
| 说明文字 | `12 / 16px` | `400–500` | 元数据与状态 |

## 参数

在应用根节点覆盖 `--font-sans` 与 `--font-mono`。除非产品已经完成密度测量，否则应保留字号与行高关系。不要把状态、文件名或长标签全部转成大写。
