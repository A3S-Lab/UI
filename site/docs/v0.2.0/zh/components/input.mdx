## 用途

<Steps>
  <Step title="Include CSS">

导入 Tailwind 和一个完整的 A3S UI 样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

或者只导入基本CSS、输入组件CSS和一个样式包。

```css
@import "tailwindcss";
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/input.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

使用CDN或批量程序导入？请参见[安装页](/installation)。

  </Step>
  <Step title="Add your input HTML">

Add `class="input"` to supported `<input>` elements. Inputs inside a `class="field"` container also receive the same styling automatically for common text-like input types.

使用原生HTML属性来实现：`disabled`用于禁止输入，`required`用于必填字段行为，`aria-invalid="true"`用于无效状态样式。

```html
<input class="input" type="email" aria-label="电子邮箱" placeholder="Email" />
```

  </Step>
</Steps>

### RTL

输入通过原生浏览器方向处理支持从右到左的布局。将 `dir="rtl"` 添加到输入、字段或祖先。

<Preview class="w-full max-w-xs">
<div role="group" class="field" dir="rtl">
  <label for="input-rtl-api-key">مفتاح API</label>
  <input id="input-rtl-api-key" type="password" placeholder="sk-..." />
  <p>مفتاح API الخاص بك مشفر ومخزن بأمان.</p>
</div>
</Preview>

## React

```tsx
  return (
    <input
      className="input"
      type="email"
      aria-label="电子邮箱"
      placeholder="Email"
    />
  );
}
```

该发布版本尚未提供框架适配器；示例直接渲染同一语义 DOM，并由该版本的浏览器运行时增强交互。
