## Families

| Token | Stack | Use |
| --- | --- | --- |
| `--font-sans` | System UI, PingFang SC, Microsoft YaHei, Noto Sans CJK SC | Interface and documentation text |
| `--font-mono` | SFMono-Regular, Consolas, Liberation Mono, Menlo | Code, identifiers, metrics, shortcuts |

## Scale

| Role | Size / line height | Weight | Notes |
| --- | --- | --- | --- |
| Display | `36 / 40px` | `600` | Marketing or empty-state statement |
| Page title | `24 / 32px` | `600` | One per view |
| Section title | `16 / 24px` | `600–650` | Settings cards and panels |
| Control | `13 / 20px` | `500–600` | Dense application chrome |
| Body | `14 / 22px` | `400` | Default documentation copy |
| Caption | `12 / 16px` | `400–500` | Metadata and status |

## Parameters

Override `--font-sans` and `--font-mono` at the application root. Preserve the scale and line-height relationships unless the product has a measured density requirement. Avoid putting status, file names, or long labels in all caps.
