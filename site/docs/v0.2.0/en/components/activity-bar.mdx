# Activity Bar

An Activity Bar is the compact, persistent navigation surface used by A3S workspaces. It supports labeled and icon-only modes without changing the semantic navigation.

## Usage

```html
<aside class="activity-bar" aria-label="Product navigation">
  <header>...</header>
  <nav aria-label="Primary"><ul>...</ul></nav>
  <footer>...</footer>
</aside>
```

### HTML structure

| Element or parameter | Required | Purpose |
| --- | --- | --- |
| `<aside class="activity-bar">` | Yes | Component root |
| `<nav aria-label="…">` | Yes | Names the navigation landmark |
| `<ul>` and `<li>` | Yes | Navigation collection |
| `aria-current="page"` | Current item | Exposes and styles the active destination |
| `data-navigation-label` | Optional | Label hidden in compact mode |
| `data-labels="hidden"` | Optional | Forces icon-only presentation on the root |

## States and variants

Use `data-labels="hidden"` for a standalone icon rail. Inside an [App Shell](/components/app-shell), `data-navigation="collapsed"` hides labels automatically. Links support default, hover, focus-visible, and current states. Buttons additionally support `aria-pressed="true"` for in-place mode changes.

## Accessibility

Keep labels in the DOM when collapsed. Every icon-only link or button still needs an accessible name. Use `aria-current`, not color alone, for the current page.

## React

```tsx
export function ActivityBarExample() {
  return (
    <aside className="activity-bar" aria-label="Product navigation">
      <header>
        <a href="/" aria-label="Home">
          A3S
        </a>
      </header>
      <nav aria-label="Primary">
        <ul>
          <li>
            <a href="/projects" aria-current="page">
              Projects
            </a>
          </li>
        </ul>
      </nav>
      <footer>
        <button type="button" aria-label="Settings">
          Settings
        </button>
      </footer>
    </aside>
  );
}
```

This published version predates framework adapters. The example renders the same semantic DOM and lets that version's browser runtime enhance its interactions.
