# 多行文本框

多行文本框用于采集一个以换行为有效结构的纯文本值。它保留浏览器原生的多行编辑能力，同时让大段粘贴、校验和可用性状态始终处于可控范围内。

## 用法

引入 Tailwind 和一套完整的 A3S UI 样式：

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

按组件加载时，依次引入基础样式、多行文本框结构、字段结构和一套视觉样式：

```css
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/textarea.css";
@import "@a3s-lab/ui/components/field.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

在原生 `<textarea>` 上添加 `class="textarea"`。生产表单中应与字段组件组合，使持久标签、普通说明、长度约束和当前错误保持在同一关系中。

```html
<div class="field">
  <label for="release-note">发布说明</label>
  <textarea
    id="release-note"
    class="textarea"
    name="releaseNote"
    rows="5"
    maxlength="320"
    aria-describedby="release-note-help"
  ></textarea>
  <p id="release-note-help" data-field-description>
    写明验证证据和失败后的回滚路径。
  </p>
</div>
```

多行文本框只处理原生纯文本。需要文档结构、格式或语法行为时使用编辑器；还需要提及、附件、工具和提交状态时使用[任务输入器](/components/agent-composer)。

### 参数

| 参数                                 | 用途                                                |
| ------------------------------------ | --------------------------------------------------- |
| `id`                                 | 将原生控件连接到一个持久可见的标签                  |
| `name`                               | 提供表单字段键；禁用的多行文本框不会进入 `FormData` |
| `rows`                               | 设置初始编辑视口，但不会启用自动增高                |
| `minlength`、`maxlength`、`required` | 仅在符合真实纯文本契约时表达原生约束                |
| `wrap`、`spellcheck`、`autocomplete` | 保留或细化原生编辑行为，不重新实现浏览器能力        |
| `aria-describedby`                   | 按需关联持久说明和当前错误                          |
| `aria-invalid="true"`                | 表达一次失败的校验，并保留用户已经输入的文本        |
| `disabled`                           | 移除聚焦、编辑、校验和表单提交，同时应提供可见原因  |
| `readonly`                           | 阻止修改，但保留聚焦、选择、复制、滚动和表单提交    |

## 状态与变体

空值和就绪是普通值状态。只有完成校验后才进入无效状态。禁用和只读代表不同的原生可用性契约，不能当作可以互换的视觉变体。

### 有界原生编辑

默认多行文本框是一个稳定的编辑视口，内容超出后在内部滚动，并保留原生垂直调整大小能力。它不会根据内容无限增高。产品若明确需要自动增高，必须限制最大高度、保留内部滚动，并证明粘贴、撤销、输入法组合和响应式切换不会推动无关控件。

`rows` 用于选择合适的初始视口。即使粘贴大量内容，文本也应完整保留，而页面高度不会无限增加。

### 表单校验与恢复

必填的多行文本框在第一次校验前保持中性。校验失败后应保留每一行输入，指出缺少的具体内容，将焦点移回多行文本框，并把错误加入说明关系。内容有效或表单重置后，应同时清除过期错误及其语义。

### 禁用与只读

禁用状态会从聚焦、编辑、约束校验和 `FormData` 中移除该值。只读状态仍允许聚焦、选择、复制、滚动和提交。两者都应保持完整文字透明度，并提供可见原因。

## 无障碍

- 保留一个持久可见的标签。占位文本只能演示内容，不能成为唯一无障碍名称。
- 把稳定的长度限制写入持久说明，并通过 `aria-describedby` 关联。可见字数使用独立的本地化标签，不加入说明关系，也不在每次按键时播报。完成校验后再加入当前错误 ID，恢复后及时移除。
- 保留浏览器原生的换行编辑、选择、撤销、粘贴、拼写检查、听写、拖动选择和输入法行为。
- 保持编辑视口有界且可垂直调整大小，避免长内容在光标附近编辑时推动整个页面。
- 只使用一层连续的内嵌焦点边界。强制颜色模式下改用系统 `Highlight` 轮廓。
- 在粗指针设备上，编辑文字至少为 16px，避免移动浏览器聚焦缩放。
- 发布前使用真实移动键盘、物理中文输入法、200% 缩放、触摸选择、Windows 强制颜色和读屏软件组合进行测试。
