# 输入组合

输入组合把一个主要值，以及理解或操作该值所必需的上下文放进同一个连续边界。它不替代字段、校验、建议列表、富文本编辑或应用状态。

## 用法

引入 Tailwind 和一套完整的 A3S UI 样式：

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

按组件加载时，依次引入基础样式、输入组合结构、字段结构、一套视觉样式和小型行为控制器：

```css
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/input-group.css";
@import "@a3s-lab/ui/components/field.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

```js
import "@a3s-lab/ui/runtime";
import "@a3s-lab/ui/input-group";
```

根节点只放一个直接主要控件。持久标签、普通说明和当前错误属于外围字段。根节点默认没有组件角色，因为原生控件已经负责名称、值、键盘行为和表单语义。

```html
<div class="field">
  <label for="repository-filter">仓库筛选</label>
  <div class="input-group">
    <input id="repository-filter" name="repositoryFilter" aria-describedby="repository-filter-help" />
    <span data-align="inline-start" aria-hidden="true"><svg viewBox="0 0 20 20" fill="none">...</svg></span>
    <span data-align="inline-end">8 个匹配项</span>
  </div>
  <p id="repository-filter-help" data-field-description>按仓库名称或路径搜索。</p>
</div>
```

不需要共享边界时使用独立输入框或多行文本框。需要可选择建议时使用组合框，需要结构化内容时使用编辑器，需要提及、附件、工具和提交状态时使用任务输入器。

### 参数

| 参数 | 用途 |
| --- | --- |
| `.input-group` | 提供共享视觉边界和指针聚焦转发，但它本身不是表单控件 |
| 直接 `input`、`textarea`、`select` 或 `[data-control]` | 提供唯一主要值、原生语义、焦点和提交行为 |
| `data-align="inline-start|inline-end"` | 按逻辑方向放置简短前后缀、状态、快捷键或有限操作 |
| `data-align="block-start|block-end"` | 将较长附加内容移到块级行，同时保持 DOM 与键盘顺序 |
| `data-orientation="vertical"` | 保留已存在的纵向组合兼容性；块级对齐本身也会产生该布局 |
| `aria-busy="true"` | 表示宿主工作正在进行，但不禁用可编辑值 |
| `data-disabled`、`data-readonly` | 可选的外壳样式镜像；语义仍以原生 `disabled` 或 `readonly` 为准 |
| `data-input-group-status` | 标识有限的结果或进度文本；只有变化需要播报时才添加 `role="status"` |

旧的 `start` 和 `end` 仍分别作为 `inline-start` 与 `inline-end` 的别名。新标记应使用明确的逻辑值。

## 状态与变体

空值和就绪是普通值状态。完成校验尝试后才进入无效状态。加载会保留当前值和编辑能力。禁用与只读具有不同的原生行为，不能被简化成同一种半透明外观。

### 校验与恢复

输入组合只反映校验结果，不制定校验策略。失败后应保留尝试值、聚焦无效控件、在外壳之外写明具体修正方法，并把错误 ID 加入 `aria-describedby`。有效编辑或重置后清除过期错误。输入法处于组合输入阶段时不要校验。

## 无障碍

- 保留一个持久可见标签，并通过 `aria-describedby` 关联普通说明。占位符不能成为唯一名称。
- 除非组合确实存在原生控件和字段无法表达的分组关系，否则根节点不要添加组件角色。
- 保留原生输入、选择、粘贴、撤销、搜索清除、密码管理器、自动填充和输入法行为。
- 仅图标操作需要准确的无障碍名称。粗指针环境下，可编辑文字至少为 16px，操作目标至少为 44×44 CSS 像素。
- 无效状态需要原生约束、`aria-invalid="true"`、具体错误和恢复路径，不能只依赖颜色。
- 加载状态保持值与焦点稳定，只使用一个有限状态消息，过期响应不能覆盖更新后的输入。
- 强制颜色模式使用系统 `Highlight` 轮廓替代内嵌焦点样式。发布前仍需测试真实移动键盘、物理中文输入法、200% 缩放、触控选择、Windows 强制颜色和读屏器/浏览器组合。
