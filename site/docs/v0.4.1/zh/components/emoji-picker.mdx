### 独立控制器

```js
import "@a3s-lab/ui/runtime";
import "@a3s-lab/ui/emoji-picker";

const component = document.querySelector(".emoji-picker");
component.getState();
```

控制器是幂等的；完整包可改为一次导入 `@a3s-lab/ui/all`。宿主通过可取消的 `before-*` 事件执行权限与业务校验。

## React

```tsx
import { EmojiPicker, useEmojiPicker } from "@a3s-lab/ui/react";

export function Example() {
  const control = useEmojiPicker();
  return (
    <EmojiPicker ref={control.ref} aria-label="选择回应表情">
      <input className="input" type="search" placeholder="搜索回应" aria-label="搜索回应" />
      <div data-emoji-grid role="listbox">
        <button type="button" data-emoji-value="👍" aria-label="赞同">👍</button>
        <button type="button" data-emoji-value="🎉" aria-label="庆祝">🎉</button>
        <button type="button" data-emoji-value="❤️" aria-label="喜爱">❤️</button>
        <p hidden data-emoji-empty>没有匹配的回应。</p>
      </div>
    </EmojiPicker>
  );
}
```

`useEmojiPicker` 通过 ref、就绪状态、事件订阅与类型化方法暴露同一 DOM 契约，不引入框架私有状态。

## Vue

```vue
<script setup>
import { EmojiPicker, useEmojiPicker } from "@a3s-lab/ui/vue";

const control = useEmojiPicker();
const componentRef = control.componentRef;
</script>

<template>
  <EmojiPicker ref="componentRef" aria-label="选择回应表情">

      <button type="button" data-emoji-value="👍" aria-label="赞同">👍</button>
      <button type="button" data-emoji-value="🎉" aria-label="庆祝">🎉</button>

    </div>

```

`useEmojiPicker` 暴露与 React hook 相同的事件与方法集，模板保留相同的根类名与原生属性。

## 契约

| 表面 | 值 |
| --- | --- |
| 根选择器 | `.emoji-picker` |
| 原生根 | `<section>` |
| 状态 | `ready`、`empty`、`disabled` |
| 事件 | `a3s:emoji-before-select`、`a3s:emoji-query-change`、`a3s:emoji-select` |
| 方法 | `getState`、`refresh`、`select`、`setQuery` |

## 产品边界

它不拥有最近使用、肤色偏好、远程表情包或消息发送。大型目录需要宿主提供分组、虚拟化与本地化检索数据。

组件只发布可复用的交互边界。数据获取、持久化、权限、可信内容与业务实体仍由宿主拥有。

## 无障碍

为根节点提供可访问名称，选项保持为带明确标签的按钮，并保留键盘网格导航。空结果必须通过空消息节点保持可感知。
