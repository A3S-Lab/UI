## 用法

```html
<label for="target-date">目标日期</label>
<input
  id="target-date"
  class="input date-picker"
  type="date"
  value="2026-08-14"
  min="2024-01-01"
  max="2028-12-31"
  required
/>
```

请使用可见标签、本地日历边界的 `min` / `max`，以及字段级恢复文案。不要把值重新解释为 UTC。

## React

```tsx
import { DatePicker, useDatePicker } from "@a3s-lab/ui/react";

export function Example() {
  const control = useDatePicker();
  return (
    <DatePicker
      ref={control.ref}
      type="date"
      defaultValue="2026-08-14"
      min="2024-01-01"
      max="2028-12-31"
      required
      aria-label="目标日期"
    />
  );
}
```

`useDatePicker` 返回同一 DOM 契约的 `ref`、就绪状态、事件订阅和受类型约束的方法调用；它不会创建框架专属状态。

## Vue

```vue
<script setup>
import { DatePicker, useDatePicker } from "@a3s-lab/ui/vue";

const control = useDatePicker();
const componentRef = control.componentRef;
</script>

<template>
  <DatePicker
    ref="componentRef"
    type="date"
    value="2026-08-14"
    min="2024-01-01"
    max="2028-12-31"
    required
    aria-label="目标日期"
  />
</template>
```

`useDatePicker` 与 React hook 暴露相同的事件和方法集合，模板仍输出同一个根类与原生属性。

## 契约

| 接口 | 值 |
| --- | --- |
| 根选择器 | `input.date-picker` |
| 原生根元素 | `<input type="date">` |
| 状态 | `ready`, `disabled`, `invalid`, `read-only` |
| 事件 | `change`, `input` |
| 方法 | — |

## 产品边界

它不拥有时区、日期范围、复发规则或自然语言解析。多个日期之间的关系由表单组合负责校验与解释。

组件只发布可复用的交互边界。数据获取、持久化、权限、可信内容与业务实体继续由宿主产品拥有。

## 无障碍

始终提供可见标签，并在字段旁解释格式、边界与错误。占位符不能代替标签。禁用与只读使用原生属性，而不是单独依赖 `aria-disabled` / `aria-readonly`。
