# 输入框

输入框用于采集一个原生单行值。它保留浏览器的编辑、选择、校验、自动填充、密码管理器、输入法和表单行为，由 A3S UI 提供一致的视觉契约。

## 用法

引入 Tailwind 和一套完整的 A3S UI 样式：

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

按组件加载时，依次引入基础样式、输入框结构、字段结构和一套视觉样式：

```css
@import "@a3s-lab/ui/base.css";
@import "@a3s-lab/ui/components/input.css";
@import "@a3s-lab/ui/components/field.css";
@import "@a3s-lab/ui/styles/a3s.css";
```

在受支持的原生 `<input>` 上添加 `class="input"`。生产表单中应与字段组件组合，使可见标签和说明在编辑前后始终存在。

```html
<div class="field">
  <label for="notification-email">通知邮箱</label>
  <input
    id="notification-email"
    class="input"
    type="email"
    name="notificationEmail"
    autocomplete="email"
    aria-describedby="notification-email-help"
  />
  <p id="notification-email-help">用于接收发布通知和恢复账户。</p>
</div>
```

输入框只处理一个原生单行值。前后缀、图标、单位或内嵌动作使用[输入框组](/components/input-group)；文件队列和进度使用[文件上传](/components/form-system/file-upload)；富文本指令、提及、附件和排队提交使用[任务输入器](/components/agent-composer)。

### 参数

| 参数                                                                  | 用途                                           |
| --------------------------------------------------------------------- | ---------------------------------------------- |
| `id`                                                                  | 将原生输入框连接到一个持久可见的标签           |
| `name`                                                                | 提交字段键；禁用输入框不会进入 `FormData`      |
| `type`                                                                | 选择原生编辑、校验、键盘、自动填充和浏览器控件 |
| `autocomplete`                                                        | 让浏览器和密码管理器识别值的真实用途           |
| `inputmode`                                                           | 当 `type` 无法完整表达时进一步指定虚拟键盘     |
| `enterkeyhint`                                                        | 标注虚拟键盘动作，但不改变 Enter 的原生行为    |
| `aria-describedby`                                                    | 关联普通说明，并在校验后关联当前错误           |
| `required`、`min`、`max`、`step`、`minlength`、`maxlength`、`pattern` | 仅在符合真实数据契约时表达原生约束             |
| `aria-invalid="true"`                                                 | 在校验已经执行后暴露失败状态                   |
| `disabled`                                                            | 阻止聚焦、编辑、校验和表单提交，并应提供原因   |
| `readonly`                                                            | 阻止编辑，但保留聚焦、选择、复制和表单提交     |

## 状态与变体

空值和就绪是普通值状态。只有执行校验之后才进入无效状态。禁用与只读是不同的原生可用性契约，不能只当成两种相似样式。

### 类型语义

根据用户真正需要的数据、键盘、校验和自动填充行为选择类型，并保留浏览器自带控件，不用装饰性图标重新实现。

### 表单校验与恢复

首次校验前保持必填字段中性。失败时保留用户值、说明具体问题、聚焦输入框，并把错误加入描述关系。值恢复有效或表单重置后，立即清除过期错误语义。

### 禁用与只读

禁用会把值移出聚焦、编辑、约束校验和表单提交。只读仍允许聚焦、选择、复制和提交。两者都需要可见原因。

## 无障碍

- 始终提供一个持久可见的标签。占位文本可以说明格式，但不能是唯一名称。
- 用 `aria-describedby` 关联普通说明。仅在校验后追加当前错误 ID，恢复后立即移除。
- 保留原生键盘编辑、选择、撤销、粘贴、自动填充、密码管理器以及搜索和日期控件。
- 输入法组合期间不要转换文本、执行业务校验或提交，等待 `compositionend`。
- 在 RTL 布局中仍以从左到右的方向编辑邮箱、电话号码和 URL，避免标点与前缀被重排；标签和辅助说明继续遵循页面方向。
- 使用一条连续的聚焦边界。强制色彩模式下改用系统 `Highlight` 轮廓。
- 粗指针环境下，文本输入框至少 44px 高、字号至少 16px，避免移动端聚焦缩放。
- 发布前在 200% 浏览器缩放、超长值、RTL 文本、中日韩输入法、真实移动键盘、自动填充、密码管理器和辅助技术中测试。
