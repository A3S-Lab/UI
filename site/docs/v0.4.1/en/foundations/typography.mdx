# Typography

A3S UI uses Geist with HarmonyOS Sans SC, PingFang SC, and system fallbacks. Geist Mono is reserved for code, commands, paths, shortcuts, identifiers, and measurements.

## Families

| Token         | Stack                                                    | Use                                                |
| ------------- | -------------------------------------------------------- | -------------------------------------------------- |
| `--font-sans` | Geist, HarmonyOS Sans SC, PingFang SC, system sans serif | Interface and documentation text                   |
| `--font-mono` | Geist Mono, SFMono-Regular, Consolas, system monospace   | Code, commands, paths, shortcuts, and measurements |

## Scale

| Role          | Size / line height                | Weight | Use                                     |
| ------------- | --------------------------------- | -----: | --------------------------------------- |
| Display       | `clamp(32px, 4vw, 40px)` / `1.08` |  `680` | Documentation and empty-state landmarks |
| Page title    | `24px` / `1.2`                    |  `660` | Page identity                           |
| Section title | `20px` / `1.3`                    |  `650` | Major document and application regions  |
| Subsection    | `16px` / `1.4`                    |  `620` | Form groups and inspector regions       |
| Body          | `15px` / `1.7`                    |  `400` | Documentation and long task output      |
| UI            | `14px` / `1.4`                    |  `520` | Controls, navigation, tables, and menus |
| Annotation    | `13px` / `1.45`                   |  `450` | Metadata and descriptions               |
| Micro         | `12px` / `1.4`                    |  `560` | Rare dense labels and measurements      |

Keep display tracking between `-0.035em` and `-0.02em`; interface labels use normal tracking. Headings receive more space above than below, and body measure stays between 65 and 75 characters. Chinese and English use equivalent roles without forced uppercase.

## Parameters

Override `--font-sans` and `--font-mono` at the application root. Do not independently shrink type or line height without measured density evidence; doing so harms bilingual readability and 200% zoom behavior together.
