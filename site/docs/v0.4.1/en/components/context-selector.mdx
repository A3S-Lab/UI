# Context Selector

Context Selector provides one compact contract for model, permission, and workspace choices. Native Select is preferred when options fit ordinary selection behavior.

## Usage

```html
<label class="context-selector" data-kind="workspace">
  <span data-context-label>Workspace</span>
  <select aria-label="Workspace"><option>A3S UI</option></select>
  <span data-context-description>Files and task history stay scoped here.</span>
</label>
```

### Parameters

| API | Values | Purpose |
| --- | --- | --- |
| `data-kind` | `model`, `permission`, `workspace` | Choice semantics |
| Native `<select>` | Preferred | Ordinary finite choice |
| `button[aria-haspopup]` | Optional | Rich searchable anchored menu |
| `data-context-description` | Recommended | Consequence of the choice |

## States and variants

Unavailable choices remain visible with their reason when that helps users recover. Do not imply that a visual selection grants permission.

## Accessibility

Use a native label and control name. Anchored menus restore focus to their trigger and constrain themselves to the viewport.

## React

```tsx
import { ContextSelector, useContextSelector } from "@a3s-lab/ui/react";

export function Example() {
  const control = useContextSelector();
  return (
    <ContextSelector ref={control.ref} data-kind="workspace">
      <span data-context-label="">Workspace</span>
      <select aria-label="Workspace">
        <option>A3S UI</option>
      </select>
      <span data-context-description="">
        Files and task history stay scoped here.
      </span>
    </ContextSelector>
  );
}
```

`useContextSelector` subscribes to manifest-declared DOM events and calls only public manifest methods. The adapter creates no second, framework-only state model.
