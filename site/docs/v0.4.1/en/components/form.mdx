## Usage

Import Tailwind and one complete A3S UI style bundle:

```css
@import "tailwindcss";
@import "@a3s-lab/ui/a3s.css";
```

Use `form.form` for one recoverable task. Field owns each control's label and local error; Form owns grouping, summary validation, submission state, and footer actions.

```html
<form class="form" novalidate>
  <div data-form-summary role="alert" hidden></div>
  <div class="field">
    <label for="workspace-name">Workspace name</label>
    <input id="workspace-name" class="input" name="workspaceName" required />
    <p data-form-error role="alert" hidden>Enter a workspace name.</p>
  </div>
  <footer>
    <button class="btn" type="submit">Save workspace</button>
    <button class="btn" type="reset" data-variant="outline">Reset</button>
  </footer>
</form>
```

### Parameters

| Contract | Purpose |
| --- | --- |
| `form.form` | Canonical native root for one submission task |
| `[data-form-summary]` | Optional summary of multiple failures; keep it empty until validation runs |
| `[data-form-error]` / `[role=alert]` | Local or summary recovery copy; reveal only after failure |
| `footer` with `type="submit"` / `type="reset"` | Primary and cancel/reset actions for the same task |
| `data-state="submitting"` / `aria-busy="true"` | Prevents duplicate edits and actions while work is in progress |
| `data-state="invalid"` / `aria-invalid="true"` | Form-level failed validation after submit |
| `data-state="success"` | Durable local success feedback without clearing entered values |
| `data-state="error"` | Host-reported failure that preserves values and recovery focus |
| `data-readonly` / `data-state="read-only"` | Read-only presentation paired with native `readonly` / disabled submit |

## React

```tsx
import { Form, useForm } from "@a3s-lab/ui/react";

export function Example() {
  const control = useForm();
  return (
    <Form ref={control.ref}>
      <div className="field">
        <label htmlFor="workspace-name">Workspace name</label>
        <input
          id="workspace-name"
          className="input"
          name="workspaceName"
          defaultValue="Research"
          required
        />
      </div>
      <footer>
        <button type="submit" className="btn">
          Save workspace
        </button>
      </footer>
    </Form>
  );
}
```

`useForm` exposes the same DOM contract through a ref, readiness state, event subscriptions, and typed method calls. It introduces no framework-only state.

## Vue

```vue
<script setup>
import { Form, useForm } from "@a3s-lab/ui/vue";

const control = useForm();
const componentRef = control.componentRef;
```

`useForm` exposes the same event and method set as the React hook while the template retains the same root class and native attributes.

## Contract

| Surface | Value |
| --- | --- |
| Root selector | `form.form` |
| Native root | `<form>` |
| States | `ready`, `submitting`, `success`, `invalid`, `error`, `read-only` |
| Events | `reset`, `submit` |
| Methods | — |

## Product boundary

Form owns interaction structure, not requests, permission, or business validation. Do not group unrelated settings or replace specific errors with a permanently disabled submit button.

The component publishes a reusable interaction boundary only. Data fetching, persistence, permission, trusted content, and business entities remain host-owned.

## Accessibility

Errors sit beside their field and can be reached from the summary. Submission preserves input, failure preserves focus context, and every field has a persistent label. While `aria-busy="true"`, pointer interaction is blocked so duplicate submits cannot race the first request.
