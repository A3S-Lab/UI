# 间距

间距系统以 4px 为基础单位。紧凑应用工具栏使用 4–12px 间距，内容与页面区域使用 16–32px 间距。

## 间距刻度

| 步骤 | 值 | 典型用途 |
| --- | ---: | --- |
| `1` | 4px | 图标与标签之间的微间距 |
| `2` | 8px | 相邻控件 |
| `3` | 12px | 工具栏与字段间距 |
| `4` | 16px | 卡片内边距与网格间距 |
| `6` | 24px | 分区间距 |
| `8` | 32px | 页面区域 |

## 布局参数

应用组件通过 CSS 变量公开连续值：

| 变量 | 默认值 | 组件 |
| --- | ---: | --- |
| `--app-shell-navigation-size` | `15rem` | App Shell |
| `--workspace-header-height` | `3.5rem` | Workspace Header |
| `--settings-navigation-size` | `14rem` | Settings Layout |
| `--resource-grid-min` | `12rem` | Resource Grid |
| `--resource-grid-gap` | `1rem` | Resource Grid |
| `--split-pane-min-height` | `18rem` | Split Pane |

优先调整这些参数，不要覆盖组件内部网格选择器。
