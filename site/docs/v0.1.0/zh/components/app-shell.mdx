## 用途

```html
<div class="app-shell" data-navigation="expanded">
  <aside data-app-navigation>...</aside>
  <main data-app-main>
    <header class="workspace-header">...</header>
    <div data-app-content>...</div>
  </main>
</div>
```

### 参数

| 参数 | 可选值 | 默认 | 目的 |
| --- | --- | --- | --- |
| `data-navigation` | `expanded`、`collapsed`、`hidden` | `expanded` | 桌面导航状态 |
| `data-mobile-navigation` | `open` 或省略 | 省略 | 移动端抽屉是否可见 |
| `--app-shell-navigation-size` | CSS 长度 | `15rem` | 展开后的导航宽度 |
| `--app-shell-navigation-collapsed-size` | CSS 长度 | `4rem` | 图标栏宽度 |
| `--app-shell-min-height` | CSS 长度 | `36rem` | 外壳最小高度 |

## 状态和变体

App Shell 支持展开、折叠、隐藏与移动端打开状态。状态管理由宿主应用负责，以便保存用户偏好并与路由协调；预览只使用文档专用的轻量控制器。

## 可访问性

使用地标元素（`aside`、`nav`、`main`、`header`）并命名每个导航区域。导航开关需要 `aria-expanded` 与随状态变化的可访问名称。移动导航为模态时，应组合 [Drawer](/components/drawer) 来管理焦点。
