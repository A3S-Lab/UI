# 快速开始

## 安装依赖

```bash
npm ci
```

## 启动在线设计器

```bash
npm run form:playground:dev
```

启动后首先显示中文“我的表单”工作台。示例表单和新建表单都保存在当前浏览器，不要求登录，也不会上传本地内容。

## 在 React 中渲染

```tsx
import { assertCompiled } from '@a3s-lab/ui/form/core';
import { FormRenderer } from '@a3s-lab/ui/form/react';
import '@a3s-lab/ui/form/a3s-ui.css';

export function ApplicationForm({ document, value, onChange }) {
  const plan = assertCompiled(document);
  return <FormRenderer plan={plan} value={value} onChange={onChange} />;
}
```

该入口包含 `@a3s-lab/ui@0.2.1` 与 Form 布局层。宿主已经加载 A3S UI，或需要隔离文档级样式时，改用 `@a3s-lab/ui/form/styles.css`。

## 质量检查

```bash
npm run form:check
```

项目对语句、分支、函数和行覆盖率都设置了 `95%` 门槛。
