# Playground

Playground 与其他 A3S Office 产品使用同一套 A3S UI 工作台与编辑器协议，默认界面为中文。

## 浏览器本地工作台

首页列出当前浏览器保存的表单，并支持：

- 按标题或说明搜索；
- 查看字段数、revision 和最后更新时间；
- 创建空白表单，或从引导模板开始；
- 只在确定性编译通过后导入 JSON 文档；
- 在表单列表与 Designer 之间切换；
- 刷新页面后恢复工作台。

工作台使用版本化的 `a3s-form-workspace:v1` key 写入 `localStorage`。旧版单表单数据会在首次读取时迁移。存储损坏或不可用时，当前会话仍可继续使用。

## Designer 工作区

桌面端同时显示组件目录或结构树、画布，以及属性、校验或 Agent 面板。窄屏会切换成独立的“组件”“画布”“设置”面板，让当前任务占满可用宽度。

预览模式会移除两侧编辑面板，在画布中渲染真实受控运行时。工具栏显示保存中、已保存和失败状态；`Cmd/Ctrl+S` 与可见的保存按钮走同一条路径。

## Agent FormPatch

Agent 面板接收与 revision 绑定的 `FormPatch` JSON，不接收自由格式输出。面板会显示当前 revision 和协议，提供空 patch 模板，预检 JSON 语法，并在修改文档之前报告 revision 冲突。

## 运行时校验

提交操作会校验表单、显示可点击的错误摘要，并聚焦第一个无效字段。值修正后错误会同步更新。草稿操作直接发送当前受控值，不受必填项阻止；异步操作会显示进度、阻止重复触发并报告失败。
