# 架构设计

```text
┌──────────────────────────────────────────────────────────────────┐
│                       A3S Cloud / Host                           │
│ 权限 · 数据源 · 动作 · 发布 · 云端持久化 · Agent / Workflow       │
└──────────────────────────────┬───────────────────────────────────┘
                               │ 稳定嵌入 API
┌──────────────────────────────▼───────────────────────────────────┐
│                           A3S Form                               │
│  ┌──────────────┐  ┌────────────────┐  ┌─────────────────────┐  │
│  │ 多表单工作台  │  │ 可嵌入表单设计器 │  │ React/Vue/Web Comp. │  │
│  └──────┬───────┘  └───────┬────────┘  └──────────┬──────────┘  │
│         └───────────────────┼──────────────────────┘             │
│                    ┌────────▼─────────┐                          │
│                    │ 自定义节点注册表  │                          │
│                    └────────┬─────────┘                          │
│                    ┌────────▼─────────┐                          │
│                    │ Core 编译/状态机  │                          │
│                    └────────┬─────────┘                          │
│                    ┌────────▼─────────┐                          │
│                    │ Rust WASM 热路径  │                          │
│                    └──────────────────┘                          │
└──────────────────────────────────────────────────────────────────┘
```

核心层不依赖 UI 框架，表单文档是唯一事实来源。设计器和适配器通过同一编译计划工作，自定义节点注册表为业务组件提供显式扩展边界。
