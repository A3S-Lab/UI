# 文档版本

已发布接口与开发中能力按版本分开维护。页面右上角的版本选择器切换整套文档，语言选择器在中文与英文内容之间切换。

<VersionTable />

稳定版用于已发布集成、生产兼容性和升级前对照；开发版用于试用与评审尚未发布的能力。开发版内容只有通过代码、测试、文档、Playground 和兼容性检查后，才会进入新的稳定版本。

## 默认语言

所有版本默认使用中文。导航、搜索、页面语言标记和组件示例共享同一语言配置。

## 链接规则

- 默认稳定版使用根路径，例如 `/guide/`。
- 非默认版本保留版本前缀，例如 `/next/guide/fields`。
- 生产集成使用稳定版链接；评审未发布能力时保留明确的版本前缀。
