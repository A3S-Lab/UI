# v0.1.0 Data Grids

The `layout: "data-grid"` contract and `dataGrid` interaction policy are outside the stable v0.1.0 contract. The v0.1.0 documentation, compiler capabilities, and runtime components remain unchanged.

Data grids are available in the `next` development version, including inline editing, dialog drafts, multi-row selection, confirmed deletion, responsive row cards, and row-level error navigation.
