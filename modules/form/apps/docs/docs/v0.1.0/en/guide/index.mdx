# Quick Start

## Install dependencies

```bash
npm ci
```

## Start the web designer

```bash
npm run form:playground:dev
```

The Chinese “My Forms” workspace appears first. Sample forms and newly created forms stay in the current browser. No sign-in is required, and local content is not uploaded.

## Render in React

```tsx
import { assertCompiled } from '@a3s-lab/ui/form/core';
import { FormRenderer } from '@a3s-lab/ui/form/react';
import '@a3s-lab/ui/form/a3s-ui.css';

export function ApplicationForm({ document, value, onChange }) {
  const plan = assertCompiled(document);
  return <FormRenderer plan={plan} value={value} onChange={onChange} />;
}
```

This stylesheet entry includes `@a3s-lab/ui@0.2.1` and the Form layout layer. Use `@a3s-lab/ui/form/styles.css` when the host already loads A3S UI or requires document-level style isolation.

## Quality checks

```bash
npm run form:check
```

The project enforces a `95%` coverage threshold for statements, branches, functions, and lines.
