# Playground

The Playground uses the same A3S UI workspace and editor contracts as other A3S Office products. Its default interface is Chinese.

## Browser-local workspace

The home page lists forms saved in the current browser and supports:

- searching by title or description;
- viewing the field count, revision, and last update time;
- creating a blank form or starting from the guided template;
- importing a JSON document only after deterministic compilation succeeds;
- moving between the form list and Designer;
- restoring the workspace after a page refresh.

The workspace writes to `localStorage` with the versioned `a3s-form-workspace:v1` key. Legacy single-form data migrates on first read. The current session remains usable when storage is corrupt or unavailable.

## Designer workspace

Desktop layouts show the component catalog or structure tree, canvas, and properties, validation, or Agent panel at the same time. Narrow screens switch among separate Components, Canvas, and Settings panels so the active task uses the available width.

Preview mode removes both editing sidebars and renders the real controlled runtime in the canvas. The toolbar shows saving, saved, and failed states. `Cmd/Ctrl+S` and the visible Save button use the same path.

## Agent FormPatch

The Agent panel accepts revision-bound `FormPatch` JSON rather than free-form output. It shows the current revision and protocol, supplies an empty patch template, checks JSON syntax, and reports revision conflicts before changing the document.

## Runtime validation

A submit action validates the form, displays a clickable error summary, and focuses the first invalid field. Errors update as values are corrected. Draft actions send the current controlled value without required-field blocking. Asynchronous actions show progress, prevent duplicate activation, and report failures.
