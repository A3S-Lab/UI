# WASM Acceleration

A Rust `no_std` WebAssembly module runs the A3S Form digest hot path. The module performs no heap allocation, uses a fixed input buffer, and exports a minimal ABI:

- `input_ptr`: input-buffer address;
- `input_capacity`: maximum UTF-8 byte length;
- `hash`: computes SHA-256 and returns the digest address;
- `engine_version`: engine semantic version.

The runtime instantiates the embedded module synchronously. It automatically uses a byte-identical JavaScript implementation when the browser lacks WebAssembly support, the module is invalid, or the input exceeds capacity.

```ts
import { wasmAccelerationStatus } from '@a3s-lab/ui/form/core';

console.log(wasmAccelerationStatus());
// { available: true, engine: 'rust-sha256', version: '1.0.0', capacity: 4194304 }
```

Rebuild and run the local benchmark:

```bash
npm run form:wasm:build
npm run build
npm run form:wasm:benchmark
```
