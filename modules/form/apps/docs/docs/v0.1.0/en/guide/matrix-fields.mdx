# v0.1.0 Matrix Fields

`matrix-single` and `matrix-multiple` are outside the stable v0.1.0 contract. The v0.1.0 documentation, compiler capabilities, and runtime components remain unchanged.

Matrix fields are available in the `next` development version, including explicit row and column types, Schema-aligned validation, Designer configuration, responsive runtime rendering, and row-level error navigation.
