# Documentation Versions

Published interfaces and in-development capabilities are maintained in separate documentation versions. The version selector switches the complete documentation set, and the language selector switches between Chinese and English.

<VersionTable />

Stable documentation covers published integrations, production compatibility, and pre-upgrade reference. Development documentation covers unreleased capabilities under trial and review. A development capability enters a new stable version only after passing code, test, documentation, Playground, and compatibility checks.

## Default language

Chinese remains the default language for every version. Navigation, search, page-language metadata, and component examples share that default configuration.

## Link rules

- Stable English documentation uses root-language paths such as `/en/guide/`.
- Non-default English versions retain the version prefix, such as `/next/en/guide/fields`.
- Production integrations should use stable-version links. Reviews of unreleased capabilities should retain an explicit version prefix.
