# Development Roadmap

Stable v0.1 established the versioned form protocol, deterministic compiler, controlled runtime, visual Designer, host adapters, and constrained `FormPatch` flow. Full JSON Schema support, complex forms, collaboration, and form-platform services are outside the v0.1 commitment.

| Milestone | Goal |
| --- | --- |
| v0.1 · current stable | Establish the protocol foundation and embedding model |
| v0.2 | Runtime integrity: closed Schema profile, computed rules, asynchronous validation, data sources, localization, and incremental performance |
| v0.3 | Complex forms: nested data, repeatable field groups, tables, matrices, multi-step wizards, extension fields, and visual rule editing |
| v0.4 | Governance: drafts and releases, history, diff, rollback, approvals, collaboration, offline synchronization, auditing, policy, and migration |
| v1.0 | Stable production contract: inspect, patch, simulate, test, approve, and publish |

See the [`next` development roadmap](/next/en/roadmap) and repository [`ROADMAP.md`](https://github.com/A3S-Lab/UI/blob/main/modules/form/ROADMAP.md) for capability ownership, known boundaries, acceptance criteria, non-goals, and release gates.

Planned capabilities are not part of the stable v0.1 protocol until they pass the release gates.
