# Architecture

```text
┌──────────────────────────────────────────────────────────────────┐
│                       A3S Cloud / Host                           │
│        Permissions · Data sources · Actions · Publishing         │
│             Cloud persistence · Agent / Workflow                 │
└──────────────────────────────┬───────────────────────────────────┘
                               │ Stable embedding API
┌──────────────────────────────▼───────────────────────────────────┐
│                           A3S Form                               │
│  ┌──────────────┐  ┌────────────────┐  ┌─────────────────────┐  │
│  │  Multi-form  │  │   Embeddable   │  │ React/Vue/Web Comp. │  │
│  │  workspace   │  │ form designer  │  │                     │  │
│  └──────┬───────┘  └───────┬────────┘  └──────────┬──────────┘  │
│         └───────────────────┼──────────────────────┘             │
│                    ┌────────▼─────────┐                          │
│                    │ Custom node      │                          │
│                    │ registry         │                          │
│                    └────────┬─────────┘                          │
│                    ┌────────▼─────────┐                          │
│                    │ Core compiler /  │                          │
│                    │ state machine    │                          │
│                    └────────┬─────────┘                          │
│                    ┌────────▼─────────┐                          │
│                    │ Rust WASM        │                          │
│                    │ hot path         │                          │
│                    └──────────────────┘                          │
└──────────────────────────────────────────────────────────────────┘
```

The Core layer has no UI-framework dependency, and the form document is the single source of truth. The Designer and framework adapters operate on the same compiled plan. The custom-node registry gives business components an explicit extension boundary.
