<div className="a3s-doc-lead">

A3S Form treats the form document as a versioned, validated, deterministically compiled product contract. The Designer edits the contract, the runtime renders it and handles interaction, and the host owns data sources, actions, permissions, and persistence.

</div>

## Available now

- Manage multiple forms in the Playground, create them in the browser, and save them automatically to `localStorage`.
- Build complex layouts with common fields, groups, columns, tabs, and repeatable sections.
- Register business-specific custom nodes with independent settings panels and runtime components.
- Embed the headless compiler and state machine in a3s-cloud, or use the React, Vue, and Web Component adapters.
- Accelerate hot paths with Rust WASM while preserving identical results when WebAssembly is unavailable.

## Start in five minutes

```bash
npm ci
npm run form:playground:dev
```

Open the address printed in the terminal. Enter the sample from “My Forms” or create a local form.
