# 开发路线

稳定版 v0.1 建立了版本化表单协议、确定性编译器、受控运行时、可视化 Designer、宿主适配器和受约束的 `FormPatch` 流程。完整 JSON Schema、复杂表单、协作和表单平台能力不属于 v0.1 承诺。

| 里程碑 | 目标 |
| --- | --- |
| v0.1 · 当前稳定版 | 建立协议基础与嵌入模型 |
| v0.2 | 运行时完整性：封闭 Schema profile、计算规则、异步校验、数据源、本地化和增量性能 |
| v0.3 | 复杂表单：嵌套数据、重复字段组、表格、矩阵、多步向导、扩展字段与可视化规则编辑 |
| v0.4 | 治理：草稿与发布、历史、diff、回滚、审批、协作、离线同步、审计、策略和迁移 |
| v1.0 | 稳定生产协议：检查、patch、模拟、测试、审批与发布 |

能力归属、已知边界、验收标准、非目标和发布门槛见 [`next` 开发路线](/next/roadmap)与仓库 [`ROADMAP.md`](https://github.com/A3S-Lab/UI/blob/main/modules/form/ROADMAP.md)。

计划能力通过发布门槛之前，不属于稳定 v0.1 协议。
