# 完成工作流

> [!IMPORTANT]
> 本页记录 A3S Flow `0.4.2` 八节点兼容 API，仅用于迁移。新编辑器请使用 [Flow 1.0 DAG 节点契约](/next/guide/workflow-node-embedding)和 `A3SFlowDagNodeConfigurationPanel`。

`flow.complete` 成功结束工作流并保存由纯表达式生成的 JSON 结果，不执行网络请求或其他副作用。

<A3SFlowNodeDemo nodeType="flow.complete" />

## 开发者契约

| 契约 | 值 |
| --- | --- |
| 分类 | 流程控制 |
| Runtime binding | `complete` |
| A3S Flow command | `Complete` |
| 稳定命令 ID | 描述符未声明稳定 ID 绑定 |
| A3S Flow 版本 | `0.4.2` |

## 在 MDX 中使用

示例包含结束节点预览和最终输出配置；完成工作流没有输出端口。

```mdx
import { A3SFlowNodeDemo } from '../../../../components/A3SFlowNodeDemo';

<A3SFlowNodeDemo nodeType="flow.complete" />
```

## 配置属性

| 属性 | 值类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `output_expression` | Flow expression | 是 | 字段 `input` | 结果会作为完成状态的 JSON 输出持久化。 |

## 端口

| 方向 | ID | 标签 | 类型 | 数据类型 | 可用条件 |
| --- | --- | --- | --- | --- | --- |
| 输入 | `in` | 完成 | Control | `FlowControl` | 始终可用 |
| 输入 | `output` | 最终结果 | Data | `JsonValue` | 始终可用 |

完成工作流没有输出端口。

## 配置值

```json
{
  "output_expression": {
    "apiVersion": "a3s.dev/flow-expression/v1",
    "expression": { "op": "field", "path": "input.result" }
  }
}
```

## 校验与运行时契约

- 表单校验要求 `output_expression` 为对象。
- 节点校验检查表达式版本封套与 AST 操作符。
- 宿主限制字段路径来源，并把表达式结果降低为 `Complete` 命令的 JSON 载荷。
- 进入 Complete 后运行处于终态，后续控制边不会执行。
