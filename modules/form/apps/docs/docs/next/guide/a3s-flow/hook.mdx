# 等待外部回调

> [!IMPORTANT]
> 本页记录 A3S Flow `0.4.2` 八节点兼容 API，仅用于迁移。新编辑器请使用 [Flow 1.0 DAG 节点契约](/next/guide/workflow-node-embedding)和 `A3SFlowDagNodeConfigurationPanel`。

`flow.hook` 暂停工作流，直到审批、Webhook、界面操作或接入系统事件提交回调数据，或回调被关闭。

<A3SFlowNodeDemo nodeType="flow.hook" />

## 开发者契约

| 契约 | 值 |
| --- | --- |
| 分类 | 等待与回调 |
| Runtime binding | `create_hook` |
| A3S Flow command | `CreateHook` |
| 稳定命令 ID | 不可变的图节点 ID |
| A3S Flow 版本 | `0.4.2` |

## 在 MDX 中使用

示例包含控制端口、数据端口，以及令牌、回调路由和附加数据配置。

```mdx
import { A3SFlowNodeDemo } from '../../../../components/A3SFlowNodeDemo';

<A3SFlowNodeDemo nodeType="flow.hook" />
```

## 配置属性

| 属性 | 值类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `kind` | `human_approval \| webhook \| host_event` | 是 | `human_approval` | 写入审计元数据的回调类型。 |
| `subject` | `string` | 是 | `Review workflow request` | 回调队列与审计记录中的简短标题。 |
| `token_expression` | Flow expression | 是 | 字段 `input.callbackToken` | 必须引用动态字段，不能使用共享字面量。 |
| `callback_method` | `POST \| PUT \| PATCH` | 否 | `POST` | 可选宿主路由元数据。 |
| `callback_path` | `string` | 否 | `/callbacks/workflow` | 引擎不会公开或托管该路径。 |
| `metadata` | JSON object | 否 | `{ "labels": {}, "data": {} }` | 高级设置；与 Hook 一起持久化。 |

## 端口

| 方向 | ID | 标签 | 类型 | 数据类型 | 可用条件 |
| --- | --- | --- | --- | --- | --- |
| 输入 | `in` | 创建回调 | Control | `FlowControl` | 始终可用 |
| 输入 | `token` | 回调令牌 | Data | `String` | 始终可用 |
| 输入 | `metadata` | 回调元数据 | Data | `JsonValue` | 始终可用 |
| 输出 | `received` | 收到回调 | Control | `FlowControl` | 收到回调后 |
| 输出 | `payload` | 回调数据 | Data | `JsonValue` | 收到回调后 |
| 输出 | `disposed` | 已关闭 | Control | `FlowControl` | Hook 被释放后 |

## 配置值

```json
{
  "kind": "human_approval",
  "subject": "Review record change",
  "token_expression": {
    "apiVersion": "a3s.dev/flow-expression/v1",
    "expression": { "op": "field", "path": "input.callbackToken" }
  },
  "callback_method": "POST",
  "callback_path": "/callbacks/workflow",
  "metadata": {
    "labels": { "queue": "record-review" },
    "data": { "source": "workflow" }
  }
}
```

## 校验与运行时契约

- 表单校验检查类型、必填字段和选项值。
- 节点校验拒绝字面量 Token 和不引用字段的 Token 表达式。
- 节点级校验无法证明 Token 唯一；A3S Flow 在所有非终态运行的活动 Hook 范围内原子校验唯一性。
- 宿主限制 Token 字段来源，绑定外部路由，并从不可变图节点 ID 生成稳定命令 ID。
- 恢复执行时，相同 ID 的 Token、种类、主题和元数据必须保持一致。
