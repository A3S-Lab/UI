# 等待至

> [!IMPORTANT]
> 本页记录 A3S Flow `0.4.2` 八节点兼容 API，仅用于迁移。新编辑器请使用 [Flow 1.0 DAG 节点契约](/next/guide/workflow-node-embedding)和 `A3SFlowDagNodeConfigurationPanel`。

`flow.wait` 暂停工作流直到指定的绝对 UTC 时间，恢复时间可以直接填写或来自已保存的工作流状态。

<A3SFlowNodeDemo nodeType="flow.wait" />

## 开发者契约

| 契约 | 值 |
| --- | --- |
| 分类 | 等待与回调 |
| Runtime binding | `wait_until` |
| A3S Flow command | `WaitUntil` |
| 稳定命令 ID | 不可变的图节点 ID |
| A3S Flow 版本 | `0.4.2` |

## 在 MDX 中使用

更改 `resume_at` 后，节点预览和下方 JSON 会同步更新。

```mdx
import { A3SFlowNodeDemo } from '../../../../components/A3SFlowNodeDemo';

<A3SFlowNodeDemo nodeType="flow.wait" />
```

## 配置属性

| 属性 | 值类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `resume_at` | Flow expression | 是 | 字段 `input.deadline` | 接受 `DateTime`；可使用 UTC 字面量或动态字段。 |

## 端口

| 方向 | ID | 标签 | 类型 | 数据类型 | 可用条件 |
| --- | --- | --- | --- | --- | --- |
| 输入 | `in` | 开始等待 | Control | `FlowControl` | 始终可用 |
| 输入 | `resume_at` | 恢复时间 | Data | `DateTime` | 始终可用 |
| 输出 | `resumed` | 继续 | Control | `FlowControl` | 到达期限后 |

## 配置值

```json
{
  "resume_at": {
    "apiVersion": "a3s.dev/flow-expression/v1",
    "expression": { "op": "field", "path": "input.resumeAt" }
  }
}
```

绝对时间也可以直接写入表达式：

```json
{
  "apiVersion": "a3s.dev/flow-expression/v1",
  "expression": { "op": "literal", "value": "2026-08-10T12:30:00Z" }
}
```

## 校验与运行时契约

- 表单校验检查表达式对象结构。
- 节点校验要求字面量是以 `Z` 结尾的有效绝对 UTC 时间；动态表达式至少引用一个字段。
- 节点级校验不会证明动态字段来自工作流输入或持久化状态，也不会静态证明解析结果是时间戳。
- 宿主限制字段路径来源，并从不可变图节点 ID 生成稳定命令 ID。
- 恢复执行时使用相同 ID，期限必须保持一致。
