# Langflow 兼容性

A3S Form 保留固定到 Langflow `1.11.3` 的描述符适配器，用于宿主导入现有 Langflow 组件配置。它是兼容层，不是 A3S Flow 1.0 DAG manifest 目录。

| 来源 | 值 |
| --- | --- |
| Repository | `langflow-ai/langflow` |
| Revision | `3325c4642c489bfc2e2f4c9f3c63a32961f9581f` |
| Component index SHA-256 | `9e19c76e01ef19fd82c6795f8c51c7c6eb7876bf2e9dfa0c33bb72b577d921e4` |
| 分类 | 17 |
| 组件 | 131 |
| 配置字段 | 797 |

适配器保留源顺序、字段元数据、类型化端口、可见性、Advanced 位置、范围元数据、选项、表格 Schema，以及归一化为生成 Schema 类型的源默认值。

```tsx
import { LangflowNodeConfigurationPanel } from '@a3s-lab/ui/form/react';
import {
  createLangflowNodeDefaultValue,
  requireLangflowNode,
} from '@a3s-lab/ui/form/workflow';

const component = requireLangflowNode('APIRequest');
const initialValue = createLangflowNodeDefaultValue(component);

<LangflowNodeConfigurationPanel
  node={component}
  value={initialValue}
  onChange={setValue}
/>;
```

导入的网络、模型、Agent、数据库和存储组件应在 A3S Flow 执行前降低为已注册的 `flow.step` handler。兼容适配器不增加运行时命令，也不负责凭证、持久化、图边或执行。

生成目录位于 `src/integrations/langflow-catalog.generated.json`。只有明确指定上游 revision 与组件索引 checksum 时才更新。
