# Langflow compatibility

A3S Form retains a pinned Langflow `1.11.3` descriptor adapter for hosts that import an existing Langflow component configuration. It is a compatibility layer, not the A3S Flow 1.0 DAG manifest catalog.

| Configuration fields | 797 |

The adapter preserves source order, field metadata, typed ports, visibility, advanced placement, range metadata, options, table schemas, and source defaults normalized to their generated Schema types.

```tsx
import { LangflowNodeConfigurationPanel } from '@a3s-lab/ui/form/react';
import {
  createLangflowNodeDefaultValue,
  requireLangflowNode,
} from '@a3s-lab/ui/form/workflow';

const component = requireLangflowNode('APIRequest');
const initialValue = createLangflowNodeDefaultValue(component);

<LangflowNodeConfigurationPanel
  node={component}
  value={initialValue}
  onChange={setValue}
/>;
```

Imported network, model, agent, database, and storage components should be lowered to registered `flow.step` handlers before A3S Flow execution. The compatibility adapter does not add runtime commands and does not own credentials, persistence, graph edges, or execution.

The generated catalog lives in `src/integrations/langflow-catalog.generated.json`. Update it only from an explicit upstream revision and component-index checksum.
