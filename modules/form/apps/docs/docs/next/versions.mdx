# 文档版本

已发布接口与开发中能力按版本分开维护。版本选择器切换整套文档，语言选择器在中文与英文内容之间切换。

<VersionTable />

稳定版用于已发布集成、生产兼容性和升级前对照；开发版用于试用与评审尚未发布的能力。

`next` 中的能力只有通过代码、测试、文档、Playground 和兼容性检查后，才会进入新的稳定版本。开发版文档不会自动成为发布承诺。

版本清单由仓库中的 `apps/docs/versions.json` 统一维护。构建会检查每个版本目录、首页和导航元数据，缺失时直接失败。

## 默认语言

文档站默认使用中文。页面语言标记、导航、搜索和实时组件示例跟随当前语言；每个版本都维护路径一致的中文与英文页面。

## 链接规则

- 默认稳定版使用根路径，例如 `/guide/`。
- 开发版保留版本前缀，例如 `/next/guide/fields`。
- 英文稳定版使用 `/en/`，英文开发版使用 `/next/en/`。
- 对外分享生产集成文档时，优先使用稳定版链接。
- 评审未发布功能时，链接中应明确保留 `/next/`。
